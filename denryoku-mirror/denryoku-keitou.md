# 電力系統・需給運用

発電した電力を「今この瞬間」需要と一致させ続ける仕組み。需給バランスが崩れると周波数が動く。論説中心だが、設備利用率・供給予備率の計算も出る。再エネ大量導入と系統連系は近年の頻出論点。出題頻度: 低（独立した枠は無く、送電・配電の問題に散って出る）難易度: ★★☆出題形式: 論説・穴埋め・計算（設備利用率/予備率）

## 1.直感的理解 — 需給バランスと周波数

電力系統の本質は、発電した電力を 今この瞬間に 需要と一致させ続けること。電力は在庫を持てない（大規模蓄電が普及する前の前提）。だから 需給のバランスが崩れると周波数が変動する。周波数は全系統の同期発電機が一斉に同期しているため、ズレは瞬時に系統全体へ伝わる。つまり周波数は「電力系統の健康診断」として機能する。

▶ 同期発電機の側から見た話（調速機で有効電力を変えて周波数を保ち、界磁電流で無効電力を変えて電圧を保つ。4節の安定度に効く P–δ・短絡比）は 機械Wiki「1.3 同期機」0節の「系統での立ち位置」へ。周波数と需給バランスの因果（最重要）
- 需要 > 供給 — 発電機（回転体）に余分な負荷 → 回転子の運動エネルギーが奪われ回転数が低下 → 周波数が低下（東日本なら50Hz以下）
- 供給 > 需要 — 発電機が空回り → 回転子にエネルギーが蓄積され回転数が上昇 → 周波数が上昇📊 このセクションの理解度:◎○△×

「経済負荷配分（EDC）は限界コストの高い発電機から優先的に出力を積み増す」→ 誤り。増分燃料費（限界コスト）の低い（安い）発電機から出力を積み増し、各機の増分燃料費が等しくなる点で配分する。目的は系統全体の燃料費最小化。EDC は運転中の発電機の出力配分であり、「どの発電所を起動するか」（限界コストの安い順＝メリットオーダー）は起動停止計画で別に決める。速度調定率の計算（R05下 問2 型。試験センター公表の問題冊子・解答で確認）

問題文が示す定義式は  $R = \dfrac{(n_2 - n_1)/n_n}{(P_1 - P_2)/P_n} \times 100\;[\%]$ （P₁・n₁ は変化前、P₂・n₂ は変化後、Pₙ・nₙ は定格）。回転速度は周波数に比例するので、分子は  $(f_2 - f_1)/f_n$  と同じ。

① 向きを先に決める：周波数が下がる（分子が負）なら、R は正なので分母も負＝出力は増える。周波数が上がれば出力は減る。② 百分率は小数にして割る（5 % → 0.05）。変形すると  $P_2 - P_1 = -P_n \times \dfrac{(f_2 - f_1)/f_n}{R}$ 。

並列の発電機はどれも同じ周波数変化を受けるので、各機の出力変化は  $P_n/R$  に比例して分担される（R だけでは決まらない。R が同じなら定格の大きい機械ほど、定格が同じなら R の小さい機械ほど大きく動く）。ただし、どの機も調速機の直線範囲にあり、出力の上限（定格）・下限に達していないときに限る。

問（R05下 問2）：定格 1000 MW・R＝5 % のタービン発電機（80 % 出力）と、定格 300 MW・R＝3 % の水車発電機（60 % 出力）が 50 Hz でガバナフリー運転中に、周波数が 0.2 Hz 下がった。それぞれの出力 [MW] は？自分で解いてから、解き方と答えを開く

 $(f_2 - f_1)/f_n = -0.2/50 = -0.004$ （下がったので出力は増える）。

タービン： $1000 \times 0.004/0.05 = 80$  MW 増えて 800 → 880 MW。水車： $300 \times 0.004/0.03 = 40$  MW 増えて 180 → 220 MW（正答 (4)）。揚水発電による需給調整（昼夜の向きに注意）

## 4.系統安定度

系統につながる同期発電機は、すべて同じ周波数に同期して回転している（そろうのは周波数で、回転速度ではない。 $N_s = 120f/p$  なので、回転速度は極数で違う。数値例は 機械Wiki「1.3 同期機」5節）。安定度とは「外乱（負荷急変・短絡等）が起きても同期を失わず（脱調せず）元の運転状態に戻れるか」の指標。

| 種類 | 定義 | 対策 |
| --- | --- | --- |
| 定態安定度 | 定常状態で小さな擾乱に対して安定を保てる限界 | 送電線を並列化・電圧維持 |
| 動態安定度 | 自動制御（AVR・PSS等）を含む動的安定性 | 自動電圧調整器（AVR）の整定 |
| 過渡安定度 | 短絡・地絡などの大きな擾乱後に同期を保てるか | 高速遮断・系統連系強化 |
定態 vs 過渡（因果で覚える）

定態安定度は小さな負荷変動に対する復元力。送電電力の上限（定態安定限界）を超えて運用しなければよい。過渡安定度は短絡事故のような大きな擾乱で、発電機が加速して他機との位相差が急拡大する前に素早く遮断（高速遮断）し、位相差が大きくなる前に故障区間を切り離して（故障除去）脱調を防ぐ。送電電力の式 — 安定度の根っこ（R04下 問9）

線路の抵抗と静電容量を無視し、1線のリアクタンスを  $X$ 、送電端と受電端の線間電圧を  $V_s, V_r$ 、両者の相差角を  $\delta$  とすると、三相の送電電力は

 $P = \dfrac{V_s V_r}{X}\sin\delta$

線間電圧で書くと係数3は付かない（相電圧  $V/\sqrt{3}$  で1相分を出して3倍すると、3 と  $(1/\sqrt{3})^2$  が打ち消し合う）。 $\delta = 90^\circ$  で最大になり、これが定態安定限界の目安になる。 $X$  を小さくする（多導体化・直列コンデンサ）・電圧を上げると、送れる電力が増える。R04下 問9 の正答は (1)（試験センターの解答 PDF で確認）。

> Pmax ＝ VsVr ／ X だから、対策は「X を小さく」「電圧を高く」の2つ——X を小さくする手段が送電線の並列化・多導体化・直列コンデンサ、電圧を高く保つ手段が電圧維持。上の表の定態安定度の対策「送電線を並列化・電圧維持」は、この2つにあたる。δ ＜ 90° の側では、山が高いと同じ電力を小さい δ で送れる（90° までの余裕が大きい）。📊 このセクションの理解度:◎○△×

## 6.中性点接地方式（地絡電流と異常電圧のトレードオフ）

| 抵抗接地 | 中（100〜数百A） | 中 | 中 | 22〜154kVの特別高圧系 |

因果で覚える — なぜ直接接地は主に超高圧か

直接接地は健全相の電圧上昇が小さいため絶縁レベルを下げられる（段絶縁・避雷器負担の軽減）＝絶縁コストが支配的な超高圧で効果が絶大。代わりに地絡電流が巨大になるが、超高圧系は保護継電器＋高速遮断で対処する。逆に6.6kV配電は絶縁コストが小さいので、地絡電流を小さくして感電・通信障害・機器損傷を抑える方が得＝非接地を選ぶ。消弧リアクトル接地は対地静電容量Cと並列共振するLを中性点に入れ、地絡電流をほぼ打ち消してアークを自然消弧させる方式。引っかけ

## 7.系統連系と単独運転防止

太陽光・風力・小水力等の分散型電源を系統につなぐには、系統連系規程（JEAC 9701。日本電気協会の技術規程で、電技解釈の解説が参考に挙げる）に沿った要件を満たす必要がある。

| 要件 | 内容 |
| --- | --- |
| 単独運転防止 | 系統停電時に分散型電源が単独で運転（アイランディング）しないこと |
| 逆潮流 | 余剰電力を系統に逆流させること。大部分の分散型電源で認められている |
| 保護協調 | 系統の保護システムと連系点の保護装置を協調させること |
| 電圧変動 | 連系により配電線の電圧が許容範囲を超えないこと |
| 高調波 | インバータから発生する高調波が規制値以下であること |
逆潮流は「有効電力」の流れだけ（法規 R1 問9 で出題）

電技解釈 第220条での逆潮流の定義は「分散型電源設置者の構内から、一般送配電事業者が運用する電力系統側へ向かう有効電力の流れ」。
- 無効電力は逆潮流に含めない。連系点で系統側へ無効電力が流れていても「逆潮流」とは呼ばない。逆潮流の有無は有効電力の向きだけで判定する。
- 「逆潮流あり」＝余剰電力を売電している状態。「逆潮流なし連系」＝発電を構内消費だけに使い有効電力を系統へ流さない運用で、RPR（逆電力継電器）で逆潮流を監視・防止する。
- なぜ有効電力だけか：売電量や系統側の電圧上昇に直接効くのは有効電力の往来で、無効電力は力率・電圧調整として別枠で管理するため。単独運転防止（アイランディング防止）が必要な理由

系統停電時に分散型電源が単独で電圧を供給し続けると、（1）需要家側に電圧が印加されたまま残り作業員の感電リスクが生じ、（2）系統復旧時の位相不一致で機器が損傷する。検出方法は、周波数・電圧に意図的な変動を与えて検出する能動的方式と、周波数・電圧の急変を検出する受動的方式。対策は、系統停電を検出したら自動的に解列（連系点遮断）すること。単独運転検出方式（受動的3・能動的4）

| 方式 | 代表例 | 検出原理（イメージ） |
| --- | --- | --- |
| 受動的 | 電圧位相跳躍検出 | 系統が切れると負荷の力率分だけ電圧位相が急に飛ぶ→その跳躍を検出 |
| 受動的 | 周波数変化率検出（ROCOF, df/dt） | 系統が切れると需給アンバランス分だけ周波数が急変→変化の速さを検出 |
| 受動的 | 3次高調波電圧急増検出 | 系統が切れると変圧器由来の3次高調波電圧が逃げ場を失い急増→それを検出 |
| 能動的 | 周波数シフト方式 | 出力周波数を少し押し続ける。系統ありなら抑え込まれ変化なし／切れると周波数がずれ続ける |
| 能動的 | 有効電力変動方式 | 出力（有効電力）を周期的に変動させる。系統ありなら周波数は動かない／切れると周波数が揺れる |
| 能動的 | 無効電力変動方式 | 無効電力を周期的に変動させる。系統ありなら影響なし／切れると周波数が揺れる |
| 能動的 | 負荷変動方式 | 瞬間的に負荷を挿入し電圧の変化を見る。系統ありなら変化小／切れると電圧が大きく動く |

受動的＝系統が切れた瞬間のショック（急変）を見る。能動的＝わざと小さく揺さぶり続ける。系統がつながっていれば揺さぶりは系統に吸収されて現れず、系統が切れると揺さぶりが周波数・電圧の変化として現れる（大きくなる）ので、それで系統が消えたと判断する。能動的は感度が高いが、複数台連系時に互いの揺さぶりが干渉する課題がある。再エネ大量導入と系統の慣性力（電力 H28〜R8上 の15回では未出題）

「太陽光発電を大量に系統連系すると系統の慣性力が増す」→ 誤り。太陽光発電はインバータ（直流→交流変換器）経由で接続されるため、同期発電機の回転体がもつ慣性力（イナーシャ）に相当するものがない。太陽光比率が上がると系統全体の慣性力が低下し、周波数が変動しやすくなる。対策は蓄電池（BESS）・揚水との組み合わせ、需要側制御（DR）。

### 直流送電 — 交流と比べた長所と短所R05下 問11・R07下 問11 ほか H21・H24・H29

交流と比べて「何が楽になり、何が難しくなるか」を、理由と組で押さえる。誤りの選択肢は、長所と短所の向きを入れ替えて作られる。

|  | 内容 | 理由 |
| --- | --- | --- |
| 長所 | 交流のような同期安定度の制約が無く、電線の許容電流まで送れる（R07下 問11 (2) の正しい選択肢）。長距離・大電力に向く | リアクタンスの影響が無く、送電端と受電端の位相差の問題が起きない |
| 非同期連系ができる（50 Hz と 60 Hz の系統もつなげる） | 直流でいったん周波数を切り離す |  |
| 定常的な充電電流が流れない（長距離のケーブルでも使える） | 電圧が時間で変わらないので、静電容量に電流が流れ続けない（投入時の過渡的な電流は別） |  |
| 絶縁を低くできる | 交流は最大値が実効値の $\sqrt{2}$ 倍。直流は最大値が電圧そのもの。だから、交流の実効値と同じ値の直流電圧で比べると、直流の方が絶縁にかかる電圧（最大値）が低い |  |
| 短所 | 送受電端に交直変換所が要る | 発電・負荷側は交流なので、変換が要る |
| 変換器から高調波が出るので、フィルタが要る | 他励式の変換器は無効電力も消費するので、調相設備も要る |  |
| 変圧器で昇圧・降圧できない | 変圧器は磁束の変化（交流）で働く |  |
| 大電流の遮断が難しい | 直流は電流が零点を通らないので、交流の遮断器のように電流零点でアークを消せない |  |

誤りの選択肢として出たのは、R05下 問11 (3)「直流の高電圧大電流の遮断は，交流の場合より容易である」と、R07下 問11 (4)「直流電圧の最大値は同じ実効値の交流電圧より高くなるため，絶縁レベルを増加させる必要がある」。問題文と正答は、試験センターの問題 PDF と解答 PDF で確認した。H21・H24・H29 は出題記録（K1 年度別一覧）の題目だけで、問題文は照合していない。📊 このセクションの理解度:◎○△×

## 8.公式マップと負荷持続曲線01設備利用率 $U = \dfrac{W}{P \times 8760} \times 100\,[\%]$ U=設備利用率、W=年間発電電力量[kWh]、P=設備容量[kW]、8760=1年の時間[h]。高いほど設備を有効活用。太陽光は約10〜15%、火力は約50〜80%（いずれも目安）。02供給予備率 $R = \dfrac{P_s - P_d}{P_d} \times 100\,[\%]$ R=供給予備率、Ps=供給力、Pd=最大需要電力。高いほど安定供給しやすいが設備コストは増える。一般に8〜10%以上を目標とすることが多い。例題①: 容量100kWの太陽光が年間130,000kWh発電 → 設備利用率は？自分で解いてから、解き方と答えを開く

設備利用率 U は次式で求まる。

 $U = \dfrac{130{,}000}{100 \times 8760} \times 100 = \dfrac{130{,}000}{876{,}000} \times 100 \approx 14.8\,\%$

上の式01の目安（太陽光 約10〜15%）に収まる。1.4 新エネルギー発電の比較表と大小関係（地熱60〜80% > 風力20〜30% > 太陽光10〜15%）とも同じ数字を使っている。例題②: 供給力1,100万kW・最大需要1,000万kW → 供給予備率は？自分で解いてから、解き方と答えを開く

供給予備率 R は次式で求まる。

 $R = \dfrac{1100 - 1000}{1000} \times 100 = 10.0\,\%$

目標の8〜10%以上を満たす水準。負荷持続曲線とベース・ミドル・ピーク

負荷持続曲線は、年間8760時間を通じて各負荷レベルが何時間持続するかを表したグラフ。これを使って電源を割り当てる。
- ベース負荷 — 年間ほぼ常時必要な最低限の電力。原子力・石炭火力・大型水力で賄う
- ミドル負荷 — 昼間・平日に追加的に必要。LNG・石油火力で対応
- ピーク負荷 — 夏の猛暑日・冬の厳寒日など年間数十〜数百時間のみ。揚水・ガスタービンで対応📊 このセクションの理解度:◎○△×

## 9.引っかけ・誤答ポイントトラップ
- 周波数低下の原因を逆に理解 — 周波数低下＝需要が供給を上回る（需要過多）。供給過多のサインではない。
