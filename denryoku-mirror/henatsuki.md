# 変圧器（基礎ハブ）

巻数比で電圧・電流が逆比例し、磁束を介してエネルギーを転送する。変電分野（約54問）の基礎ハブ。巻数比・換算・損失・効率・電圧変動率・並行運転・結線を俯瞰する。
**出題頻度:** 高（変電分野 約54問の中核）
**難易度:** ★★★
**出題形式:** 計算（効率/並行運転/短絡）・論説（結線/種類）

## 1.巻数比（5秒で思い出す）

01
**巻数比 a（電圧比＝電流比の逆数）**
$\dfrac{V_1}{V_2} = \dfrac{N_1}{N_2} = \dfrac{I_2}{I_1} = a$
電圧は巻数に比例、電流は巻数に反比例。V1·I1=V2·I2（エネルギー保存）から導ける。
等価回路の換算は「方向で逆数」
巻数比 $a = N_1/N_2 = V_1/V_2$。インピーダンス換算は方向で $a^2$ 倍と $1/a^2$ 倍が逆転する：
- **二次→一次**に換算した抵抗・リアクタンス： $R_2' = a^2 R_2,\ X_2' = a^2 X_2$（$\times a^2$）
- **一次→二次**に換算した抵抗・リアクタンス： $R_1'' = R_1/a^2$（$\times 1/a^2$）

理由：換算後 $V_1=aV_2,\ I_1=I_2/a$ なので $Z_1 = V_1/I_1 = a^2 Z_2$。「一次に換算した二次抵抗は $a^2$ 倍＝正／二次に換算した一次抵抗は $1/a^2$ 倍」— 主語と換算方向を必ず読む。

## 2.損失の分類（鉄損は一定・銅損は α²）

| 損失 | 別名 | 発生場所 | 負荷依存性 |
| --- | --- | --- | --- |
| 鉄損 Pi | 無負荷損 | 鉄心 | **一定**（電圧・周波数で決まる） |
| 銅損 Pc | 負荷損 | 巻線抵抗 | **電流²＝負荷率α²に比例** |

鉄損の内訳（論説頻出）— ヒステリシス損と渦電流損は別物
- **ヒステリシス損** $P_h \propto f \cdot B_m^{1.6}$（周波数1乗）→ 対策＝**方向性珪素鋼板・アモルファス**
- **渦電流損** $P_e \propto f^2 B_m^2 t^2 / \rho$（周波数2乗・板厚² ・比抵抗に反比例）→ 対策＝**薄板積層・珪素添加**

「薄板化はヒステリシス損対策」は**誤**（薄板化は渦電流損対策）。板厚半分で渦電流損は約1/4。
損失の分離測定
**無負荷試験**（定格電圧・二次開放）→ 励磁電流のみで銅損≈0、測定値≈**鉄損 Pi**。**短絡試験**（二次短絡・インピーダンス電圧で定格電流）→ 磁束密度数%で鉄損≈0、測定値≈**定格銅損 Pc,full** ＋ $\%Z = \dfrac{V_s}{V_n}\times100,\ \%R = \dfrac{P_s}{S_n}\times100,\ \%X = \sqrt{\%Z^2-\%R^2}$ も得る。

## 3.効率と最大効率（鉄損＝銅損）

02
**効率（皮相容量 Sn・負荷率 α 基準）**
$\eta = \dfrac{\alpha S_n \cos\theta}{\alpha S_n \cos\theta + P_i + \alpha^2 P_{c,full}} \times 100\,[\%]$
出力 Pout=α·Sn·cosθ。銅損は Pc(α)=α²·Pc,full。
03
**最大効率条件・最大効率の負荷率**
$P_i = \alpha^2 P_{c,full} \quad\Rightarrow\quad \alpha_m = \sqrt{\dfrac{P_i}{P_{c,full}}}$
鉄損=銅損のとき効率最大。このとき損失合計＝2Pi。
例題: 10kV·A・α=1・力率1.0・鉄損200W・定格銅損300W → 効率は？
$\eta = \dfrac{10{,}000}{10{,}000 + 200 + 300}\times100 = \dfrac{10{,}000}{10{,}500}\times100 \approx 95.2\%$
最大効率の負荷率（Pi=100W・Pc,full=400W の場合）：$\alpha_m = \sqrt{100/400} = 0.5$

## 4.電圧変動率

04
**電圧変動率**
$\varepsilon \approx \varepsilon_r \cos\theta + \varepsilon_x \sin\theta\,[\%]$
εr=Pc,full/Sn×100（%抵抗）、εx=%リアクタンス。εr の分母は皮相 Sn（有効出力ではない）。
例題: %r=2%・%x=4%・力率0.8(遅れ)
$\varepsilon = 2\times0.8 + 4\times0.6 = 1.6 + 2.4 = 4.0\%$

## 5.並行運転（分担は共通基準の %Z に逆比例）

並行運転の条件：**変圧比・%Z・極性・相回転・位相変位（角変位）**の一致。**違ったときに起きることは同じではない**——変圧比・極性・角変位が違うと**循環電流や短絡で運転が成立しない**が、%Z が違うだけなら**運転はでき、分担が偏る**。なお必要なのは**角変位の一致**であって結線方式の同一ではない（Δ-Δ と Y-Y は結線が違うが角変位 0° 同士なので並行運転できる）。一般式と数値例は 機械Wiki「2.1 変圧器」セクション10 並行運転へ。
%Z が違うと容量比どおりに分担されない
分担電流はインピーダンスに反比例＝**分担 ∝ 1/%Z**（この %Z は**共通基準に換算した値**。同容量なら自己容量基準がそのまま共通基準になるので下の例はそのまま使える）。同容量で A(%Z=4%)・B(%Z=6%) を並列すると $I_A:I_B = \tfrac{1}{4}:\tfrac{1}{6} = 6:4$。負荷100Aなら A=60A・B=40A で、容量比1:1なのに**%Z の小さい A が過負荷**。異容量機は基準容量を揃えて比較する。

## 6.三相結線とV結線

| 結線 | 位相変位 | 第3高調波 | 特徴 |
| --- | --- | --- | --- |
| Y-Y | 0° | 吸収先なし→歪む | 配電にほぼ不使用・第三巻線(Δ)で対策 |
| Δ-Δ | 0° | Δループで循環吸収 | 中性点なし・1台故障でV結線運転可 |
| Y-Δ | −30°(遅れ) | 二次Δで吸収 | 降圧用（**受電端**の変電所） |
| Δ-Y | +30°(進み) | 一次Δで吸収 | 昇圧用（**送電端**＝発電所） |

V結線の3公式（H30問12型）
単相1台容量を $S_n$ とすると：三相出力 $S_V = \sqrt{3}\,S_n$、利用率 $\dfrac{S_V}{2S_n} = \dfrac{\sqrt{3}}{2} \approx 0.866$、容量効率 $\dfrac{S_V}{3S_n} = \dfrac{1}{\sqrt{3}} \approx 0.577$。**0.866(2台基準)と0.577(Δ3台基準)を取り違えない**。Y-Δ と Δ-Y は角変位が60°違うので並行運転不可——ただし**不可の理由は「角変位が異なる」こと自体**で、60°が閾値ではない（Y-Y と Y-Δ の30°差でも不可）。
▶ **単相3台のΔ-Δで1台故障 → V結線運転**（なぜ57.7%か・2台の力率が cos(30°∓θ) に分かれる理由・応急運転の制約）は 機械Wiki「2.1 変圧器」セクション12へ。
**Y は中性点が「ある」／Δ は「ない」**——ただし中性点があることと接地することは別（接地方式は選択）。位相変位はY-Δ が二次30°遅れ、Δ-Y が30°進み——ただし**比べているのは線間電圧どうし**で、Y の相電圧と線間電圧の間にある 30°とは別物（ここを混ぜると符号が合わなくなる）。V結線の 86.6% と 57.7% は**分母が違うだけ**で、なぜ 57.7% になるかの機構は上の機械Wikiリンク先へ。

## 7.短絡電流（%Z 使用）

05
**短絡電流**
$I_s = I_n \times \dfrac{100}{\%Z}\,[\text{A}]$
In=定格電流。%Z に反比例＝%Z が小さいほど短絡電流大→遮断器の遮断容量を大きく。
例題: 500kV·A・6600/210V・%Z=5% の二次側三相短絡電流
$I_n = \dfrac{500\times10^3}{\sqrt{3}\times210} \approx 1375\,\text{A}$
$I_s = 1375 \times \dfrac{100}{5} = 27{,}500\,\text{A} = 27.5\,\text{kA}$
定格電流の20倍。電源側%Zが与えられたら 合成%Z=変圧器%Z+電源%Z で計算。

## 8.正誤判定の急所

| 命題 | 判定 | 理由 |
| --- | --- | --- |
| 変圧器の鉄損は負荷電流の2乗に比例する | **誤** | 鉄損は一定。2乗比例は銅損 |
| 二次側に換算した一次抵抗は a² 倍 | **誤** | 1/a² 倍（一次に換算した二次抵抗が a²倍） |
| 無負荷試験では銅損も測定できる | **誤** | 励磁電流のみ→測定値は実質 鉄損 |
| 短絡試験は定格電圧をかけて行う | **誤** | インピーダンス電圧（数%）で定格電流 |
| ヒステリシス損は周波数の2乗に比例する | **誤** | Ph∝f（1乗）。2乗は渦電流損 |
| 短絡電流は %Z に比例して大きくなる | **誤** | Is=In×100/%Z で %Z に反比例 |
| Y-Y結線は第3高調波電流を吸収できる | **誤** | 吸収はΔ結線。Y-Yは歪む |
| 無電圧切換は変圧器を停止させずに行える | **誤** | 停止が必要。停止不要は負荷時タップ切換 |

「無電圧切換＝電圧を切らない」という誤読に注意
タップ切換装置の**無電圧切換（オフロードタップチェンジャー）**は、変圧器を**停止してから**切り換える。停止が不要なのは**負荷時タップ切換装置（オンロードタップチェンジャー）**。名称の「無電圧」は「電圧が印加されていない状態で切り換える」という意味であり、「電圧を中断せずに（切らずに）切り換える」という意味ではない。この誤読を突く正誤問題が頻出。
