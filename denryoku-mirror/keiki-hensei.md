# 計器用変成器（VT・CT）

系統の大電流・高電圧を、計器・継電器で扱える小さな値（5 A・110 V）に縮小するセンサー。VT（計器用変圧器）と CT（変流器）の総称。CT は二次開放 NG・VT は二次短絡 NG という左右対称の禁則が最頻出。
**出題頻度:** 高（5年で3〜4問・問7枠の固定論点）
**難易度:** ★★☆
**出題形式:** 論説・穴埋（取扱注意）／計算（変流比・残留回路）

## 1.直感的理解 — なぜ「縮小」するか

系統では電圧 6.6 kV〜500 kV、電流 数百〜数千 A が日常的に流れる。これを直接計器・継電器に入れると、**電圧側は絶縁が破れ端子が高電圧化**し、**電流側は巻線が瞬時に焼損**する。そこで「変圧器の原理で電圧を 110 V に下げる／電流を 5 A に下げる」器具が要る。これが計器用変成器。
用語の整理（総称と個別名）
- **計器用変成器**＝**VT と CT の総称**。試験文ではこの言葉単独でも頻出（上位概念）。
- **計器用変圧器（VT または PT）**＝高電圧→110 V 等の電圧変成。電圧計・電力計・電圧継電器の入力。
- **変流器（CT）**＝大電流→5 A 等の電流変成。電流計・電力計・電流継電器の入力。
- **VT と PT は同じもの**。JIS では VT が正式表記だが現場では PT も併用。試験で「PT」「計器用変圧器」「VT」のどれが出ても同じ機器と判断してよい。

5秒で思い出す
VT ＝ 高電圧用センサー（**並列**・110 V 取出）／CT ＝ 大電流用センサー（**直列**・5 A 取出）。**VT は短絡 NG・CT は開放 NG**（左右対称で覚える）。

## 2.設備（構造と諸元）

系統内では **CT は主回路に直列挿入**して大電流を 5 A に、**VT は線間または対地に並列接続**して高電圧を 110 V に縮小し、それぞれ電流計・OCR・電圧計・UVR・電力計へ渡す。
CT の一次巻線が「太く少巻数」な理由
CT の一次は**系統の主回路そのもの**を流す。数百〜数千 A が定常的に流れるため導体は太く、巻数は1ターン〜数ターンで済む（貫通形 CT は鉄心に電線を1回通すだけ＝1ターン）。二次は計器側で 5 A しか流さないため細く・多く巻ける。

| 項目 | CT（変流器） | VT（計器用変圧器） |
| --- | --- | --- |
| 目的 | 大電流を計器用 5 A に変換 | 高電圧を計器用 110 V に変換 |
| 接続方式 | **直列**（主回路に挿入） | **並列**（線間または対地） |
| 一次側 | 大電流・低電圧（線路に直列） | 高電圧・小電流（線路に並列） |
| 二次定格 | 通常 **5 A**（一部 1 A） | 通常 **110 V**（線間または相電圧 110/√3） |
| 負荷側インピーダンス | **低い**（電流計・OCR 内部抵抗） | **高い**（電圧計・電圧コイル） |
| 二次側の禁則 | **開放 NG**（異常高電圧・焼損） | **短絡 NG**（過電流・焼損） |
| 接地 | 二次側1点接地 | 二次側1点接地（人身保護） |

禁則の向きは**つなぎ方から導ける**——CT は主回路に直列なので一次電流は系統側で決まり、二次をどうしても止められない。二次を開けると**打ち消していた二次アンペアターンが消え**、一次電流がまるごと励磁に回って磁束が過大になり、鉄心が飽和して急峻な尖頭電圧が現れる。VT は線間に並列なので一次電圧が系統側で決まる。二次を短絡すると端子電圧はほぼゼロに落ち、誘導起電力を**巻線の抵抗と漏れリアクタンスだけ**が制限するため大きな短絡電流が流れる。**丸暗記せず「何が外から決まっているか」で判断する**。

## 3.種類の比較（CT・VT の種別）

| CT 種別 | 構造 | 主用途 | 特記 |
| --- | --- | --- | --- |
| 巻線形 CT | 一次・二次とも巻線を巻く | 一般配電・低電流用 | 巻数比で変流比を設計可能 |
| 貫通形 CT | 鉄心に主回路導体を1回通す（一次1ターン） | 大電流系統・主回路 | 構造が単純で堅牢 |
| ブッシング CT | 変圧器・遮断器のブッシング部に内蔵 | 主変圧器・GIS | 設置スペース不要 |
| 零相変流器（ZCT） | 三相一括で鉄心を通し和電流を検出 | 地絡保護（DGR / OCGR） | 通常 ΣI≒0／地絡時 ΣI≠0 |

| VT 種別 | 構造 | 主用途 | 特記 |
| --- | --- | --- | --- |
| 単相 VT | 単相変圧器を1〜3台組合せ | 一般配電・線間電圧測定 | 二相結線・三相結線で運用 |
| 三相 VT | 三相変圧器を1台で構成 | 中電圧配電・経済性重視 | 単台で済む |
| コンデンサ形 VT（CVT） | コンデンサ分圧＋誘導性結合 | 主に特別高圧（66 kV〜。高電圧ほど経済的） | 鉄心 VT より絶縁設計が容易 |
| 接地形計器用変圧器（EVT / GPT） | 三相 VT の中性点接地で零相電圧検出 | 非接地系の地絡検出 | 一次は Y 接地、**残留電圧用の巻線（通常は三次巻線）を開放Δ（ブロークンデルタ）**にして **3V₀** を出力（残留回路の 3I₀ と対。計測用の二次 Y 巻線は別にある） |

ZCT と EVT の関係（因果理解）
**ZCT** は**零相電流 I0** を、**EVT** は**零相電圧 V0** を検出する。非接地系（高圧配電のΔ系）では地絡時に I0 と V0 が同時に発生するため、両者を組み合わせて方向判定（DGR）に使う。地絡方向継電器の入力は ZCT＋EVT のセットが定石。

## 4.公式マップ（変成比・誤差・残留回路）

01
**変流比（CT）**
$K_n = \dfrac{I_1}{I_2} = \dfrac{N_2}{N_1}$
I1,I2=一次・二次電流、N1,N2=巻数。電流は巻数の逆比。CT は一次電流が大→一次巻数を少なく（N1<N2）。
02
**変圧比（VT）**
$K_v = \dfrac{V_1}{V_2} = \dfrac{N_1}{N_2}$
V1,V2=一次・二次電圧。電圧は巻数の順比。VT は一次電圧が大→一次巻数を多く（N1>N2）。
計器側からの一次値換算（試験頻出）
一次電流 $I_1 = I_2 \times K_n$（例: 二次計器 4 A・変流比 200/5 なら $I_1 = 4 \times 40 = 160$ A）。一次電圧 $V_1 = V_2 \times K_v$（例: 二次計器 100 V・変圧比 6600/110 なら $V_1 = 100 \times 60 = 6000$ V）。
CT と VT で巻数比の向きが逆
CT は一次電流が大→一次巻数を**少なく**して二次に小電流を出す（$N_1 < N_2$）。VT は一次電圧が大→一次巻数を**多く**して二次に低電圧を出す（$N_1 > N_2$）。「電流は巻数の逆比・電圧は巻数の順比」という変圧器一般式そのもの。
**接続方式（最頻出）**：CT は主回路に**直列**・二次計器（電流計・電流コイル）にも**直列**で負荷は**低インピーダンス**。VT は主回路に**並列**・二次計器（電圧計・電圧コイル）にも**並列**で負荷は**高インピーダンス**。
極性記号 K-L / k-l
一次側端子 **K（同極性）・L（反対側）**、二次側端子 **k（同極性）・l（反対側）**。同時刻に **K → 一次** へ流れ込む電流方向と **k → 二次** から流れ出す電流方向が**同じ向きの磁束**を作る。電力計・差動継電器など**方向を読む装置**は極性を間違えると逆動作する。
03
**比誤差**
$\varepsilon = \dfrac{K_n I_2 - I_1}{I_1} \times 100\,[\%]$
変成比のずれ。主な原因は励磁電流分の損失。位相誤差δは二次と一次の位相のずれ（鉄損・励磁電流が原因）。
負担（burden）が大きいほど誤差が増える
二次側に接続する計器・継電器が消費する皮相電力（定格二次電流を流したときの $Z I_2^2$）を**負担（burden）**と呼ぶ［V·A］。負担が大きい（多数の計器を接続）ほど、二次側に必要な誘導起電力 $E_2 = I_2(Z_2 + Z_{\text{burden}})$ が増え、**鉄心磁束と励磁電流が増加**して**誤差増大**。**「磁束が減る」ではなく「増える」**——その極限が負担無限大＝**二次開放**で、磁束が飽和域まで増えて高電圧を生む（開放厳禁の理由と同じ因果）。負担が定格を超えると階級（精度等級）を保証できない。CT では OCR・電流計・電力計の多数接続で負担超過に注意し、さらに二次回路に絶対に**開放部を作らない**。
04
**残留回路（零相電流検出）**
$I_{res} = I_a + I_b + I_c = 3 I_0$
3相の相CT二次をY結線して中性線を取り出すと、その線に3相の和電流=3I0（零相電流の3倍）が流れる。
残留回路の挙動と ZCT との違い
**平衡時**：$I_a + I_b + I_c = 0$ → 残留回路に電流流れず。**地絡時**：1相に地絡電流加算 → $I_a + I_b + I_c \neq 0$ → 残留回路に **3 I0** が流れる。残留回路は**3つの相 CT**の二次を組み合わせて検出（既設の相 CT を利用でき経済的）。ZCT は**三相一括で1個の鉄心**を通して直接検出（精度が高く小電流地絡も検出可）。
どちらも見ているのは $I_a + I_b + I_c = 3I_0$ で**同じ量**。違うのは和をとる場所——残留回路は**3台の CT の二次側で電気的に**足し、ZCT は**1個の鉄心の中で磁気的に**足す。磁気的に足す方が誤差の入る余地が少ないので、**小電流の地絡検出には ZCT が有利**。高圧受電の地絡保護に ZCT が使われる主な理由がこれ。緑の線は一次導体ではなく CT の二次リードで、Y 結線するのは**二次側**（一次を結んだら三相短絡になる）。

## 5.解法パターン（例題つき）

① 変流比から一次電流を求める
変流比 400/5 の CT で二次電流計が 3.5 A を示した。一次電流は？
$K_n = 400/5 = 80$
$I_1 = I_2 \times K_n = 3.5 \times 80 = 280\,\text{A}$
「比は一次/二次」を必ず確認。小数の掛け算で計算ミスが多い。
④ 残留回路から一線地絡電流を読む
3つの相 CT 二次を Y 結線した残留回路に 0.6 A が流れた。変流比 200/5 のとき地絡電流は？
$I_0(\text{2nd}) = 0.6 / 3 = 0.2\,\text{A}$
$K_n = 200/5 = 40$
$I_0 = 0.2 \times 40 = 8\,\text{A}$
$I_g = 3 I_0 = 3 \times 8 = 24\,\text{A}$
「3で割って40倍して3倍する」と覚える（数学的には Kn 倍する＝二次の 3I0 を一次へ写し取る）。
② CT 二次回路を絶対に開放してはいけない（計器交換手順）
- **必ず二次端子を短絡してから**計器を取り外す（CT には専用の短絡端子板がある）。
- 計器を交換した後、**短絡を解除**して通電状態に戻す。
- 短絡したまま放置しても**過電流にはならない**（むしろ安全側）。

③ VT 二次回路を絶対に短絡してはいけない
- **一次側を停止**してから二次を触る、または**二次ヒューズを抜く**。
- 通電中の VT 二次を短絡すると**過大短絡電流**で巻線焼損。
- 実機の VT 二次にはヒューズが入っており、万一短絡してもヒューズが先に切れて巻線を守る。CT の禁則（開放 NG）と左右対称で混同しやすい。

⑤ 取扱注意の総合判別／⑥ 極性ミスは逆動作
取扱注意問題は4基準で判別：VT 二次は**並列・短絡 NG**／CT 二次は**直列・開放 NG**／接地は**二次側1点**（多点接地は循環電流発生）／計器負担は定格 VA を超えない。1つでも違反する選択肢が「誤り」。極性は CT の K 端子と電力計の電流端子、VT の K 端子と電力計の電圧端子の極性側（±）を一致させる。逆だと電力指示が負・誤値になり、差動継電器（87）では誤動作につながる。

## 6.引っかけパターン

頻出トラップ（左右対称・因果の取り違え）
- **接続方式の取り違え** — 「CT は並列／VT は直列」は誤。正しくは **CT 直列・VT 並列**。
- **二次禁則の左右対称取り違え** — 「CT 二次は短絡してはならない」は誤（短絡してよい・むしろ安全）。「VT 二次は開放してはならない」も誤（開放してよい・短絡が NG）。
- **CT 二次開放の害を「電流」と誤認** — 開放すると過大**電圧**が発生して焼損（一次電流が全量励磁電流化→鉄心磁気飽和→二次に異常高電圧）。過大電流ではない。
- **計器用変成器＝VT のみと誤認** — VT と CT の**総称**。JIS では両方を含む上位概念。
- **ZCT と CT の混同** — ZCT は短絡電流ではなく**零相電流（地絡電流）**を検出する。

CT 二次開放がなぜ危険か（最頻出の因果）
通電中の CT 二次を不用意に開放すると、一次電流が全量励磁電流化して鉄心が磁気飽和し、**数千 V の異常高電圧**が二次に発生する。絶縁破壊・感電・焼損につながる。試験論点としても実務安全としても最頻出。

## 7.正誤判定の急所

| 命題 | 判定 | 理由 |
| --- | --- | --- |
| 計器用変成器は VT と CT の総称である | **正** | JIS 用語。単独で出ても両者の話 |
| VT は二次側を並列接続し、CT は二次側を直列接続する | **正** | 二次側の計器接続も VT 並列／CT 直列 |
| CT の二次側を開放しても問題ない | **誤** | 鉄心磁気飽和で異常高電圧→焼損・感電 |
| VT の二次側を短絡しても問題ない | **誤** | 過大短絡電流で巻線焼損。CT と左右対称 |
| CT は二次側に低インピーダンス負荷を接続する | **正** | 電流計・電流コイル（内部抵抗小） |
| VT は二次側に高インピーダンス負荷を接続する | **正** | 電圧計・電圧コイル（内部抵抗大） |
