# 誘導障害（静電誘導・電磁誘導）

架空送電線が近くの通信線に電圧を誘起して起こす障害。「静電誘導＝電圧由来（静電容量 C）」「電磁誘導＝電流由来（相互インダクタンス M）」の二本立てで、取り違えが最頻の失点源。地絡事故時に大きくなるのは電磁誘導。
**出題頻度:** 中（R07上 問9・H28 問8）
**難易度:** ★★☆（論説・取り違え注意）
**出題形式:** 論説（原因・対策の正誤判定）

## 1.まず結論 — 「電圧由来」か「電流由来」かで割る

架空電線路が、近くの**弱電流電線路**（通信線・信号線など）に電圧を誘起して障害を起こす現象を**誘導障害**という。原因は2種類あり、**どちらも「電圧が原因か／電流が原因か」で一意に決まる**。ここを固定すれば、反対に答えることはなくなる。
30秒アンカー（これだけは絶対に裏返さない）
- **静電**誘導 ＝ 電線路の**電圧**が原因 ＝ **静電容量 C**（コンデンサ結合・電界）
- **電磁**誘導 ＝ 電線路の**電流**が原因 ＝ **相互インダクタンス M**（磁気結合・磁束）

名前がそのままヒント。**「静電」＝静電気＝電荷＝電界＝電圧 → C**、**「電磁」＝電流がつくる磁界＝磁束 → M**。
左: 静電誘導（電圧→電界→静電容量 C）／右: 電磁誘導（電流→磁界→相互インダクタンス M）。原因と結合経路がちょうど裏返しの関係になっている。

## 2.静電誘導 — 電圧由来（容量結合）

**静電誘導**＝送電線の**対地電圧**が、送電線と通信線の間の**静電容量（相互容量）**を介して通信線に電圧を誘起する現象。電線と通信線の間に「目に見えないコンデンサ」があり、通信線と大地の間にもコンデンサがあるため、通信線が分圧されて電位をもつ。**電流が流れていなくても、電圧がかかっていれば常時発生**する（無負荷・充電状態でも生じる）点が急所。
各相と通信線の相互容量 Ca・Cb・Cc と、通信線の対地容量 Cs による分圧。三相が対称で Ca＝Cb＝Cc なら誘起電圧は打ち消し合ってゼロになる。
Y1
**静電誘導電圧（不平衡分・代表式）**
$E_s = \dfrac{\sqrt{C_a{}^2 + C_b{}^2 + C_c{}^2 - C_aC_b - C_bC_c - C_cC_a}}{C_a + C_b + C_c + C_s}\, E$
E＝送電線の対地電圧。Ca＝Cb＝Cc（完全ねん架・対称配置）なら分子がゼロになり Es＝0。だから静電誘導対策の要はねん架と対称配置。
静電誘導の3つの急所
- 原因は**電圧**（電流ではない）。負荷電流ゼロでも発生する。
- 大きさは送電線の**電圧に比例**し、相互容量の**不平衡**で決まる。
- **ねん架・対称配置**で Ca＝Cb＝Cc に近づけると打ち消せる。

## 3.電磁誘導 — 電流由来（磁気結合）・地絡時に急増

**電磁誘導**＝送電線の**電流**が作る**磁束**が、並行する通信線と鎖交し、**相互インダクタンス M**を介して誘導起電力を生じさせる現象（変圧器と同じ原理）。平常時は**三相電流のベクトル和がほぼゼロ**（Ia＋Ib＋Ic≈0）で磁束が打ち消し合うため誘導は小さい。ところが**地絡事故**が起きると三相の対称性が崩れ、大きな**零相電流**（残留電流 3I₀＝地絡電流）が流れて磁束が打ち消されず、通信線に大きな誘導電圧が現れる。**電磁誘導障害が問題になるのは、この地絡事故時**。
送電線電流が作る磁束 Φ が通信線と鎖交し、相互インダクタンス M を介して Em を誘起。平常時は三相の磁束が打ち消し合うが、地絡時は 3I₀ が残って Em が急増する。
Y2
**電磁誘導電圧（地絡事故時）**
$E_m = \omega M \ell \,(3I_0) = 2\pi f\, M \ell \,(3I_0)\;[\text{V}]$
M＝送電線と通信線の相互インダクタンス[H/km]、ℓ＝並行長[km]、3I₀＝地絡電流（零相電流の3倍）[A]。周波数 f・並行長 ℓ・地絡電流が大きいほど、離隔が小さいほど大きくなる。
電磁誘導の急所 — 地絡電流を小さくすれば障害も小さい
Em は**地絡電流 3I₀ に比例**する。だから中性点接地方式が効いてくる：**直接接地は地絡電流が大きく電磁誘導障害も大きい**／**抵抗接地・消弧リアクトル接地は地絡電流を抑えて障害を小さくできる**。加えて**故障を高速遮断**して誘導電圧の継続時間を短くするのも有効。

## 4.静電誘導 vs 電磁誘導（対比表・裏返り防止）

| 項目 | 静電誘導 | 電磁誘導 |
| --- | --- | --- |
| 原因 | **電線路の電圧 V** | **電線路の電流 I** |
| 結合 | 静電容量 C（コンデンサ・電界） | 相互インダクタンス M（磁束・磁界） |
| 比例するもの | 電圧に比例 | 電流に比例 |
| 平常時 | 電圧があれば常時発生（不平衡分） | 三相電流のベクトル和≈0 で小さい |
| 最大になる時 | 常時（無負荷・充電状態でも） | **地絡事故時（3I₀ が流れる）** |
| 代表式 | Es＝√(…)/(ΣC)·E | Em＝ωMℓ·3I₀ |
| 主な対策 | ねん架・対称配置・遮蔽線 | 地絡電流抑制・高速遮断・ねん架・遮蔽線 |

## 5.なぜ反対に間違えるのか — 名前を分解して固定する

名前がそのまま原因を指している
- **「静電」誘導** → 静電気 → 電荷 → 電界 → **電圧**が原因 → 相手は**コンデンサ C**
- **「電磁」誘導** → 電流がつくる磁界 → 磁束 → **電流**が原因 → 相手は**相互インダクタンス M**

試験で迷ったら問題文のキーワードで機械的に振り分ける：「**電圧・充電・無負荷でも**」とあれば**静電**／「**電流・地絡事故・零相電流**」とあれば**電磁**。特に**地絡事故時に問題になるのは電磁誘導**を固定すると、R07上問9・H28問8 のような論説で裏返らない。

## 6.誘導障害の対策

| 区分 | 対策 | 効く理由 |
| --- | --- | --- |
| 共通 | 送電線と通信線の**離隔距離**を大きくする | C も M も距離が離れるほど小さくなる |
| 共通 | **ねん架**（電線の位置を区間ごとに入れ替える） | 相互容量・相互インダクタンスを三相で均等化し打ち消す |
| 共通 | **遮蔽線**（架空地線）の設置・接地 | 誘導を遮蔽線側に肩代わりさせ通信線への誘導を低減 |
| 共通 | 通信線を**ケーブル化し金属遮蔽層を接地** | 電界・磁界を遮蔽して誘起電圧を抑える |
| 静電のみ | **対称配置**（相導体の幾何配置を対称に） | Ca＝Cb＝Cc に近づけて静電誘導電圧を打ち消す |
| 電磁のみ | **中性点を抵抗接地／消弧リアクトル接地** | 地絡電流 3I₀ を小さくして Em を下げる（直接接地は逆に大きい） |
| 電磁のみ | 保護継電器で**故障を高速遮断** | 大きな誘導電圧の継続時間を短くする |

中性点接地方式は「静電」ではなく「電磁」に効く
中性点接地方式（直接／抵抗／消弧リアクトル）が変えるのは**地絡電流の大きさ**なので、効くのは**電磁誘導**側。静電誘導は電圧由来なので中性点接地方式では変わらない。「静電誘導対策に中性点接地」と書いた選択肢は誤り。

## 7.正誤判定の急所

| 命題 | 判定 | 理由 |
| --- | --- | --- |
| 静電誘導は送電線の電流によって生じる | **誤** | 静電誘導の原因は電圧。電流由来は電磁誘導 |
| 電磁誘導障害は地絡事故時に大きくなる | **正** | 3I₀（零相電流）が流れ磁束が打ち消されない |
| 完全なねん架で静電誘導電圧は打ち消される | **正** | Ca＝Cb＝Cc となり Es の分子が 0 |
| 電磁誘導軽減には中性点を直接接地するのがよい | **誤** | 直接接地は地絡電流大→障害大。抵抗／消弧リアクトルが有効 |
| 通信線をケーブル化し遮蔽層を接地すると障害が減る | **正** | 電界・磁界を遮蔽して誘起電圧を抑える |
| 静電誘導は負荷電流が流れていなくても発生する | **正** | 電圧が原因なので無負荷（充電状態）でも生じる |
