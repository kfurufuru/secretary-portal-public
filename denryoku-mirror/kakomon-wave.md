| 配電 変圧器容量 | 過負荷防止・並行運転・遮断器定格 | 並行容量比＝%Z逆比。遮断電流＝短絡容量/(√3・V) |
| 水力 揚水 | 電動機入力・揚程・流量・効率 | $P_{\text{motor}} = \rho g Q H_p/(\eta_{\text{pump}}\,\eta_{\text{motor}})\times 10^{-3}\,[\text{kW}]$ |
| 水力 発電 | 出力・使用水量・有効落差 | $P = 9.8\,\eta Q H\,[\text{kW}]$ 、H=有効落差、η=総合効率 |
| 火力 熱効率 | 重油消費量・CO2排出量・発電電力量 | $\eta = \text{出力}/(\text{燃料量}\times\text{発熱量})$ 。CO2 = 燃料量×C比×44/12 |
| 変圧器 並行 | 負荷分担・過負荷容量 | $P_1/P_2 = (\%Z_2\,S_1)/(\%Z_1\,S_2)$ |
| 原子力 比較 | ウランvs重油の等エネルギー質量比 | $m_{\text{ウラン}} = m_{\text{重油}}\times \text{発熱量}_{\text{重油}}/\text{発熱量}_{\text{ウラン}}$ |

### なぜ出題周期があるのか（因果説明）

電力科目の周期性には3つの構造的理由がある。
- 問番号とテーマの固定配置: 問1=水力、問4=原子力、問14=電気材料という配置は長年の出題慣行としてほぼ固定されている（24回での実測は 問1 92%・問4 92%・問14 96%・問3 96%。公式に明文化された制度ではなく、変わる可能性はある）。周期ではなく「テーマは固定・角度のみ変わる」という構造。
- 計算テーマの難度調整: 計算が集中するB問題（問15〜17）は各10点で配点が大きく差がつきやすい。試験委員は配電・水力・火力という頻出計算テーマの難度を回ごとに均すため、同一テーマを毎回ではなく交互に配置する傾向がある。これが特定計算の「隔年的な出題」の一因とみられる。
- 出題委員の交代サイクル: 出題委員の任期・交代周期は公表されていないが、テーマの「休眠→復活」パターンから作問体制の交代周期が推定される。委員が交代すると「前任者が出したテーマ」は一定期間避けられ、その後復活する。架空送電や地中送電でみられる「2〜3年の空白→再出題」はこのサイクルを反映している可能性が高い。出典・関連
