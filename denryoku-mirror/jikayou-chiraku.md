# 自家用受電設備の地絡保護

高圧で受電する需要家（工場・ビル）の地絡保護。GR と DGR の使い分け、もらい事故（波及事故）の防止が核心。電力科目の保護継電器枠（問8）と法規の自家用電気工作物の双方で問われる横断領域。
**出題頻度:** 高頻度（問8枠・横断）
**難易度:** ★★★
**出題形式:** 穴埋・論説・計算

## 1.直感的理解

自家用受電設備の地絡保護の本質は、**構内の地絡を検出して受電用遮断器を切る**だけでなく、**自分の事故を電力会社の配電系統に波及させない（もらい事故を起こさない・受けない）**ことにある。高圧受電（6.6 kV）する需要家では、この2つを両立させる保護方式が求められる。
地絡保護の骨格（この流れで押さえる）
配電線 6.6 kV → **PAS（区分開閉器）** → 構内引込（高圧 CVT ケーブル）→ **受電用 VCB** → 変圧器 → 低圧負荷。地絡検出は **ZCT（零相電流 I₀）** と **零相電圧センサ（V₀）** で行い、**DGR** が方向を判定して PAS・VCB を切る。
なぜ単純な GR では足りないのか（因果理解）
高圧受電では構内に高圧ケーブル（CVT 等）が引き回される。ケーブルは **対地静電容量が大きい** ため、**構外（系統側）の地絡** が起きると、その零相電圧を受けて構内ケーブルの対地静電容量を通る **充電電流** が ZCT に流れる。大きさだけを見る GR（地絡過電流継電器）はこれを「構内地絡」と誤認し、**健全な自家用設備が不必要に遮断される（もらい事故）**。これを防ぐため、電流の大きさに加え **位相（方向）** を判定する DGR で「電流が構内へ向かうか／系統へ向かうか」を仕分ける。
5秒で思い出す
GR は大きさだけ → ケーブルの充電電流で **もらい事故**。DGR は大きさ＋方向 → 構外地絡では不動作で **波及・もらいを防ぐ**。

## 2.設備を歩く（地絡保護の骨格）

高圧受電設備の主要機器
- **PAS（区分開閉器）** — 電柱上の引込口に設置。GR 付 PAS／DGR 付 PAS とし、構内地絡時に自動で開放して系統への波及を防ぐ。PAS は遮断器ではないが、通常の6.6kV非接地系の地絡電流は短絡電流より十分小さく PAS の地絡遮断定格内のため**地絡時は検出後ただちに開放できる（G動作）**。開放できないのは**短絡電流**で、過電流を検出したら開放せずロック（蓄勢）し、**配電用変電所の遮断器が動作して高圧側が無電圧になってから開放する（SO動作）**。地絡と過電流が同時に発生した場合も SO動作が優先する。この2つを合わせて SOG 動作という。
- **ZCT（零相変流器）** — 三相一括で鉄心を通し、零相電流 I₀（地絡電流相当）を検出。
- **EVT／ZPD（接地形計器用変圧器・零相電圧検出器）** — 零相電圧 V₀ を検出。DGR の方向判定の基準位相を与える。
- **VCB（真空遮断器）** — 受電用遮断器。継電器の指令で実際に電流を遮断する実行側。

GR と DGR の入力の違い（見分けの第一歩）
**GR（地絡過電流継電器）＝ ZCT のみ**（I₀ の大きさだけ）。**DGR（地絡方向継電器）＝ ZCT ＋ 零相電圧センサ**（I₀ の大きさ ＋ V₀ との位相関係）。**零相電圧を採っているか否か**が GR と DGR の見分けの第一歩。その零相電圧センサは**設置場所で呼び名が変わる**——**配電用変電所側は EVT**（接地形計器用変圧器）、**高圧需要家のキュービクル・PAS 内蔵 DGR は ZPD**（零相電圧検出器・コンデンサ形）が通常。「需要家に EVT」と覚えると機器名の穴埋で外す。DGR は「① I₀ が整定値以上」かつ「② V₀ に対する I₀ の位相が構内方向」の両方を満たすときトリップする。

## 3.GR と DGR の比較表（最重要）

| 項目 | GR（地絡継電器） | DGR（地絡方向継電器・67G） |
| --- | --- | --- |
| **入力センサー** | ZCT のみ | ZCT ＋ EVT／ZPD |
| **判定要素** | 零相電流 I₀ の大きさだけ | I₀ の大きさ ＋ 位相（方向） |
| **構外地絡（系統側）** | ケーブル充電電流で誤動作しうる | 不動作（電流が構外方向と判定） |
| **構内地絡** | 動作 | 動作 |
| **もらい事故防止** | ×（できない） | ○（方向判定で防ぐ） |
| **適用** | 構内ケーブルが短い小規模設備 | ケーブルこう長が長い／対地静電容量が大きい設備 |
| **コスト** | 安い（EVT 不要） | 高い（EVT／ZPD が必要） |

出題の核心：なぜ DGR が必要か
「構内の高圧ケーブルが長い（対地静電容量が大きい）ほど、構外地絡時に GR が誤動作しやすい」→ だから **方向判定する DGR** を用いる、という因果が穴埋・論説の頻出論点。

## 4.もらい事故（波及事故）のメカニズム

構外地絡時に GR が誤動作する流れ
1. 構外（他需要家・系統側）で1線地絡が発生 → 系統全体に零相電圧 V₀ が生じる
2. V₀ により、自分の構内ケーブルの対地静電容量へ充電電流が流れる
3. この充電電流（零相分）が ZCT を通過し、GR が I₀ を検出
4. GR は大きさだけを見て「構内地絡」と誤認 → 不要動作（もらい事故）

もらい事故の正体
自分の構内では地絡が起きていないのに、**他者・系統側の地絡が作る零相電圧** によって、**自分のケーブルの対地静電容量を流れる充電電流** を GR が拾ってしまう現象。構内ケーブルが長い（C 大）ほど充電電流が大きく、誤動作しやすい。
DGR がもらい事故を防ぐのは、電流の **向き（位相）** で構内地絡と構外地絡を仕分けられるから。

| 地絡の場所 | I₀ の向き（V₀ 基準） | DGR の判定 |
| --- | --- | --- |
| **構内地絡** | 系統 → 構内（地絡点）へ電流が向かう | **動作**（トリップ） |
| **構外地絡** | 構内（ケーブル C）→ 系統へ充電電流が向かう | **不動作** |

構外地絡では電流の向きが「構外向き（充電電流）」になるため、位相で除外できる。これが DGR がもらい事故を防ぐ原理。

## 5.公式マップ

01
**対地静電容量に流れる地絡電流（容量分）**
$I_{gc} = 2\pi f\, C_3\, E \,[\text{A}]$
C₃＝3線一括の対地静電容量[F]、E＝事故前の対地電圧（相電圧 V/√3）。1線地絡で健全相の対地電圧が上昇し、各相の対地静電容量を通じて充電電流が大地へ流れる。充電電流 ωCV と同型で、ケーブルの C が大きいほど大きい。
02
**1線地絡電流（抵抗分と容量分のベクトル合成）**
$I_g = \sqrt{I_{gr}^2 + I_{gc}^2} \,[\text{A}]$
非接地系（高圧配電）では、抵抗分 I_gr（EVT の制限抵抗・地絡抵抗を流れる成分）と容量分 I_gc（対地静電容量を流れる成分）のベクトル和。
03
**地絡電流の位相（零相電圧 V₀ に対する進み角）**
$\theta = \tan^{-1}\!\left(\dfrac{I_{gc}}{I_{gr}}\right)$
抵抗分 I_gr が容量分 I_gc より十分大きいと位相 θ は小さく、DGR の方向判定が安定する。EVT 二次に制限抵抗を入れて抵抗分を確保するのは、位相を安定させ DGR を確実に動作させるため。
04
**ケーブル1条あたりの対地静電容量（同軸近似）**
$C = \dfrac{2\pi\varepsilon}{\ln(D/d)} \,[\text{F/m}]$
D＝遮へい層（外側電極）径、d＝導体径。高圧ケーブルは D/d が小さく C が大きい → 地絡電流（容量分）が大きい。地中送電のケーブル静電容量と同じ帰結。
なぜ高圧ケーブルで地絡電流が大きいか（地中送電からの帰結）
高圧ケーブル（CVT 等）は導体と遮へい層の距離が数 mm と非常に近く、対地静電容量が架空電線に比べ桁違いに大きい。したがって構内ケーブルが長いほど、対地静電容量に流れる地絡電流（充電電流分）が大きくなり、もらい事故のリスクが上がる。

## 6.CVT 遮へい銅テープの接地と ZCT の関係（実務頻出）

最頻出ミス：接地線を ZCT に通すか通さないか
CVT（高圧ケーブル）の **遮へい銅テープの接地線** を ZCT の **どちら側で処理するか** によって、地絡検出が正しく動いたり・動かなかったりする。実務でも試験でも狙われる。
なぜ接地線を ZCT に通し返すのか（因果理解）
遮へい層には、健全時でもケーブルの対地静電容量を通る充電電流（遮へい電流）が流れている。この電流は ZCT を「行き（導体側）」に通過するので、接地線を ZCT に **通さず** に接地すると、ZCT は充電電流分を「残留＝地絡」と誤検出してしまう。
接地線を **ZCT の窓に通し返して** 接地すると、行きの充電電流と帰りの接地電流が ZCT 内で打ち消し合い（ベクトル和 ≒ 0）、ZCT は真の地絡電流だけを検出できる。

| 接地方法 | ZCT が見る電流 | 結果 |
| --- | --- | --- |
| 接地線を **ZCT に通し返す**（正） | 充電電流が相殺 → 真の地絡分のみ | **正常検出** |
| 接地線を **ZCT を通さず**接地（誤） | 充電電流分が残留 | **誤動作・不検出** |

結論：**遮へいの接地線は ZCT を貫通させて（通し返して）から接地する**。ケーブルヘッドの接地処理の定番論点。
**原理で覚える（構成が変わっても効く）**：判定基準は「**遮へい回路が ZCT の窓を通る正味回数をゼロにする**」の一点。上図のように**遮へいの接地点が ZCT より負荷側**にある標準構成では、シースが窓を1回通るので接地線を**通し返して**打ち消す。逆に**接地点が ZCT より電源側**にある構成では、シースがそもそも窓を通らないので**通し返さない**（通すと相殺が崩れる）。「常に通す」と丸暗記すると構成違いの図で逆を選ぶ。
ZCT は**窓を通る電流のベクトル和**しか見ない。健全時でも遮へい層には充電電流が流れているので、その「行き」と「帰り」を両方とも窓に通せば和がゼロになる——これが通し返しの理由。接地線を窓の外で落とすと帰りだけが窓を通らず、充電電流がまるごと「地絡」に見える。**接地するかどうかではなく、どちら側で窓を通すかの問題**。

## 7.解法パターン

① GR と DGR を見分ける（零相電圧を採っているか）
「EVT があるか」「方向判定するか」「もらい事故を防げるか」の3点セットで判断する。EVT/ZPD なし・大きさのみ・もらい事故を防げない＝GR。EVT/ZPD あり・大きさ＋方向・もらい事故を防げる＝DGR。
② もらい事故の因果を説明する（論説の模範筋道）
1. 高圧ケーブルは対地静電容量が大きい
2. 構外地絡時、零相電圧で充電電流が ZCT を流れる
3. GR は大きさだけ見て誤動作（もらい事故）
4. DGR は位相（方向）で構外地絡を除外できる
5. ゆえにケーブルこう長が長いほど DGR が必要

③ 地絡電流（容量分）の計算
対地静電容量 C₃ ＝ 0.3 μF、6.6 kV 非接地系、f ＝ 50 Hz のときの容量分地絡電流：
1. 対地電圧 $E = 6600/\sqrt{3} \approx 3810\,\text{V}$
2. $\omega = 2\pi f = 2\pi\times 50 = 314\,\text{rad/s}$
3. $I_{gc} = \omega C_3 E = 314\times 0.3\times10^{-6}\times 3810 \approx 0.36\,\text{A}$

④ 地絡電流の合成と位相
抵抗分 I_gr ＝ 0.5 A、容量分 I_gc ＝ 0.36 A のとき：
1. 大きさ $I_g = \sqrt{0.5^2 + 0.36^2} = \sqrt{0.25+0.130} \approx 0.62\,\text{A}$
2. 位相 $\theta = \tan^{-1}(0.36/0.5) \approx 36^\circ$（V₀ に対する進み）
