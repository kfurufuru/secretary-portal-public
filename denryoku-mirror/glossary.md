## 1.水力発電

| 用語 | 定義 |
| --- | --- |
| 水頭（すいとう） | 水がもつエネルギーを水柱の高さ [m] に直した量。重さ 1 N 分の水のエネルギーなので [J/N]＝[m] になる。位置水頭 z・圧力水頭 p/(ρg)・速度水頭 v²/(2g) の3つがあり、その和が全水頭。損失が無ければ全水頭は流れのどこでも一定（ベルヌーイの定理）。英語の head の訳で、実際の高さの差である「落差」とは別物（圧力・流速の分も含む）。 |
| 損失水頭（そんしつすいとう） | 水路・水圧管路の摩擦などで熱になって失うエネルギーを水頭 [m] で表したもの。発電時は総落差から引き（有効落差＝総落差−損失水頭）、揚水時は総落差に足す（全揚程＝総落差＋損失水頭。ポンプは失う分も余計に押し上げる）。 |
| 有効落差（ゆうこうらくさ） | 総落差から損失水頭を引いた実際に利用できる落差。 |
| 流量（りゅうりょう） | 単位時間当たりの水量 [m³/s]。 |
| 流出係数（りゅうしゅつけいすう） | 流域に降った降水（雨・雪）のうち、川へ流れ出る水量の割合（0〜1・単位なし）。残りは主に蒸発散などで川に出ない。流出する水量 [m³] は 流域面積 [m²]×降水量 [m]×流出係数。降水量は地面にたまる水の層の厚みであって、落差ではない（mm で与えられたら m に直す）。川に出た水を全部発電に使うかは別の話で、問題が取水率や溢水を別に与えなければ、流出量を全部使う前提で解く（水力発電ページの例「⑥ 総水量から年間可能発電電力量」と同じ）。 |
| 理論的包蔵水力（りろんてきほうぞうすいりょく） | ある地域に降った水が持つ水力エネルギーを、水車・発電機の効率や水路の損失を見込まずに見積もった量。流出係数は問題の指定に従う（R08上 問2 は「流出係数を 1 とする」と指定）。「理論的」なので効率は掛けない。R08上 問2 は落差を書いていないが、平均海抜を落差とみなすと公表解答 (5) と一致する。総水量 V から入るなら ÷3600 だけ（水力発電ページの例「⑥ 総水量から年間可能発電電力量」で、流出係数・効率・落差を問題の値に置き換えたもの）。平均流量から出力 [kW] を出したなら ×8760 h だけ。両方はしない。単位が [TW·h] なら出力で止めず電力量まで出す。公的統計の「包蔵水力」の定義はここでは一次照合していない。 |
| 流況曲線（りゅうきょうきょくせん） | 1年の日流量を大きい順に並べた曲線。横軸 x 日の値は「1年のうち x 日はこの流量以上ある」ことを表す。調整池の容量や使用流量の計算に使う（R07上 問15）。 |
| 渇水量（かっすいりょう） | 流況曲線で横軸355日の値。「1年のうち355日はこの流量以上ある」という日流量。 |
| ダム（だむ） | 河川をせき止めて水をためる構造物。重力ダム（重さで耐える・日本で最も多い）、アーチダム（両岸の岩盤で支える・両岸の幅が狭い所向き）、ロックフィルダム、アースダム、取水ダムがある。 |
| 突極形（とっきょくけい） | 磁極を回転子から突き出した形の回転子。低速で回る水車発電機に使う。低速で同じ周波数を作るには極数を多くするしかなく（N＝120f/p）、磁極を円周に多く並べるので直径が大きく軸方向に短い。高速のタービン発電機は遠心力に耐えるよう円筒形にする。 |
| ペルトン水車（ぺるとんすいしゃ） | 高落差（目安 300m以上）向けの衝動水車。バケットにジェット水流を当てる。 |
| フランシス水車（ふらんしすすいしゃ） | 中落差（目安 40〜600m）向けの反動水車。最も普及。 |
| カプラン水車（かぷらんすいしゃ） | 低落差（目安 10〜60m）向けのプロペラ型反動水車。羽根が可変。 |
| 適用落差（てきようらくさ） | 水車の種類ごとに適した落差の範囲。各水車には比速度に適した有効落差が決められていて、比速度の大きな水車を大きな落差で使い吸出し管を用いると、放水速度が大きくなってキャビテーションが生じやすくなる（H30 問2）。R01 問2 は、ペルトン水車を高落差で流量の比較的少ない地点、フランシス水車を「一般に，落差 40 m～500 m の中高落差用」、プロペラ水車を流量が多く低落差の発電所に用いるとしている。用語集のフランシス水車の行（目安 40〜600m・中落差）とは上限と呼び方が違う。 |
| 調速機（ちょうそくき） | 水車の流量を調整する装置（ガバナ）。発電機を系統に並列するまでは回転速度を制御し、並列した後は出力を調整し、負荷遮断時などには回転速度の異常な上昇を防ぐ。 |
| 調圧水槽（ちょうあつすいそう） | 負荷変動時の水圧変動を緩和するタンク。 |
| 揚水発電（ようすいはつでん） | 余剰電力で水を上部貯水池に揚げ、需要ピーク時に発電する方式。 |
| 比速度（ひそくど） | ある水車と相似形の水車が1mの落差で単位出力を発生するときの回転速度。ns=n×P^(1/2)/H^(5/4)（n＝回転速度[min⁻¹]、P＝ランナー1個またはノズル1本当たりの出力[kW]、H＝有効落差[m]）。ペルトンが最小・カプランが最大で、落差が低いほど大きい比速度を選ぶ。 |
| キャビテーション（きゃびてーしょん） | 流水中で圧力が低下して気泡が発生し、崩壊時の衝撃でランナなどを壊食する現象。振動・騒音・効率低下の原因。吸出し高さを低くする、比速度を大きくしすぎないことで防止。 |
| 水撃作用（すいげきさよう） | 弁や案内羽根の急閉鎖で管内の流れが急変し、水圧管に大きな圧力変動が生じる現象（ウォータハンマ）。調圧水槽の設置や弁の緩閉鎖で緩和する。 |
| サージタンク（さーじたんく） | 調圧水槽の英名。導水路と水圧管の間に設け、水撃作用による圧力変動を水面の昇降で吸収する。 |
| 吸出し管（すいだしかん） | 反動水車のランナ出口から放水面までを結ぶ管。ランナ出口流速の運動エネルギーを圧力として回収し、落差を有効利用する。衝動水車（ペルトン）には無い。 |
| デフレクタ（でふれくた） | ペルトン水車のノズルの前で噴流をそらし、ランナーに当てないようにする装置。急停止のときに使い、噴流そのものは止めない。流量の調整はノズルの中のニードル弁で行い、急に閉じると水撃作用が起きるのでゆっくり閉じる。 |
| ランナ（らんな） | 水車の回転部（羽根車）。水の持つエネルギーを回転運動に変換する。 |
| 調整池（ちょうせいち） | 1日〜1週間程度の短期間の負荷変動に合わせて発電用水量を調整する池。年間単位で調整する貯水池と区別する。 |
| 速度調定率（そくどちょうていりつ） | 発電機出力の変化に対する回転速度（周波数）変化の割合。（速度変化の割合）÷（出力変化の割合）×100%で、並列運転する発電機の負荷分担を決める。 |
| 水圧管（すいあつかん） | 上水槽または調圧水槽から水車まで水を導く鋼管。水撃作用による圧力上昇に耐える強度が必要。 |

## 2.火力発電

| 用語 | 定義 |
| --- | --- |
| タービン発電機（たーびんはつでんき） | 蒸気タービン・ガスタービンで回す同期発電機。高速回転なので2極が多く、機械的強度から回転子は円筒形で直径が小さい。大容量機は水素冷却。 |
| ランキンサイクル（らんきんさいくる） | 蒸気タービン発電の基本熱サイクル（蒸発→膨張→凝縮→圧縮）。 |
| 再熱サイクル（さいねつさいくる） | 高圧タービンで膨張した蒸気をボイラの再熱器へ戻して再加熱し、中・低圧タービンで再び仕事をさせて効率を高めるサイクル。 |
| 再生サイクル（さいせいさいくる） | タービン抽気でボイラ給水を加熱するサイクル。 |
| コンバインドサイクル（こんばいんどさいくる） | ガスタービンと蒸気タービンを組み合わせた高効率発電方式。 |
| 熱効率（ねつこうりつ） | 発電に利用した熱量/投入した熱量。 |
| 低位発熱量（ていいはつねつりょう） | 燃料の発熱量から水蒸気の蒸発潜熱を引いた値。 |
| ボイラ（ぼいら） | 燃料を燃焼させて蒸気を生成する装置。 |
| 脱硝装置（だっしょうそうち） | 排煙中のNOxを除去する装置。 |
| 脱硫装置（だつりゅうそうち） | 排煙中のSOxを除去する装置。 |
| 衝動タービン（しょうどうたーびん） | 蒸気をノズル（静止側）だけで膨張・加速させ、高速の噴流を動翼に当てた力で回す蒸気タービン。動翼の前後で圧力はほぼ変わらない。水車ではペルトン水車が同じ方式（衝動水車）。 |
| 反動タービン（はんどうたーびん） | 静翼に加えて動翼の中でも蒸気を膨張させ、動翼から噴き出す反動力も使って回す蒸気タービン。動翼の前後でも圧力が下がる。水車ではフランシス水車・カプラン水車が同じ方式（反動水車）。 |
| 汽力発電（きりょくはつでん） | ボイラで発生させた蒸気でタービンを回す発電方式。ランキンサイクルを基本とし、再熱・再生サイクルで効率を高める。 |
| 復水器（ふくすいき） | タービン排気蒸気を冷却水で凝縮して復水に戻す装置。内部を真空に保ってタービンの熱落差を大きくする。熱サイクル中で最大の熱損失源。 |
| 節炭器（せつたんき） | 煙道排ガスの余熱でボイラ給水を予熱する装置（エコノマイザ）。排ガス損失を減らして熱効率を高める。 |
| 過熱器（かねつき） | ボイラで発生した飽和蒸気をさらに加熱して過熱蒸気にする装置。熱効率が向上し、タービン翼の湿り蒸気による浸食も防ぐ。 |
| 再熱器（さいねつき） | 高圧タービンで仕事をした蒸気をボイラへ戻して再加熱する装置。再熱サイクルを構成し、効率向上と低圧タービンの湿り防止に効く。 |
| 給水加熱器（きゅうすいかねつき） | タービンから抽気した蒸気でボイラ給水を予熱する装置。再生サイクルを構成し、復水器で捨てる熱を減らす。 |
| 熱消費率（ねつしょうひりつ） | 電力量1kWhを発生するのに消費した熱量 [kJ/kWh]。小さいほど高効率で、熱効率＝3600÷熱消費率。 |
| タービン室効率（たーびんしつこうりつ） | 蒸気がボイラで受け取った熱に対する、タービン出力の比。熱サイクル効率 ηC とタービン効率 ηT の積（ηC × ηT）。 |
| 電気集じん器（でんきしゅうじんき） | 排ガス中のばいじん（すす・灰）を除く装置。コロナ放電で粒子を帯電させ、集じん電極に静電気力で捕集する。石炭（微粉炭）火力の代表構成では、煙道の空気予熱器と排煙脱硫装置の間に置く。 |
| タービン効率（たーびんこうりつ） | 理想的な熱サイクルで得られる仕事に対する、実際のタービン出力の比（ηT）。熱サイクル効率 ηC と掛けるとタービン室効率になる。 |

## 3.原子力発電

| 用語 | 定義 |
| --- | --- |
| 核分裂（かくぶんれつ） | ウラン235などの重い原子核が中性子を吸収して2つに分裂し、大きなエネルギーと2〜3個の中性子を放出する反応。 |
| 質量欠損（しつりょうけっそん） | 核反応の前後で減少する質量。E=mc²に従いエネルギーとして放出される。ウラン235の核分裂1回で約200MeV。 |
| 軽水炉（けいすいろ） | 軽水（普通の水）を減速材と冷却材に兼用する原子炉。日本の商用炉の主流でBWRとPWRに分かれる。燃料は低濃縮ウラン。 |
| 沸騰水型原子炉（BWR）（ふっとうすいがたげんしろ） | 炉心で直接沸騰させた蒸気をそのままタービンへ送る軽水炉。構造が簡単だが、タービン系も放射性物質を含む蒸気に触れる。 |
| 再循環ポンプ（さいじゅんかんぽんぷ） | 沸騰水型原子炉（BWR）に特有の設備（H27 問4）。加圧水型（PWR）に特有の設備は加圧器・蒸気発生器・一次冷却材ポンプで、区別して覚える。 |
| 加圧水型原子炉（PWR）（かあつすいがたげんしろ） | 一次系を加圧して沸騰させず、蒸気発生器で二次系の水を蒸気にしてタービンへ送る軽水炉。タービン系は放射性物質と分離される。 |
| 減速材（げんそくざい） | 核分裂で生じる高速中性子を、核分裂を起こしやすい熱中性子まで減速させる材料。軽水炉では水。 |
| 冷却材（れいきゃくざい） | 炉心で発生した熱を外へ運ぶ流体。軽水炉では水が減速材を兼ねる。 |
| 制御棒（せいぎょぼう） | 中性子をよく吸収する材料（ほう素・カドミウムなど）の棒。炉心への出し入れで核分裂連鎖反応の速さを制御する。 |
| 臨界（りんかい） | 核分裂で生じる中性子と、吸収・漏れで失われる中性子が釣り合い、連鎖反応が一定の割合で持続する状態。 |
| 崩壊熱（ほうかいねつ） | 原子炉停止後も核分裂生成物の放射性崩壊で発生し続ける熱。停止後も炉心冷却を続ける必要がある理由。 |
| 核燃料サイクル（かくねんりょうさいくる） | ウランの採鉱・濃縮・成形加工から、使用済み燃料の再処理でウラン・プルトニウムを回収して再利用するまでの一連の流れ。 |
| 中性子（ちゅうせいし） | 電荷を持たない核子。ウラン235に吸収されると核分裂を引き起こし、連鎖反応の担い手となる。 |
| 天然ウラン（てんねんうらん） | 濃縮していないウラン。核分裂しやすい U-235 を約0.7%しか含まない。軽水炉は軽水が中性子を吸うので、U-235 を2〜5%に濃縮した燃料が要る。減速材が中性子をほとんど吸わなければ、天然ウランのままでも臨界を保てる。重水（中性子の吸収が軽水の数百分の1）を使う CANDU 炉がその例。 |
| 高速増殖炉（こうそくぞうしょくろ） | 速い中性子（高速中性子）を使う原子炉。U-238 が中性子を吸収して Pu-239 に転換される反応は軽水炉でも起き、使用済み燃料に Pu が含まれるのはこのため。高速増殖炉は、U-238 が高速中性子を吸収して、消費した Pu-239 より多くの Pu-239 ができる（増殖）点が違う。R07下 問4 では「U-238 が速度の遅い熱中性子を吸収して核分裂を起こし」が誤り。 |

## 4.新エネルギー

| 用語 | 定義 |
| --- | --- |
| 太陽電池（たいようでんち） | pn接合半導体の光起電力効果で、光エネルギーを直接直流電力に変換する素子。可動部がなく保守が容易。 |
| 太陽光発電（たいようこうはつでん） | 太陽電池の直流出力をパワーコンディショナで交流に変換して利用する発電。出力は日射量に左右され、余剰は逆潮流で系統へ送る。 |
| 風力発電（ふうりょくはつでん） | 風の運動エネルギーで風車を回して発電する方式。理論上の出力は受風面積と風速の3乗に比例する。 |
| 二次電池（にじでんち） | 充電して繰り返し使える電池（使い切りは一次電池）。代表はリチウムイオン電池。風力・太陽光と組み合わせると、出力の変動を平滑化できる。 |
| 燃料電池（ねんりょうでんち） | 水素と酸素を電気化学反応させて化学エネルギーを直接直流電力に変換する装置。水の電気分解の逆反応で、排熱も給湯などに利用できる。 |
| 地熱発電（ちねつはつでん） | 地下から噴出する蒸気・熱水でタービンを回す発電。ボイラと燃料が不要で、出力は天候に左右されない。 |
| バイオマス（ばいおます） | 動植物由来の有機資源（木くず・廃棄物など）を燃料とする発電。燃焼でCO2を出すが、成長過程の吸収と相殺されるカーボンニュートラルな電源とされる。 |
| 設備利用率（せつびりようりつ） | 発電設備が1年間ずっと定格出力で運転したとした電力量に対する、実際の年間発電電力量の割合。設備利用率 = E [kWh] ÷（定格出力 [kW] × 8760 h）× 100 [%]。8760 h は1年＝365日。問題文に運転時間や日数が与えられたら、それを使う。 |

## 5.変電

| 用語 | 定義 |
| --- | --- |
| 変圧器（へんあつき） | 電圧を変換する機器。1次・2次の巻き数比で電圧が決まる。 |
| 短絡試験（たんらくしけん） | 変圧器の二次側を短絡し、一次側に定格周波数の電圧を加えて行う試験。定格電圧を加えるのではなく、電流計が所定の値を示すように一次側の電圧を調整し、電圧・電流・電力を測る（R04上 機械 問8・R07下 機械 問9）。励磁回路を無視すると、測った値から一次側からみた漏れインピーダンスと、一次側からみた（一次換算の）巻線抵抗が求まり、漏れリアクタンスが出る。 |
| 鉄損（てつそん） | 磁束の変化により鉄心に生じる損失（ヒステリシス損＋渦電流損）。負荷に無関係。 |
| 銅損（どうそん） | 電流が巻き線の抵抗を流れることで生じる損失。負荷電流の2乗に比例。 |
| 最大効率（さいだいこうりつ） | 鉄損＝銅損となる負荷時に変圧器効率が最大になる。 |
| パーセントインピーダンス（ぱーせんといんぴーだんす） | 定格電流を流したとき変圧器の内部インピーダンスによる電圧降下の定格（相）電圧に対する比（%）。 |
| 遮断器（CB）（しゃだんき） | 通常の負荷電流の開閉に加え、短絡などの事故電流も遮断できる開閉装置。電流を切るときに出るアークを消す能力（消弧能力）が要る。 |
| 断路器（DS）（だんろき） | 無負荷（電流がほぼゼロ）の状態で回路を開閉する機器。電圧が掛かっていても開閉はできるが、負荷電流の遮断は不可。 |
| 過電流継電器（OCR）（かでんりゅうけいでんき） | 設定値以上の電流が流れると動作して遮断器を制御する継電器。 |
| タイムレバー（たいむればー） | 過電流継電器（OCR）の動作時間の倍率を決める目盛り。動作時間はタイムレバーの位置に比例する。限時特性図がレバー位置10で描かれているとき、位置 n の動作時間は特性図の時間の n/10 倍。動作し始める電流を決める電流タップと区別する（R05下 問16(b)）。 |
| 地絡継電器（GR）（ちらくけいでんき） | 地絡事故を検出する継電器。 |
| GIS（じーあいえす） | ガス絶縁開閉装置。SF6ガスで絶縁・アーク消弧。小型化が可能。 |
| 計器用変成器（けいきようへんせいき） | 高電圧・大電流を計器や保護継電器が扱える小さな値に変換する機器の総称。電圧用のVTと電流用のCTがある。 |
| 計器用変圧器（VT）（けいきようへんあつき） | 高電圧を110Vなどの低電圧に変換する変成器。二次側を短絡すると大電流が流れて焼損するため短絡厳禁。 |
| 変流器（CT）（へんりゅうき） | 大電流を5Aなどの小電流に変換する変成器。通電中に二次側を開放すると高電圧が発生して危険なため開放厳禁。VT（短絡厳禁）との対比が引っかけどころ。 |
| 零相変流器（ZCT）（れいそうへんりゅうき） | 三相分の電線を一括して貫通させ、平常時はゼロになる三相電流のベクトル和（＝零相電流の3倍）を検出する変流器。地絡時に現れる残留電流を地絡継電器へ伝える。 |
| 母線（ぼせん） | 変電所内で発電機・変圧器・送電線などの回路を共通に接続する導体。単母線・二重母線などの方式があり、信頼度と経済性で使い分ける。 |
| 調相設備（ちょうそうせつび） | 無効電力を供給・吸収して電圧を調整する設備の総称。進み側の電力用コンデンサ、遅れ側の分路リアクトル、連続調整できる同期調相機・SVCなど。 |
| 中性点接地方式（ちゅうせいてんせっちほうしき） | 系統の中性点の接地方法。直接接地・抵抗接地・消弧リアクトル接地・非接地があり、地絡電流の大きさと健全相の電圧上昇・誘導障害がトレードオフになる。 |
| 直接接地（ちょくせつせっち） | 中性点を直接接地する方式。健全相の電圧上昇が小さく機器絶縁を低減できるが、地絡電流が大きく誘導障害も大きい。187kV以上の超高圧系統で採用。 |
| 抵抗接地（ていこうせっち） | 中性点を抵抗を介して接地する方式。地絡電流を抑えて誘導障害を軽減しつつ、地絡継電器の動作に必要な電流は確保する。 |
| 消弧リアクトル接地（しょうこりあくとるせっち） | 送電線の対地静電容量と並列共振するリアクトルで中性点を接地する方式。1線地絡時のアークを自然に消滅させる。 |
| 非接地方式（ひせっちほうしき） | 中性点を接地しない方式。地絡電流は小さいが、1線地絡時に健全相の対地電圧が変化する（地絡抵抗0の完全地絡では2相とも√3倍に上昇。地絡抵抗があると倍率は相ごとに変わり、√3倍を超える相も、平常時より下がる相も出る）。6.6kV高圧配電系統で採用。 |
| 短絡電流（たんらくでんりゅう） | 短絡事故時に流れる大電流。三相短絡電流は 基準電流×100÷%Z で求める（%Z は短絡点までの合成値を同じ基準容量にそろえたもの、基準電流はその基準容量に対する電流）。遮断器の定格遮断電流はこれを上回る必要がある。 |
| 短絡容量（たんらくようりょう） | 短絡点から見た系統の強さを表す皮相電力。√3×定格（線間）電圧×短絡電流。大きすぎると遮断できないため、限流リアクトルや系統分割で抑制する。 |
| 定格遮断電流（ていかくしゃだんでんりゅう） | 遮断器が定格条件で確実に遮断できる電流の限度。設置点の短絡電流より大きい値を選定する。 |
| 真空遮断器（VCB）（しんくうしゃだんき） | 高真空中でアークを拡散させて消弧する遮断器。小型で保守が容易、火災の心配がなく、高圧受電設備で広く使われる。 |
| ガス遮断器（GCB）（がすしゃだんき） | SF6（六ふっ化硫黄）ガスを使う遮断器。電流を遮断するときに発生するアークに圧縮ガスを吹き付けて、早く消弧する。電圧が高い系統では、真空遮断器よりガス遮断器が広く使われる（H28 問7）。SF6 は同じ圧力の空気より絶縁破壊電圧が高く、消弧能力も空気より優れるが、温室効果ガスなので使用量の削減や回収が求められる（R07上 問14・H28 問7）。SF6 がアーク放電を発生させないとする記述は誤り（R04上 問14）。アークは発生し、それを早く消す。 |
| 負荷開閉器（ふかかいへいき） | 負荷電流の開閉はできるが短絡電流は遮断できない開閉装置。短絡遮断は遮断器、無負荷開閉は断路器、という役割分担が頻出。 |
| 高圧交流負荷開閉器（こうあつこうりゅうふかかいへいき） | 負荷電流、変圧器の励磁電流、線路電流など、負荷開閉器の定格電流以下の電流の開閉に使う高圧の開閉器（R06下 問11。受電設備内の LBS をこの名で呼んでいる）。区分開閉器として使う PAS も、公表問題では「地絡方向継電装置付高圧交流負荷開閉器（DGR付PAS）」と呼ぶ（R04下 法規 問9・R07上 法規 問10）。遮断器・断路器との役割分担は「負荷開閉器」の行を参照。 |
| 地中線用ガス開閉器（UGS）（ちちゅうせんようがすかいへいき） | 地中配電線路に使う、ガス絶縁方式の開閉器。配電用機材の「ガス開閉器」は六ふっ化硫黄（SF6）と結びつく（R05上 問8）。地中配電線路に用いられる開閉器ではガス絶縁方式は採用されない、とする記述は誤り（H28 問11）。Wiki本文では、需要家の地中引込に置く区分開閉器（UGS）をこの名で呼ぶ。 |
| 比率差動継電器（ひりつさどうけいでんき） | 保護区間に流入・流出する電流の差から内部故障を検出する継電器。変圧器保護の主力で、励磁突入電流による誤動作を抑制する工夫がされる。 |
| 距離継電器（きょりけいでんき） | 設置点の電圧と電流の比からインピーダンス（故障点までの電気的距離）を測定して動作する継電器。送電線の保護に使う。 |
| 段階保護（だんかいほご） | 距離継電器の保護範囲を、1段（瞬時）・2段（短時限）・3段（長時限）の3段に分けて広い範囲をカバーする方式。距離継電器が測るのは電気的距離（インピーダンス V/I）で、物理的な距離そのものではない。 |
| 酸化亜鉛形避雷器（さんかあえんがたひらいき） | 酸化亜鉛（ZnO）素子の優れた非直線抵抗特性を利用した避雷器。常時はほぼ絶縁体で過電圧時のみ電流を流すため、直列ギャップを省略できる。 |
| 第3高調波（だいさんこうちょうは） | 基本周波数の3倍の周波数の成分。変圧器の励磁電流には第3高調波が含まれ、Δ結線があればその中を環流して吸収される（R04下 問7）。Δ結線が無いと、誘導起電力（相電圧）は第3高調波を含むひずみ波形になる。中性点を接地すると第3高調波電流が線路の静電容量を介して大地に流れ、通信線への電磁誘導障害の原因になる。このため Y-Y 結線の変圧器には Δ結線の三次巻線を設ける（H25 問6・H29 問7。問題文の表記は「第三調波」）。 |
| もらい事故（もらいじこ） | 自家用設備の外（系統側）で起きた地絡のとき、構内の高圧ケーブルの対地静電容量を通る充電電流が ZCT に流れ、構内ケーブルが長くてこの電流が整定値を超えると、大きさだけを見る地絡継電器（GR）が誤動作して、健全な構内を遮断してしまうこと。零相電流の向きも見る地絡方向継電器（DGR）で防ぐ。 |
| 波及事故（はきゅうじこ） | 自家用電気工作物の事故（構内の地絡など）で、電力会社の配電線などまで停電させ、他の需要家に供給支障を起こすこと。電気関係報告規則 第3条第1項の表 第十二号（送配電事業者の電気工作物と電気的に接続された電圧 3000 V 以上の自家用電気工作物の破損・誤操作・操作しないことにより、一般送配電事業者・配電事業者・特定送配電事業者に供給支障を発生させた事故）に当たり、事故報告の対象になる。ただし、配電線が自動的に再閉路されて供給の停止が終わった場合は供給支障事故に当たらない（同規則 第1条第2項第七号）。構内地絡を、配電用変電所より先に動作するよう整定した受電点の PAS・受電用遮断器で切り離して防ぐ。構外の事故で自分が止まる「もらい事故」とは向きが逆。 |
| 構内地絡・構外地絡（こうないちらく・こうがいちらく） | 自家用設備の ZCT より負荷側（構内）で起きた地絡が構内地絡、系統側（構外）で起きた地絡が構外地絡。地絡方向継電器（DGR）は、零相電圧に対する零相電流の位相（向き）で両者を区別し、構内地絡だけで動作する。 |
| 整定値（せいていち） | 保護継電器が動作する境目として設定しておく値（電流・電圧・時間など）。例: 地絡方向継電器（DGR）は、零相電流と零相電圧がそれぞれ整定値以上で、かつ位相の条件を満たすと動作する。 |
| 定限時特性（ていげんじとくせい） | 整定値を超えた電流の大きさに関わらず、一定の時間で動作する継電器の特性。動作時間が読みやすく、上流と下流の継電器の協調をとりやすい。 |
| 反限時特性（はんげんじとくせい） | 電流が大きいほど短い時間で動作する継電器の特性。重大な事故ほど早く遮断できる。線路の過電流継電器（OCR）で一般的。 |
| 時限協調（じげんきょうちょう） | 直列に並ぶ保護継電器の動作時間に差をつけ、事故点に近い下流が先に動作し、上流は後から動作するようにすること。上流は、下流が事故を切れなかったときのバックアップになる。 |
| 器具番号（きぐばんごう） | 保護継電器などの種類を表す番号。例: 過電流継電器（OCR）＝51、地絡過電流継電器（OCGR）＝51G、地絡方向継電器（DGR）＝67G、不足電圧継電器＝27、過電圧継電器＝59、地絡過電圧継電器（OVGR）＝64（59 と混同しない）、差動継電器＝87。距離継電器＝44（JEM 1090。米国 ANSI では 21）。 |
| トリップ指令（とりっぷしれい） | 保護継電器が遮断器へ送る、遮断の指令。受けた遮断器は操作機構で接触子を開き、そのとき生じるアークを消弧して電流を断つ。 |
| 消弧媒体（しょうこばいたい） | 遮断器が接触子を開いたときに生じるアークを消す媒体。油・空気・SF₆ ガス・真空があり、その違いで遮断器の種類が決まる。 |
| 位相変位（いそうへんい） | 三相変圧器の一次と二次の、対応する電圧の位相の差（角変位）。Y-Y・Δ-Δ は 0°、標準結線（Yd1／Dy11）では、一次と二次の線間電圧どうしを比べて Y-Δ は二次が 30° 遅れ、Δ-Y は 30° 進む（符号は巻線の組み方で決まる）。角変位が異なる変圧器は並行運転できない。 |
| 二次開放（にじかいほう） | 変圧器や変流器（CT）の二次側に何もつながず、開いた状態。変圧器の無負荷試験は二次開放で行う。通電中の CT の二次開放は、鉄心が飽和して二次に異常な高電圧が出るので厳禁。 |

## 6.送電

| 用語 | 定義 |
| --- | --- |
| 電圧降下（でんあつこうか） | 送電線のインピーダンスによる送電端と受電端の電圧差。 |
| 電力損失（でんりょくそんしつ） | 送電線の抵抗による発熱損失。三相3線式は 3I²R、単相2線式は 2I²R（I は線電流、R は1線当たりの抵抗）。 |
| 力率改善（りきりつかいぜん） | 進相コンデンサ等で力率を1に近づけ、無効電力を減らすこと。 |
| ACSR（えーしーえすあーる） | 鋼心アルミより線。軽量で引張強度が高い送電線用電線。 |
| 弛度（たるみ）（しど） | 電線が自重でたわんだ量。温度上昇や着雪で増加。 |
| 実効値（じっこうち） | 交流の実効的な大きさ（瞬時値の2乗平均の平方根）。正弦波では最大値の1/√2。 |
| スキン効果（すきんこうか） | 交流で電流が導体表面に偏る現象。周波数が高く断面が大きいほど顕著で、商用周波でも大断面の導体では効く。 |
| フェランチ効果（ふぇらんちこうか） | 軽負荷・無負荷時に受電端電圧が送電端電圧より高くなる現象。フェランチ現象とも呼び、試験の題名では「送電線のフェランチ現象」と書かれる。 |
| 架空地線（かくうちせん） | 鉄塔頂部に電力線とは別に張る接地された線。直撃雷から電力線を遮へいし、誘導雷サージも軽減する。遮へい角が小さいほど遮へい効果が高い。 |
| がいし（がいし） | 電線を支持物から絶縁して支持する磁器製などの器具。懸垂がいしは連結個数で絶縁強度を調整する。塩害地区では過絶縁やがいし洗浄で対策。 |
| アークホーン（あーくほーん） | がいし連の両端に取り付ける金具。フラッシオーバ時のアークをがいしから離れた場所に誘導し、がいしの破損を防ぐ。 |
| 多導体（たどうたい） | 1相あたり2本以上の電線をスペーサで間隔を保って並列に使う方式。等価半径が大きくなってコロナ開始電圧が上がり、インダクタンス減・静電容量増となる。超高圧送電で標準。 |
| コロナ放電（ころなほうでん） | 電線表面の電位の傾きが空気の絶縁耐力（標準状態で波高値約30kV/cm）を超えて起こる局部放電。電力損失・雑音・電線腐食の原因で、太い電線や多導体で防ぐ。 |
| ねん架（ねんが） | 送電線各相の配置を区間ごとに入れ替え、線路全体で三相の線路定数を平衡させること。電圧・電流の不平衡と通信線への誘導障害を抑える。 |
| 誘導障害（ゆうどうしょうがい） | 送電線が近接する通信線などへ電圧・電流を誘導して生じる障害。静電容量を介する静電誘導障害と、相互インダクタンスを介する電磁誘導障害があり、1線地絡時の電磁誘導が特に問題。 |
| 離隔距離（りかくきょり） | 2つの設備の間に空ける距離。誘導障害では、送電線と通信線の離隔距離を大きくすると、静電誘導（静電容量 C）と電磁誘導（相互インダクタンス M）の両方が小さくなる。中性点の接地方式は地絡電流を変えるので電磁誘導に効くが、常時の静電誘導には効かない。この点と区別する。電線と建造物などの離隔（法規）とは別の文脈。 |
| 逆フラッシオーバ（ぎゃくふらっしおーば） | 鉄塔や架空地線への雷撃で鉄塔の電位が上昇し、がいし連を鉄塔側から電線側へ放電が飛ぶ現象。塔脚接地抵抗を下げて防止する（逆フラッシオーバーとも書く）。 |
| 塔脚接地抵抗（とうきゃくせっちていこう） | 鉄塔の接地抵抗。大きいと雷撃時に鉄塔の電位が上がり逆フラッシオーバの原因になる。埋設地線を設けて低減する。 |
| 埋設地線（まいせつちせん） | 「塔脚の地下に放射状に埋設された接地線，あるいは，いくつかの鉄塔を地下で連結する接地線をいい，鉄塔の塔脚接地抵抗を小さくし，逆フラッシオーバを抑止する目的等のため取り付けるもの」（R04下・R05下 問8 (5)。どちらも正しい選択肢）。 |
| 線路定数（せんろていすう） | 送電線の抵抗・インダクタンス・静電容量・漏れコンダクタンスの4定数。主に電線の太さ・材質・配置で決まり、電圧や電流の大きさにはほとんど影響されない（ただし抵抗は温度と周波数〈表皮効果〉で変わり、漏れコンダクタンスはコロナが出る高電圧で増える）。 |
| 静電容量（せいでんようりょう） | 電線と大地間・電線相互間に形成されるコンデンサ成分。充電電流やフェランチ効果の原因になり、ケーブルは架空線よりはるかに大きい。 |
| 充電電流（じゅうでんでんりゅう） | 線路の静電容量に流れる進み位相の電流。無負荷でも流れ、ケーブル系統で特に大きい。フェランチ効果の原因。 |
| 送電容量（そうでんようりょう） | 送電線で送ることのできる電力の限度。電線の許容電流・電圧降下・安定度などで決まる。 |
| 電位傾度（でんいけいど） | 電界の強さ。1 cm あたりに何 kV かかるか（kV/cm）で表す。電線では導体表面で最大になり、これが空気の臨界電界（標準状態で波高値約 30 kV/cm、実効値約 21 kV/cm）を超えるとコロナ放電が起きる。 |
| 遮蔽線（しゃへいせん） | 送電線による誘導障害を減らすために設ける導線。ねん架とともに、静電誘導・電磁誘導の対策として挙げられる。 |
| 対称配置（たいしょうはいち） | 送電線の各相の導体を、通信線に対して幾何的に対称に配置すること。各相と通信線の静電容量（Ca＝Cb＝Cc）がそろい、平常時の静電誘導電圧を打ち消す。相互インダクタンスもそろうので平常時の電磁誘導の打ち消しにも働くが、地絡時の零相分は残る。 |

## 7.地中送電

| 用語 | 定義 |
| --- | --- |
| XLPE（えっくすえるぴーいー） | 架橋ポリエチレン絶縁。地中ケーブルの主流。耐熱性・絶縁性に優れる。 |
| OFケーブル（おいるふぃるどけーぶる） | 絶縁油を充填した油浸紙絶縁ケーブル。高電圧対応。 |
| CVTケーブル（しーぶいてぃーけーぶる） | 単心CVケーブル3本をより合わせたトリプレックス形ケーブル。3心共通シース形より放熱が良く許容電流を大きくとれ、端末処理も容易。 |
| 単心ケーブル（たんしんけーぶる） | 1条のケーブルに導体（線心）が1つだけ入ったケーブル。単心 CV ケーブル3条をより合わせたものが CVT ケーブル（トリプレックス形）で、3心共通シース形 CV ケーブルより熱抵抗が小さく、電流容量を大きくできる（H30 問11・R07上 問10）。 |
| 誘電損（ゆうでんそん） | ケーブルの絶縁体に交流電圧がかかることで絶縁体内部に生じる損失。電圧の2乗・周波数・静電容量・誘電正接tanδに比例する。 |
| 誘電正接（ゆうでんせいせつ） | 絶縁体の誘電損の大きさを表す指標（tanδ）。絶縁劣化が進むと増加するため、絶縁診断の指標に使われる。 |
| 許容電流（きょようでんりゅう） | 連続して流せる電流の上限。絶縁体の最高許容温度で決まり、ケーブルでは布設条件や土壌の放熱性にも左右される。 |
| シース損（しーすそん） | ケーブルの金属シースに誘導される電流による損失。低減する方法として、クロスボンド接地方式の採用が効果的（H25 問10）。ただしシース損には種類があり、効く対策が種類で違う（H29 問10 で出題）。内訳は「地中送電」のページを参照。 |
| 最高導体温度（さいこうどうたいおんど） | 電線・ケーブルの導体に許される最高の温度。ここでは常時の値（常時導体最高許容温度）を指す。ケーブルの許容電流は、導体温度が絶縁体の最高許容温度を超えない上限の電流として決まる（H29 問10）。CV ケーブルは OF ケーブルより常時導体最高許容温度が高く、送電容量の面で有利（H30 問11）。 |
| 故障点標定（こしょうてんひょうてい） | 地中ケーブルの故障位置を地上からの測定で特定すること。ブリッジ回路を使うマーレーループ法、パルスの反射時間で測るパルスレーダ法などがある。 |
| 直接埋設式（ちょくせつまいせつしき） | ケーブルを防護物とともに地中へ直接埋める布設方式。工事費が安く放熱も良いが、増設や張替えが困難。 |
| 管路式（かんろしき） | あらかじめ埋設した管路にケーブルを引き入れる布設方式。増設・張替えが容易だが、条数が多いと相互加熱で許容電流が小さくなる。 |
| 暗きょ式（あんきょしき） | 洞道（共同溝など）内の受け棚にケーブルを布設する方式。多条数の布設と保守点検が容易で、都市部の幹線に使われる。 |

## 8.配電

| 用語 | 定義 |
| --- | --- |
| 電圧降下率（でんあつこうかりつ） | 電圧降下を受電端電圧で割った割合 (Vs−Vr)/Vr×100 [%]。送電端電圧で割ると誤り（R05上 問17(b) は 5.1 % が正答、送電端基準の 4.9 % は誤りの選択肢）。 |
| 樹枝状方式（じゅしじょうほうしき） | 変電所から放射状に配電する最もシンプルな方式。 |
| ループ方式（るーぷほうしき） | 配電線をリング状に結ぶ方式。信頼性が高い。 |
| スポットネットワーク方式（すぽっとねっとわーくほうしき） | 複数回線から変圧器を並列に接続。大容量需要家向け。 |
| ネットワークプロテクタ（ねっとわーくぷろてくた） | スポットネットワーク方式・低圧ネットワーク方式で、ネットワーク変圧器の二次側に置く保護装置。プロテクタヒューズ・プロテクタ遮断器・電力方向継電器で構成される（H23 問12）。変圧器の一次側には断路器を置く（H27 問12）。一次側にネットワークプロテクタ、二次側に断路器を置くとする記述は誤り（R08上 問11）。低圧ネットワーク方式では、これを置くことで変圧器一次側の遮断器やヒューズを省略できる（R04下 問13）。 |
| 低圧バンキング方式（ていあつばんきんぐほうしき） | 同一高圧線に接続した複数の変圧器の低圧側を並列接続。 |
| 力率（りきりつ） | 有効電力/皮相電力 = cosφ。1に近いほど効率が良い。 |
| 進相コンデンサ（しんそうこんでんさ） | 遅れ無効電力を補償して力率を改善するコンデンサ。 |
| 変圧器タップ（へんあつきたっぷ） | 変圧器の巻き数を切り替えて電圧を調整する端子。タップを切り替えて巻数比を変えることをタップ調整という。柱上変圧器のタップ調整は低圧配電線路の電圧を調整する（R04下 問12）。配電用変電所の負荷時タップ切換変圧器（LRT）が負荷変動に応じて母線電圧を調整するのとは区別する。 |
| PAS（ぱす） | 柱上気中開閉器。地絡電流を検出して自動開放する。 |
| 柱上変圧器（ちゅうじょうへんあつき） | 電柱上に設置して高圧6.6kVを100V/200Vに降圧する変圧器。単相3線式で引き出すことが多い。 |
| 高圧カットアウト（こうあつかっとあうと） | 柱上変圧器の一次側に設ける開閉器。内蔵する高圧ヒューズで変圧器の過負荷・短絡を保護する。 |
| 単相3線式（たんそうさんせんしき） | 電圧線2本と中性線1本で100Vと200Vの両方を供給する方式。中性線の断線で不平衡負荷の軽負荷側に過電圧がかかるのが頻出の引っかけ。 |
| 三相3線式（さんそうさんせんしき） | 3本の電線で三相電力を供給する方式。高圧配電線は6.6kV三相3線式が標準。同一電力・同一電圧・同一損失・同一距離の条件で比べると、電線の総重量は単相2線式の3/4で済む。 |
| V結線（ぶいけっせん） | 単相変圧器2台で三相を供給する結線。出力はΔ結線（3台）の1/√3＝57.7%、変圧器利用率は86.6%。 |
| バランサ（ばらんさ） | 単相3線式配電線の末端に設ける巻数比1対1の単巻変圧器。両外線の電圧不平衡を是正し、中性線の電流を打ち消す。 |
| 中性線（ちゅうせいせん） | 単相3線式の中央の接地された電線。断線すると軽負荷側の電圧上昇で機器を焼損するおそれがあり、中性線には過電流遮断器を（単独で）施設しない。 |
| 需要率（じゅようりつ） | 最大需要電力を設備容量の合計で割った百分率。通常100%以下。 |
| 負荷率（ふかりつ） | 平均需要電力を最大需要電力で割った百分率。100%に近いほど設備が平準的に使われている。対象期間（日・月・年）で値が変わる。変圧器の効率計算でいう負荷率（実負荷÷定格容量）とは別の量。 |
| 不等率（ふとうりつ） | 各需要家の最大需要電力の合計を合成最大需要電力で割った値。最大需要の発生時刻のずれを表し、常に1以上。 |
| 高調波（こうちょうは） | 基本波（50/60Hz）の整数倍の周波数成分。パワーエレクトロニクス機器などから発生し、進相コンデンサの過熱・焼損の原因。直列リアクトルで流入を抑える。 |
| 逆潮流（ぎゃくちょうりゅう） | 需要家側から系統側へ向かう有効電力の流れ（無効電力は含めない）。太陽光発電の余剰電力で生じ、大量連系時は配電線の電圧上昇が問題になる。 |
| 単独運転（たんどくうんてん） | 系統側が停電しているのに分散型電源が局所的に送電を続けてしまう状態。感電・機器損傷の危険があるため、検出して直ちに解列する。検出には、周波数・電圧に意図的な変動を与える能動的方式と、周波数・電圧の急変をとらえる受動的方式がある。 |
| 相電圧（そうでんあつ） | 三相交流で、各相の電圧（Y 結線では各相と中性点の間の電圧）。Y 結線では線間電圧の 1/√3（中性点を接地していれば対地電圧に等しい）。Δ 結線では相電圧＝線間電圧。地絡保護で使う零相電圧 V₀ とは別の量。 |

## 9.電力系統・需給

| 用語 | 定義 |
| --- | --- |
| 周波数調整（しゅうはすうちょうせい） | 発電と需要のバランスを保ち系統周波数を50/60Hzに維持すること。 |
| 負荷周波数制御（LFC）（ふかしゅうはすうせいぎょ） | 系統周波数のズレを検出して発電機出力を自動制御する。 |
| 電力系統安定度（でんりょくけいとうあんていど） | 擾乱後も同期運転を維持できる能力（定態・過渡・動態安定度）。 |
| 定態安定度（ていたいあんていど） | 電力系統安定度（定態・過渡・動態）の1つ。定常状態で、小さな負荷変動などの擾乱に対して同期を保てる度合い。送電電力の上限（定態安定限界）を超えて運用しなければよい。最大送電電力は Pmax＝VsVr／X（Vs・Vr は線間電圧、X は1線のリアクタンス。三相の値）なので、X を小さくする（送電線の並列化・多導体化・直列コンデンサ）か、電圧を高く保つと上限が上がる。 |
| 過渡安定度（かとあんていど） | 電力系統安定度（定態・過渡・動態）の1つ。短絡・地絡のような大きな擾乱のあとも、発電機が同期を保てるかの度合い。事故で発電機が加速して他機との位相差が急に開く。対策の1つは、位相差が大きくなる前に故障区間を切り離す高速遮断で、これで脱調を防ぐ。 |
| 需給バランス（じゅきゅうばらんす） | 発電量と消費量を常時一致させること（電気は大量に貯めにくい。揚水発電や蓄電池で貯める分を除けば、発電したその瞬間に消費される）。 |
| ピーク負荷（ぴーくふか） | 1日・1年の最大需要電力。ピーク対応に揚水発電等を活用。 |
| 自動周波数制御（AFC）（じどうしゅうはすうせいぎょ） | 電力系統の周波数・潮流を自動的に制御するシステム。 |
| SCADA（すかだ） | 広域での発電・送電設備を監視・制御するシステム。 |
| 系統連系（けいとうれんけい） | 太陽光等の分散型電源を電力系統に接続すること。 |
| 特別高圧（とくべつこうあつ） | 電技省令第2条の電圧区分で、7000 V を超えるもの。低圧は直流 750 V 以下・交流 600 V 以下、高圧はそれを超え 7000 V 以下。66 kV・154 kV・500 kV の送電や 22 kV・33 kV の配電は、すべて特別高圧。 |
| 潮流（ちょうりゅう） | 電力系統の各部を流れる有効電力・無効電力の流れ。潮流計算で各点の電圧や損失を評価する。 |
| 経済負荷配分（EDC）（けいざいふかはいぶん） | 総燃料費が最小になるように各発電機の出力を配分する制御。送電損失を無視でき、各機が出力上下限にかからない範囲では、各発電機の増分燃料費が等しいときに最も経済的になる。 |
| 進み電流（すすみでんりゅう） | 電圧より位相が進んだ電流。静電容量（コンデンサ・ケーブル）に流れる電流が代表例で、長い送電線や地中ケーブルでは軽負荷のときに受電端の電圧を上げる（フェランチ効果）。 |

| 耐熱クラス（たいねつくらす） | 絶縁材料を、耐えられる最高温度で分けた区分。低い方から Y・A・E・B・F・H・C。F＝155 ℃、H＝180 ℃ の取り違えが頻出（各クラスの温度は電気材料のページの表）。 |
| 導電材料（どうでんざいりょう） | 電流を通すための材料。電線では銅・アルミニウムなどを、導電率・比重・強さなどで比べて選ぶ。 |
| 絶縁材料（ぜつえんざいりょう） | 電気を通さず、電路を絶縁するための材料。耐えられる最高温度で耐熱クラスに分ける。 |
| 絶縁耐力試験（ぜつえんたいりょくしけん） | 電路や機器に規定の試験電圧を規定の時間加え、絶縁が壊れないことを確かめる試験。電技省令第5条の要求を満たす具体値として、試験電圧の倍率と時間（連続して10分間）を電技解釈第15条・第16条が定める。 |

## 11.その他

| 用語 | 定義 |
| --- | --- |
| 誘導発電機（ゆうどうはつでんき） | 同期速度より速く回して発電する誘導機。構造が簡単で励磁装置が要らないが、単独では発電できず系統に並列して運転する。並列時の突入電流は大きい。 |
| 電圧変動率（でんあつへんどうりつ） | 負荷やコンデンサの開閉で電圧がどれだけ変わるかを、基準の電圧に対する割合（%）で表したもの。変圧器では、無負荷と全負荷の二次電圧の差を定格二次電圧で割る。送電・配電では、受電端で無効電力 Q を出し入れしたときの変化をおよそ %X×Q／基準容量 で見積もる（H25 問16）。 |
| 太線化（ふとせんか） | 電線を断面積の大きいものに替えること。抵抗が下がるので電圧降下と電力損失が減り、流せる電流（電流容量）が増える。配電線の電圧降下の対策（R05下 問7・R04下 問12）や、短距離送電線の送電容量を増やす方策（H24 問7）として出る。 |
| 区分開閉器（くぶんかいへいき） | 電路を区分する開閉器。高圧配電線では、事故区間を切り離すために線路の途中に設ける。高圧で受電する需要家では、保安上の責任分界点付近に設け、構内の事故を系統から切り離す（架空引込は PAS、地中引込は UGS）。 |
