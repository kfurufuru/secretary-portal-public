| **再熱サイクル**（さいねつさいくる） | タービン中段で蒸気を再加熱して効率を高めるサイクル。 |
| **再生サイクル**（さいせいさいくる） | タービン抽気でボイラ給水を加熱するサイクル。 |
| **コンバインドサイクル**（こんばいんどさいくる） | ガスタービンと蒸気タービンを組み合わせた高効率発電方式。 |
| **熱効率**（ねつこうりつ） | 発電に利用した熱量/投入した熱量。 |
| **低位発熱量**（ていいはつねつりょう） | 燃料の発熱量から水蒸気の蒸発潜熱を引いた値。 |
| **ボイラ**（ぼいら） | 燃料を燃焼させて蒸気を生成する装置。 |
| **脱硝装置**（だっしょうそうち） | 排煙中のNOxを除去する装置。 |
| **脱硫装置**（だつりゅうそうち） | 排煙中のSOxを除去する装置。 |
| **汽力発電**（きりょくはつでん） | ボイラで発生させた蒸気でタービンを回す発電方式。ランキンサイクルを基本とし、再熱・再生サイクルで効率を高める。 |
| **復水器**（ふくすいき） | タービン排気蒸気を冷却水で凝縮して復水に戻す装置。内部を真空に保ってタービンの熱落差を大きくする。熱サイクル中で最大の熱損失源。 |
| **節炭器**（せつたんき） | 煙道排ガスの余熱でボイラ給水を予熱する装置（エコノマイザ）。排ガス損失を減らして熱効率を高める。 |
| **過熱器**（かねつき） | ボイラで発生した飽和蒸気をさらに加熱して過熱蒸気にする装置。熱効率が向上し、タービン翼の湿り蒸気による浸食も防ぐ。 |
| **再熱器**（さいねつき） | 高圧タービンで仕事をした蒸気をボイラへ戻して再加熱する装置。再熱サイクルを構成し、効率向上と低圧タービンの湿り防止に効く。 |
| **給水加熱器**（きゅうすいかねつき） | タービンから抽気した蒸気でボイラ給水を予熱する装置。再生サイクルを構成し、復水器で捨てる熱を減らす。 |
| **熱消費率**（ねつしょうひりつ） | 電力量1kWhを発生するのに消費した熱量 [kJ/kWh]。小さいほど高効率で、熱効率＝3600÷熱消費率。 |

## 3.原子力発電

| 用語 | 定義 |
| --- | --- |
| **核分裂**（かくぶんれつ） | ウラン235などの重い原子核が中性子を吸収して2つに分裂し、大きなエネルギーと2〜3個の中性子を放出する反応。 |
| **質量欠損**（しつりょうけっそん） | 核反応の前後で減少する質量。E=mc²に従いエネルギーとして放出される。ウラン235の核分裂1回で約200MeV。 |
| **軽水炉**（けいすいろ） | 軽水（普通の水）を減速材と冷却材に兼用する原子炉。日本の商用炉の主流でBWRとPWRに分かれる。燃料は低濃縮ウラン。 |
| **沸騰水型原子炉（BWR）**（ふっとうすいがたげんしろ） | 炉心で直接沸騰させた蒸気をそのままタービンへ送る軽水炉。構造が簡単だが、タービン系も放射性物質を含む蒸気に触れる。 |
| **加圧水型原子炉（PWR）**（かあつすいがたげんしろ） | 一次系を加圧して沸騰させず、蒸気発生器で二次系の水を蒸気にしてタービンへ送る軽水炉。タービン系は放射性物質と分離される。 |
| **減速材**（げんそくざい） | 核分裂で生じる高速中性子を、核分裂を起こしやすい熱中性子まで減速させる材料。軽水炉では水。 |
| **冷却材**（れいきゃくざい） | 炉心で発生した熱を外へ運ぶ流体。軽水炉では水が減速材を兼ねる。 |
| **制御棒**（せいぎょぼう） | 中性子をよく吸収する材料（ほう素・カドミウムなど）の棒。炉心への出し入れで核分裂連鎖反応の速さを制御する。 |
| **臨界**（りんかい） | 核分裂で生じる中性子と、吸収・漏れで失われる中性子が釣り合い、連鎖反応が一定の割合で持続する状態。 |
| **崩壊熱**（ほうかいねつ） | 原子炉停止後も核分裂生成物の放射性崩壊で発生し続ける熱。停止後も炉心冷却を続ける必要がある理由。 |
| **核燃料サイクル**（かくねんりょうさいくる） | ウランの採鉱・濃縮・成形加工から、使用済み燃料の再処理でウラン・プルトニウムを回収して再利用するまでの一連の流れ。 |
| **中性子**（ちゅうせいし） | 電荷を持たない核子。ウラン235に吸収されると核分裂を引き起こし、連鎖反応の担い手となる。 |

## 4.新エネルギー

| 用語 | 定義 |
| --- | --- |
| **太陽電池**（たいようでんち） | pn接合半導体の光起電力効果で、光エネルギーを直接直流電力に変換する素子。可動部がなく保守が容易。 |
| **太陽光発電**（たいようこうはつでん） | 太陽電池の直流出力をパワーコンディショナで交流に変換して利用する発電。出力は日射量に左右され、余剰は逆潮流で系統へ送る。 |
| **風力発電**（ふうりょくはつでん） | 風の運動エネルギーで風車を回して発電する方式。理論上の出力は受風面積と風速の3乗に比例する。 |
| **燃料電池**（ねんりょうでんち） | 水素と酸素を電気化学反応させて化学エネルギーを直接直流電力に変換する装置。水の電気分解の逆反応で、排熱も給湯などに利用できる。 |
| **地熱発電**（ちねつはつでん） | 地下から噴出する蒸気・熱水でタービンを回す発電。ボイラと燃料が不要で、出力は天候に左右されない。 |
| **バイオマス**（ばいおます） | 動植物由来の有機資源（木くず・廃棄物など）を燃料とする発電。燃焼でCO2を出すが、成長過程の吸収と相殺されるカーボンニュートラルな電源とされる。 |

## 5.変電

| 用語 | 定義 |
| --- | --- |
| **変圧器**（へんあつき） | 電圧を変換する機器。1次・2次の巻き数比で電圧が決まる。 |
| **鉄損**（てつそん） | 磁束の変化により鉄心に生じる損失（ヒステリシス損＋渦電流損）。負荷に無関係。 |
| **銅損**（どうそん） | 電流が巻き線の抵抗を流れることで生じる損失。負荷電流の2乗に比例。 |
| **最大効率**（さいだいこうりつ） | 鉄損＝銅損となる負荷時に変圧器効率が最大になる。 |
| **パーセントインピーダンス**（ぱーせんといんぴーだんす） | 定格電流を流したとき変圧器の内部インピーダンスによる電圧降下の定格電圧に対する比（%）。 |
| **遮断器（CB）**（しゃだんき） | 事故時に回路を遮断する機器。アーク消弧能力が必要。 |
| **断路器（DS）**（だんろき） | 無電圧・無負荷状態で回路を開閉する機器。負荷電流の遮断不可。 |
| **過電流継電器（OCR）**（かでんりゅうけいでんき） | 設定値以上の電流が流れると動作して遮断器を制御する継電器。 |
| **地絡継電器（GR）**（ちらくけいでんき） | 地絡事故を検出する継電器。 |
| **GIS**（じーあいえす） | ガス絶縁開閉装置。SF6ガスで絶縁・アーク消弧。小型化が可能。 |
| **計器用変成器**（けいきようへんせいき） | 高電圧・大電流を計器や保護継電器が扱える小さな値に変換する機器の総称。電圧用のVTと電流用のCTがある。 |
| **計器用変圧器（VT）**（けいきようへんあつき） | 高電圧を110Vなどの低電圧に変換する変成器。二次側を短絡すると大電流が流れて焼損するため短絡厳禁。 |
| **変流器（CT）**（へんりゅうき） | 大電流を5Aなどの小電流に変換する変成器。通電中に二次側を開放すると高電圧が発生して危険なため開放厳禁。VT（短絡厳禁）との対比が引っかけどころ。 |
| **零相変流器（ZCT）**（れいそうへんりゅうき） | 三相分の電線を一括して貫通させ、平常時はゼロになる三相電流のベクトル和（＝零相電流の3倍）を検出する変流器。地絡時に現れる残留電流を地絡継電器へ伝える。 |
| **母線**（ぼせん） | 変電所内で発電機・変圧器・送電線などの回路を共通に接続する導体。単母線・二重母線などの方式があり、信頼度と経済性で使い分ける。 |
| **調相設備**（ちょうそうせつび） | 無効電力を供給・吸収して電圧を調整する設備の総称。進み側の電力用コンデンサ、遅れ側の分路リアクトル、連続調整できる同期調相機・SVCなど。 |
| **中性点接地方式**（ちゅうせいてんせっちほうしき） | 系統の中性点の接地方法。直接接地・抵抗接地・消弧リアクトル接地・非接地があり、地絡電流の大きさと健全相の電圧上昇・誘導障害がトレードオフになる。 |
| **直接接地**（ちょくせつせっち） | 中性点を直接接地する方式。健全相の電圧上昇が小さく機器絶縁を低減できるが、地絡電流が大きく誘導障害も大きい。187kV以上の超高圧系統で採用。 |
| **抵抗接地**（ていこうせっち） | 中性点を抵抗を介して接地する方式。地絡電流を抑えて誘導障害を軽減しつつ、地絡継電器の動作に必要な電流は確保する。 |
| **消弧リアクトル接地**（しょうこりあくとるせっち） | 送電線の対地静電容量と並列共振するリアクトルで中性点を接地する方式。1線地絡時のアークを自然に消滅させる。 |
| **非接地方式**（ひせっちほうしき） | 中性点を接地しない方式。地絡電流は小さいが、1線地絡時に健全相の対地電圧が√3倍に上昇する。6.6kV高圧配電系統で採用。 |
| **短絡電流**（たんらくでんりゅう） | 短絡事故時に流れる大電流。定格電流×100÷%Z（%Zは短絡点までの合成パーセントインピーダンス）で求める。遮断器の定格遮断電流はこれを上回る必要がある。 |
| **短絡容量**（たんらくようりょう） | 短絡点から見た系統の強さを表す皮相電力。√3×定格電圧×短絡電流。大きすぎると遮断できないため、限流リアクトルや系統分割で抑制する。 |
| **定格遮断電流**（ていかくしゃだんでんりゅう） | 遮断器が定格条件で確実に遮断できる電流の限度。設置点の短絡電流より大きい値を選定する。 |
| **真空遮断器（VCB）**（しんくうしゃだんき） | 高真空中でアークを拡散させて消弧する遮断器。小型で保守が容易、火災の心配がなく、高圧受電設備で広く使われる。 |
| **負荷開閉器**（ふかかいへいき） | 負荷電流の開閉はできるが短絡電流は遮断できない開閉装置。短絡遮断は遮断器、無負荷開閉は断路器、という役割分担が頻出。 |
| **比率差動継電器**（ひりつさどうけいでんき） | 保護区間に流入・流出する電流の差から内部故障を検出する継電器。変圧器保護の主力で、励磁突入電流による誤動作を抑制する工夫がされる。 |
| **距離継電器**（きょりけいでんき） | 設置点の電圧と電流の比からインピーダンス（故障点までの電気的距離）を測定して動作する継電器。送電線の保護に使う。 |
| **酸化亜鉛形避雷器**（さんかあえんがたひらいき） | 酸化亜鉛（ZnO）素子の優れた非直線抵抗特性を利用した避雷器。常時はほぼ絶縁体で過電圧時のみ電流を流すため、直列ギャップを省略できる。 |

## 6.送電

| 用語 | 定義 |
| --- | --- |
| **電圧降下**（でんあつこうか） | 送電線のインピーダンスによる送電端と受電端の電圧差。 |
| **電力損失**（でんりょくそんしつ） | 送電線の抵抗による発熱損失。三相3線式は 3I²R、単相2線式は 2I²R（I は線電流、R は1線当たりの抵抗）。 |
| **力率改善**（りきりつかいぜん） | 進相コンデンサ等で力率を1に近づけ、無効電力を減らすこと。 |
| **ACSR**（えーしーえすあーる） | 鋼心アルミより線。軽量で引張強度が高い送電線用電線。 |
| **弛度（たるみ）**（しど） | 電線が自重でたわんだ量。温度上昇や着雪で増加。 |
| **実効値**（じっこうち） | 交流の実効的な大きさ。最大値の1/√2。 |
| **スキン効果**（すきんこうか） | 高周波では電流が導体表面に集中する現象。 |
| **フェランチ効果**（ふぇらんちこうか） | 軽負荷・無負荷時に受電端電圧が送電端電圧より高くなる現象。 |
| **架空地線**（かくうちせん） | 鉄塔頂部に電力線とは別に張る接地された線。直撃雷から電力線を遮へいし、誘導雷サージも軽減する。遮へい角が小さいほど遮へい効果が高い。 |
| **がいし**（がいし） | 電線を支持物から絶縁して支持する磁器製などの器具。懸垂がいしは連結個数で絶縁強度を調整する。塩害地区では過絶縁やがいし洗浄で対策。 |
| **アークホーン**（あーくほーん） | がいし連の両端に取り付ける金具。フラッシオーバ時のアークをがいしから離れた場所に誘導し、がいしの破損を防ぐ。 |
| **多導体**（たどうたい） | 1相あたり2本以上の電線をスペーサで間隔を保って並列に使う方式。等価半径が大きくなってコロナ開始電圧が上がり、インダクタンス減・静電容量増となる。超高圧送電で標準。 |
| **コロナ放電**（ころなほうでん） | 電線表面の電位の傾きが空気の絶縁耐力（標準状態で波高値約30kV/cm）を超えて起こる局部放電。電力損失・雑音・電線腐食の原因で、太い電線や多導体で防ぐ。 |
| **ねん架**（ねんが） | 送電線各相の配置を区間ごとに入れ替え、線路全体で三相の線路定数を平衡させること。電圧・電流の不平衡と通信線への誘導障害を抑える。 |
| **誘導障害**（ゆうどうしょうがい） | 送電線が近接する通信線などへ電圧・電流を誘導して生じる障害。静電容量を介する静電誘導障害と、相互インダクタンスを介する電磁誘導障害があり、1線地絡時の電磁誘導が特に問題。 |
| **逆フラッシオーバ**（ぎゃくふらっしおーば） | 鉄塔や架空地線への雷撃で鉄塔の電位が上昇し、がいし連を鉄塔側から電線側へ放電が飛ぶ現象。塔脚接地抵抗を下げて防止する。 |
| **塔脚接地抵抗**（とうきゃくせっちていこう） | 鉄塔の接地抵抗。大きいと雷撃時に鉄塔の電位が上がり逆フラッシオーバの原因になる。埋設地線を設けて低減する。 |
| **線路定数**（せんろていすう） | 送電線の抵抗・インダクタンス・静電容量・漏れコンダクタンスの4定数。電線の太さや配置で決まり、電圧や電流の大きさには無関係。 |
| **静電容量**（せいでんようりょう） | 電線と大地間・電線相互間に形成されるコンデンサ成分。充電電流やフェランチ効果の原因になり、ケーブルは架空線よりはるかに大きい。 |
| **充電電流**（じゅうでんでんりゅう） | 線路の静電容量に流れる進み位相の電流。無負荷でも流れ、ケーブル系統で特に大きい。フェランチ効果の原因。 |
| **送電容量**（そうでんようりょう） | 送電線で送ることのできる電力の限度。電線の許容電流・電圧降下・安定度などで決まる。 |

## 7.地中送電

| 用語 | 定義 |
| --- | --- |
| **XLPE**（えっくすえるぴーいー） | 架橋ポリエチレン絶縁。地中ケーブルの主流。耐熱性・絶縁性に優れる。 |
| **OFケーブル**（おいるふぃるどけーぶる） | 絶縁油を充填した油浸紙絶縁ケーブル。高電圧対応。 |
| **CVTケーブル**（しーぶいてぃーけーぶる） | 単心CVケーブル3本をより合わせたトリプレックス形ケーブル。3心共通シース形より放熱が良く許容電流を大きくとれ、端末処理も容易。 |
| **誘電損**（ゆうでんそん） | ケーブルの絶縁体に交流電圧がかかることで絶縁体内部に生じる損失。電圧の2乗・周波数・静電容量・誘電正接tanδに比例する。 |
| **誘電正接**（ゆうでんせいせつ） | 絶縁体の誘電損の大きさを表す指標（tanδ）。絶縁劣化が進むと増加するため、絶縁診断の指標に使われる。 |
| **許容電流**（きょようでんりゅう） | 連続して流せる電流の上限。絶縁体の最高許容温度で決まり、ケーブルでは布設条件や土壌の放熱性にも左右される。 |
| **故障点標定**（こしょうてんひょうてい） | 地中ケーブルの故障位置を地上からの測定で特定すること。ブリッジ回路を使うマーレーループ法、パルスの反射時間で測るパルスレーダ法などがある。 |
| **直接埋設式**（ちょくせつまいせつしき） | ケーブルを防護物とともに地中へ直接埋める布設方式。工事費が安く放熱も良いが、増設や張替えが困難。 |
| **管路式**（かんろしき） | あらかじめ埋設した管路にケーブルを引き入れる布設方式。増設・張替えが容易だが、条数が多いと相互加熱で許容電流が小さくなる。 |
| **暗きょ式**（あんきょしき） | 洞道（共同溝など）内の受け棚にケーブルを布設する方式。多条数の布設と保守点検が容易で、都市部の幹線に使われる。 |

## 8.配電

| 用語 | 定義 |
| --- | --- |
| **樹枝状方式**（じゅしじょうほうしき） | 変電所から放射状に配電する最もシンプルな方式。 |
| **ループ方式**（るーぷほうしき） | 配電線をリング状に結ぶ方式。信頼性が高い。 |
| **スポットネットワーク方式**（すぽっとねっとわーくほうしき） | 複数回線から変圧器を並列に接続。大容量需要家向け。 |
| **低圧バンキング方式**（ていあつばんきんぐほうしき） | 同一高圧線に接続した複数の変圧器の低圧側を並列接続。 |
| **力率**（りきりつ） | 有効電力/皮相電力 = cosφ。1に近いほど効率が良い。 |
| **進相コンデンサ**（しんそうこんでんさ） | 遅れ無効電力を補償して力率を改善するコンデンサ。 |
| **変圧器タップ**（へんあつきたっぷ） | 変圧器の巻き数を切り替えて電圧を調整する端子。 |
| **PAS**（ぱす） | 柱上気中開閉器。地絡電流を検出して自動開放する。 |
| **柱上変圧器**（ちゅうじょうへんあつき） | 電柱上に設置して高圧6.6kVを100V/200Vに降圧する変圧器。単相3線式で引き出すことが多い。 |
| **高圧カットアウト**（こうあつかっとあうと） | 柱上変圧器の一次側に設ける開閉器。内蔵する高圧ヒューズで変圧器の過負荷・短絡を保護する。 |
| **単相3線式**（たんそうさんせんしき） | 電圧線2本と中性線1本で100Vと200Vの両方を供給する方式。中性線の断線で不平衡負荷の軽負荷側に過電圧がかかるのが頻出の引っかけ。 |
| **三相3線式**（さんそうさんせんしき） | 3本の電線で三相電力を供給する方式。高圧配電線は6.6kV三相3線式が標準。同一電力・同一電圧・同一損失・同一距離の条件で比べると、電線の総重量は単相2線式の3/4で済む。 |
| **V結線**（ぶいけっせん） | 単相変圧器2台で三相を供給する結線。出力はΔ結線（3台）の1/√3＝57.7%、変圧器利用率は86.6%。 |
| **バランサ**（ばらんさ） | 単相3線式配電線の末端に設ける巻数比1対1の単巻変圧器。両外線の電圧不平衡を是正し、中性線の電流を打ち消す。 |
| **中性線**（ちゅうせいせん） | 単相3線式の中央の接地された電線。断線すると軽負荷側の電圧上昇で機器を焼損するおそれがあり、中性線には過電流遮断器を施設しない。 |
| **需要率**（じゅようりつ） | 最大需要電力を設備容量の合計で割った百分率。通常100%以下。 |
| **負荷率**（ふかりつ） | 平均需要電力を最大需要電力で割った百分率。100%に近いほど設備が平準的に使われている。対象期間（日・月・年）で値が変わる。 |
| **不等率**（ふとうりつ） | 各需要家の最大需要電力の合計を合成最大需要電力で割った値。最大需要の発生時刻のずれを表し、常に1以上。 |
| **高調波**（こうちょうは） | 基本波（50/60Hz）の整数倍の周波数成分。パワーエレクトロニクス機器などから発生し、進相コンデンサの過熱・焼損の原因。直列リアクトルで流入を抑える。 |
| **逆潮流**（ぎゃくちょうりゅう） | 需要家側から系統側へ向かう電力の流れ。太陽光発電の余剰電力で生じ、大量連系時は配電線の電圧上昇が問題になる。 |
| **単独運転**（たんどくうんてん） | 系統側が停電しているのに分散型電源が局所的に送電を続けてしまう状態。感電・機器損傷の危険があるため、検出して直ちに解列する。 |

## 9.電力系統・需給

| 用語 | 定義 |
| --- | --- |
| **周波数調整**（しゅうはすうちょうせい） | 発電と需要のバランスを保ち系統周波数を50/60Hzに維持すること。 |
| **負荷周波数制御（LFC）**（ふかしゅうはすうせいぎょ） | 系統周波数のズレを検出して発電機出力を自動制御する。 |
| **電力系統安定度**（でんりょくけいとうあんていど） | 擾乱後も同期運転を維持できる能力（定態・過渡・動態安定度）。 |
| **需給バランス**（じゅきゅうばらんす） | 発電量と消費量を常時一致させること（電気は貯蔵できない）。 |
| **ピーク負荷**（ぴーくふか） | 1日・1年の最大需要電力。ピーク対応に揚水発電等を活用。 |
| **自動周波数制御（AFC）**（じどうしゅうはすうせいぎょ） | 電力系統の周波数・潮流を自動的に制御するシステム。 |
| **SCADA**（すかだ） | 広域での発電・送電設備を監視・制御するシステム。 |
| **系統連系**（けいとうれんけい） | 太陽光等の分散型電源を電力系統に接続すること。 |
| **潮流**（ちょうりゅう） | 電力系統の各部を流れる有効電力・無効電力の流れ。潮流計算で各点の電圧や損失を評価する。 |
| **経済負荷配分（EDC）**（けいざいふかはいぶん） | 総燃料費が最小になるように各発電機の出力を配分する制御。送電損失を無視でき、各機が出力上下限にかからない範囲では、各発電機の増分燃料費が等しいときに最も経済的になる。 |

## 10.絶縁・電気材料

| 用語 | 定義 |
| --- | --- |
| **絶縁破壊**（ぜつえんはかい） | 電界が材料の絶縁耐力を超え、電子なだれによって導通路ができる現象。決めるのは電圧でなく電界。 |
| **絶縁耐力**（ぜつえんたいりょく） | 絶縁物が耐えられる電界の強さ。kV/mm など単位長さあたりの電圧で表す。 |
| **絶縁協調**（ぜつえんきょうちょう） | 機器の絶縁強度を階段状に定め、最も低い避雷器の制限電圧で異常電圧を頭打ちにする設計思想。 |
| **BIL（基準衝撃絶縁強度）**（びーあいえる） | 機器が耐えるべき雷インパルス電圧の基準値。避雷器の制限電圧より十分高く設定する。 |
| **制限電圧**（せいげんでんあつ） | 避雷器がサージを放電している間に両端に残る電圧。低いほど機器保護の余裕が大きい。 |
| **続流**（ぞくりゅう） | サージ通過後も避雷器に流れ続ける商用周波電流。確実に遮断できることが要件。 |
| **部分放電**（ぶぶんほうでん） | 固体絶縁中の空気ボイド等で起こる局所的な放電。電界集中と空気の低耐力が重なって発生し、トリーイングを経て全路破壊に至る。 |
| **トリーイング**（とりーいんぐ） | 部分放電により絶縁物内部に樹枝状の劣化痕が伸びる現象。進展すると絶縁破壊に至る。 |
| **パッシェンの法則**（ぱっしぇんのほうそく） | 気体の火花放電開始電圧は気圧とギャップ長の積で決まり、極小値を持つ（単調ではない）。 |
| **フラッシオーバ**（ふらっしおーば） | 空気中や絶縁物表面を放電が飛ぶ現象。自復性があり、内部を貫通する絶縁破壊（不可逆）とは区別する。 |
| **沿面放電**（えんめんほうでん） | 絶縁物の表面に沿って進む放電。塩害・汚損で沿面の絶縁が低下すると起こりやすい。 |
| **水トリー**（みずとりー） | CVケーブルで水分と電界により微小な樹枝状劣化が進行する現象。絶縁破壊の前兆。 |
| **導電率**（どうでんりつ） | 電流の流れやすさを表す量で抵抗率の逆数。軟銅を100%とする百分率表示では硬銅線が約97%、硬アルミ線が約61%。 |
| **けい素鋼板**（けいそこうばん） | 鉄にけい素を数%加えた電磁鋼板。ヒステリシス損が小さく、薄板を絶縁して成層することで渦電流損も抑える。変圧器や回転機の鉄心材料。 |
| **アモルファス**（あもるふぁす） | 原子配列が不規則な非晶質の磁性材料。けい素鋼板より鉄損が大幅に小さく、柱上変圧器などの鉄心に使われる。加工性と占積率が課題。 |
