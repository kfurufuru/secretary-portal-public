# 架空送電線路

発電所から変電所まで超高圧で電力を運ぶ大動脈。送電分野の最頻出テーマ（約68問）。論説中心だが、電圧降下・電力損失の計算も毎年のように問われる。
**出題頻度:** 最頻出（送電分野 約68問）
**難易度:** ★★★
**出題形式:** 論説中心・計算（電圧降下/損失）

## 0.このページ（架空送電線路）を森・ミクロ・マクロで見る

同じテーマを **森（俯瞰）→ ミクロ（なぜ）→ マクロ（解く）** の3層で見る。まず森でこのページの位置を掴み、ミクロで機構を、マクロで解き方を押さえる。
森（俯瞰）：発電所から変電所まで電力を運ぶ大動脈。「なぜ超高圧で送るか」が全体を貫く問いで、ここから地中送電・誘導障害・配電線路へ枝分かれする。送電分野の最頻出テーマ。

| 視点 | 何を見るか | 代表する式・量 |
| --- | --- | --- |
| **ミクロ** （なぜ） | 三相電力は $P = \sqrt{3}\,V_L I_L \cos\theta$ なので、**同じ電力なら電圧を上げるほど電流が小さくなる**。損失は**電流の2乗**で効くため、電圧を10倍にすれば損失は 1/100 になる | 電圧↑ ⇒ 電流↓ ⇒ 損失↓↓ |
| **マクロ** （解く） | 電線は完全導体ではなく**抵抗 R とリアクタンス X** を持つ。送電端と受電端の電圧差（電圧降下）と抵抗損失を計算する。試験はここ（論説中心＋計算） | $V_s = V_r + \Delta V$・$P_{\text{loss}} = 3I^2R$ |
| **実務** （意味づけ） | 275 kV・500 kV の**超高圧**で送り、変電所で降圧して配電する。電線・がいし・鉄塔・架空地線などの構成要素と、その保護・対策が問われる | 超高圧送電・構成要素と保護 |

## 1.直感的理解 — なぜ超高圧で送るか

電線は完全な導体ではなく、抵抗 R とリアクタンス X で電圧降下が生じ、送電端と受電端の電圧が異なる。三相電力は $P = \sqrt{3}\,V_L I_L \cos\theta$ なので、**同じ電力なら電圧を上げるほど電流が小さくなる**。
超高圧送電のメリット（損失は電流の2乗）
電力損失は $P_{\text{loss}} = 3I^2R$。電圧を10倍にすれば電流は $1/10$、損失は $1/100$ になる。だから 275 kV・500 kV の超高圧で送り、変電所で降圧して配電する。送電端電圧は $V_s = V_r + \Delta V$ で、$\Delta V$ は「抵抗成分（有効分）＋リアクタンス成分（無効分）」からなる。

**3経路は「どこに落ちたか」で区別する**——①導体に直撃／②線路の近くに落ちた（線路には当たっていない）／③鉄塔・架空地線に落ちた。③だけ破壊の向きが鉄塔→導体で逆になり、だから対策も避雷器ではなく**接地抵抗の低減**。因果は**R が高い → 塔電位が上がる → がいし両端電圧が絶縁耐力を超える → 破壊**の順で、「塔電位が導体を上回る」だけでは破壊しない（がいしが耐えれば起きない）のが3段目の意味。
逆フラッシオーバーの物理（接地抵抗を下げる理由）
通常は「導体（高電位）→がいし→鉄塔（接地）」へ絶縁破壊が進む。だが鉄塔の**接地抵抗が高い**と、落雷時に塔基部の電位が $V = I_{\text{雷}} \times R_{\text{接地}}$ だけ上昇し、塔電位が導体電位を上回って「鉄塔→がいし→導体」へ逆向きに破壊が進む。だから対策は**接地抵抗の低減**。コロナは逆に、導体が細いほど表面電界（1/r で減衰）が高くなり発生しやすいので、多導体で等価半径を大きくして電界を下げる。

## 5.たるみ（弛度）と実長（計算頻出）

電線は支持点間で必ずたるむ。張力を上げればたるみは減るが、電線・支持物への負担は増える。この関係を式で扱うのが弛度計算。
D1
**弛度（たるみ）**
$D = \dfrac{WS^2}{8T}\,[\text{m}]$
W: 電線1mあたりの合成荷重 [N/m]、S: 径間 [m]、T: 電線最低点の水平張力 [N]。張力Tを大きくすると弛度Dは小さくなる（反比例）。支持点がほぼ同じ高さで弛度が径間に比べ小さいときの放物線近似。
D2
**電線の実長**
$L = S + \dfrac{8D^2}{3S}\,[\text{m}]$
実長Lは径間SよりD²に比例する分だけわずかに長い。「たるみが2倍なら伸び（L−S）は4倍」の関係が問われる。
因果で覚える — 温度・荷重とたるみの連動
- **気温上昇 → 電線が伸びる → 実長L増 → 弛度D増・張力T減**。夏・大電流時は地上高が下がるため、最大たるみ時でも法定離隔を確保できる高さに設計する。
- **氷雪・風の付加荷重 → 合成荷重W増 → 弛度・張力とも増**。Wは鉛直方向（自重＋氷雪）と水平方向（風圧）のベクトル和で求める。
- 「温度が上がると張力も上がる」は**誤り**（張力と弛度は逆の関係。S3 引っかけパターン16参照）。

$D = \dfrac{WS^2}{8T}$ は「**張力を張るほどたるみは減る**」、$L - S = \dfrac{8D^2}{3S}$ は「**たるみが2倍なら伸びは4倍**」。計算の急所は W が鉛直（自重＋氷雪）と水平（風圧）の直角合成である点で、**代数和にすると必ず過大になる**。D は支持点を結ぶ直線から測った距離であって地上高ではなく、風があるときは **W の向き**に測る（鉛直方向の値そのものではない）。

## 6.円筒導体の電界とコロナ放電

送電線は断面が円い**円筒（円柱）導体**。電荷を帯びた円筒導体のまわりには、中心から外向きに放射状の**電界**が広がる。線電荷密度を $\lambda\,[\text{C/m}]$、真空（空気）の誘電率を $\varepsilon_0$ とすると、中心軸から距離 $r$ の点の電界の大きさは次式で表される。
C1
**円筒導体まわりの電界（放射状・ガウスの法則）**
$E = \dfrac{\lambda}{2\pi\varepsilon_0\, r}\;[\text{V/m}]$
E は距離 r に反比例（1/r で減衰）。導体表面（r = 導体半径 a）でいちばん強くなる。
この**導体表面の電界**を**電位傾度**（1 cm あたり何 kV かかっているか）と呼ぶ。$E \propto 1/r$ なので電界は導体表面で最大で、外へ離れるほど急速に弱まる。下図の左は円筒導体の断面と放射状の電界（内側ほど密＝電位傾度大）、右は距離 r に対する電界 E の 1/r 減衰を示す。
左: 円筒導体断面の放射状電界（内側ほど密）。右: 電界 E の 1/r 減衰と、表面付近で臨界電界 Ec を超える「コロナ発生域」。
コロナ放電の発生条件 — 表面の電位傾度が臨界電界を超える
電線表面の電位傾度が、空気の**臨界電界（絶縁破壊の限界。標準状態 δ=1 で約 30 kV/cm＝波高値。実効値では約 21 kV/cm）**を超えると、導体ごく近傍の空気が局部的に絶縁破壊して青白く放電・発音する。これが**コロナ放電**。がいし連の全路破壊（フラッシオーバ）と違い、**導体表面近傍だけの部分放電**である点が急所。
**コロナが発生しやすくなる要因**（いずれも「表面電界が上がる」または「臨界電界が下がる」方向）。

| 要因 | 効果（表面電界／臨界電界への影響） |
| --- | --- |
| 電線が細い（半径 a が小さい） | 表面電界は $E \propto 1/a$ なので上昇。細いほどコロナしやすい |
| 送電電圧が高い（線電荷 λ 大） | 電荷密度が増えて電界が上昇 |
| 雨・雪・霧・塩分や傷などの突起 | 水滴や突起の先端に電界が集中し、表面係数が下がって臨界電界が低下 |
| 高地・低気圧・高温（空気密度 δ が小） | 空気が薄く絶縁破壊しやすくなり臨界電界が低下 |

なぜ太い導体・多導体（バンドル）でコロナを抑えるのか
表面電界は導体の**等価半径**で決まる。**多導体（バンドル）方式**は数本の素導体を数十 cm 間隔で並べ、全体を「1 本の太い導体」とみなした等価半径を大きくする。等価半径が大きいほど表面の電位傾度が下がり、臨界電界に達しにくい。単導体でも太径・中空にする、金具の端部に**コロナリング**を付けて電界集中を緩和する、なども同じ狙い。第4節の表「太い導体・多導体方式・コロナリング」はすべてこの原理。
**コロナの影響（ほとんどがデメリット）。**

| 影響 | 内容 |
| --- | --- |
| コロナ損 | 放電でエネルギーを消費する電力損失。線路定数の**コンダクタンス G** に相当し、雨天時に増大 |
| 雑音障害 | 電波障害・通信線への誘導雑音（ラジオノイズ） |
| 可聴騒音 | ジー音・パチパチ音（とくに雨天時） |
| 腐食・劣化 | オゾン・窒素酸化物（NOx）が発生し、電線・金具を腐食 |
| （利点）異常電圧の減衰 | 雷サージなど進行波の波高値を減衰させる効果もある（数少ない利点） |

論説の急所 — コロナ臨界電圧の大小関係
コロナが始まる電圧を**コロナ臨界電圧**という。表面の電位傾度がちょうど臨界電界に一致するときの電圧で、導体半径・線間距離・相対空気密度 δ・表面係数 m で決まる（ピークの式）。3 種では数値計算より、**「太い導体・多導体・δ が大（低地・低温・高気圧）・晴天ほど臨界電圧が高くコロナしにくい」**という大小関係の論説が問われる。
地中ケーブルでも同じ円筒の電界（→地中送電・電力ケーブル）
この 1/r の円筒電界は、地中ケーブルの**同軸円筒構造**にも現れる。ただしケーブルは遮へいで閉じているため電界が絶縁体内で完結し、導体表面の電位傾度が絶縁設計を左右する。詳細は「地中送電・電力ケーブル」ページの**同軸円筒ケーブルの電界分布と電位傾度**を参照。

## 7.公式マップ（最重要）

01
**電圧降下（三相3線式）**
$\Delta V = \sqrt{3}\,I(R\cos\theta + X\sin\theta)\,[\text{V}]$
√3 は (Rcosθ+Xsinθ) の外側全体にかかる。Vs = Vr + ΔV。
02
**電圧降下（単相2線式）**
$\Delta V = 2I(R\cos\theta + X\sin\theta)\,[\text{V}]$
往復2線分で係数は2。三相の √3 と取り違えない。
03
**電力損失（三相3線式）**
$P_{\text{loss}} = 3I^2R\,[\text{W}]$
cosθ は式に現れないが、力率が低いと I が増えて損失は増える（力率は I に織込み済み）。
04
**送電効率**
$\eta = \dfrac{P_r}{P_r + P_{\text{loss}}} \times 100\,[\%]$
Pr=受電端電力、Ploss=線路損失。
05
**百分率電圧降下率**
$\delta = \dfrac{\Delta V}{V_r} \times 100\,[\%]$
Vr は線間/相のどちらかに統一して使う。
フェランチ効果 — 軽負荷時に受電端電圧が上がる
長い送電線や地中ケーブルは対地静電容量 C が大きく、軽負荷・無負荷でも**進み電流（充電電流）**が流れる。これがリアクタンス X を通ると電圧上昇（+jX）方向に作用し、受電端電圧が送電端より**高くなる**。対策は**分路リアクトル**で進み電流を吸収。「重負荷時」「電圧が下がる」と書いた選択肢は誤り。
仕組みは**1本の向き**で決まる——充電電流は受電端電圧より **90°進み**、その電流が作る $jXI$ はさらに90°進んで基準と正反対を向く。だから送電端電圧の方が短くなり、**受電端電圧 > 送電端電圧**になる。遅れ負荷のときは $jXI$ が基準と同じ向きに効いて電圧が下がるので、**向きが逆転するのは電流が進みだから**。C が大きい地中ケーブル・長距離線ほど強く出る。

## 8.解法パターン（三相電圧降下）

例題: Vr=66kV・20MW・力率0.8(遅れ)・R=10Ω・X=15Ω → 送電端電圧は？
① 線電流を求める：
$I = \dfrac{20\times10^{6}}{\sqrt{3}\cdot 66\times10^{3}\cdot 0.8} \approx 218.7\,\text{A}$
② $\sin\theta = \sqrt{1-0.8^2} = 0.6$ を使って電圧降下：
$\Delta V = \sqrt{3}\cdot 218.7\cdot(10\cdot0.8 + 15\cdot0.6) = \sqrt{3}\cdot 218.7\cdot 17 \approx 6.44\,\text{kV}$
③ 送電端電圧：$V_s = V_r + \Delta V = 66 + 6.44 \approx 72.4\,\text{kV}$
R の定義を誤解する引っかけ
R は「1線あたりの抵抗」。「1kmあたり0.1Ω・線路長50km」なら R = 5Ω。三相3線式で往復分を足してはいけない（$3I^2R$ の「3」が既に3線分）。Δ結線では線電流 $I_L = \sqrt{3}\,I_P$ に変換してから使う。
