## 1.Day 3（試験3日前）— 数値と公式の因果確認

### 水力発電の出力公式P = 9.8QHη の根拠

水の密度 ρ = 1,000 kg/m³、重力加速度 g = 9.8 m/s²。水の質量流量 = ρQ [kg/s]、位置エネルギー = mgh なので、理論水力  $P_0 = \rho g Q H = 1000 \times 9.8 \times Q \times H\,[\text{W}] = 9.8QH\,[\text{kW}]$ 。ηは水車・発電機の総合効率。9.8 は ρg を単位変換した係数であり、丸暗記ではなく物理量の積。

確認事項:
- Q[m³/s]、H[m]、η（小数）の単位を正しく代入できるか
- 「9.8 は ρg から導出される」と説明できるか
- 揚水時の所要電力  $P = 9.8QH_p / \eta$ （ηで割る。 $H_p$ ＝全揚程＝総落差＋損失水頭）と発電時（ηを掛ける）を混同しないか

### 電圧降下式単相と三相で係数が異なる理由

単相2線式: 往路・復路の2本分の抵抗・リアクタンスが直列に入るため、係数は2。 $v = 2I(R\cos\phi + X\sin\phi)\,[\text{V}]$

三相3線式: 線電流は1本分だが、線間電圧は相電圧の√3倍。 $v = \sqrt{3}\,I(R\cos\phi + X\sin\phi)\,[\text{V}]$

「なぜ√3か」— 三相の1線あたりの電圧降下は  $I(R\cos\phi + X\sin\phi)$  だが、これは相電圧の降下。線間電圧は √3 倍なので全体も √3 倍になる。

確認事項:
- 単相2線式の係数「2」の理由を説明できるか
- 三相3線式の係数「√3」の理由を説明できるか
- R・X・φの定義（R=抵抗、X=リアクタンス、φ=力率角）を言えるか

### 電力損失式P_loss = 3I²R のI²とその意味

3本の電線それぞれでジュール熱が発生する。1本あたりの損失は  $I^2R$ 。3本分の合計が  $3I^2R$ 。

I²になる理由: ジュール熱は電圧×電流 = (IR)×I = I²R。電圧に比例するのではなく、電流の2乗に比例する。これは銅損の本質。

確認事項:
- 「なぜ I² か」をオームの法則から導けるか
- 3線分あるのに係数「3」と、三相の√3の混同をしていないか

### 力率改善（コンデンサ進相）コンデンサで線電流が減る理由

有効電力  $P = \sqrt{3}\,V I \cos\phi$  が一定のとき、cosφが上がると  $I = P/(\sqrt{3}\,V\cos\phi)$  は下がる。コンデンサは遅れ電流（誘導性負荷）に対して進み電流を供給し、電源から見た無効電流を相殺→合成電流（線電流）が減少する。

確認事項:
- コンデンサが「進み無効電力を供給する」ことを説明できるか
- 線電流が減ることで電圧降下・電力損失が同時に減る連鎖を説明できるか

## 2.Day 2（試験2日前）— 引っかけパターン復習

### DS→CB操作順序操作順序の誤りを突く引っかけ（電力 R3 問8、法規 R4下 問9 で出題）

投入時: DS（断路器）先投入 → CB（遮断器）後投入。開放時: CB先開放 → DS後開放。

理由: DSはアーク消弧能力がない。負荷電流が流れている状態でDSを操作するとアークが発生し事故につながる。CBはアーク消弧機能を持つため、電流を切る操作は必ずCBで行う。

確認事項:
- 「DSはアーク消弧できない→負荷電流が流れていない状態でだけ操作」を言えるか
- 投入・開放それぞれの手順を、理由とセットで説明できるか

### 揚水発電の効率方向発電時と揚水時でηの使い方が逆

発電時:  $P_{\text{出力}} = 9.8QH\eta$ （η掛け → エネルギーが減る方向）。揚水時:  $P_{\text{入力}} = 9.8QH_p / \eta$ （ $H_p$ ＝全揚程）（η割り → 入力エネルギーが増える方向）。

理由: 発電時は水のエネルギーから損失を引いて電気出力を得る（出力 < 理論値）。揚水時は必要な位置エネルギー以上のエネルギーを電力で投入しなければならない（入力 > 理論値）。

確認事項:
- 「入力=必要量/η、出力=投入量×η」という方向性を即答できるか

### 風力出力の風速指数v²ではなくv³

風力発電の出力  $P \propto v^3$ 。

理由: 空気 1 kg がもつ運動エネルギーは  $\frac{1}{2}v^2$ 。単位時間に通る空気の質量（質量流量）は  $\rho Av$ （密度×断面積×風速）。よって  $P = \frac{1}{2}v^2 \times \rho Av \propto v^2 \times v = v^3$ 。

確認事項:
- 「質量流量がvに比例するため、指数が2から3になる」を説明できるか
- 風速が2倍になると出力は8倍（2³）になることを即答できるか

### 変圧器並行運転条件並行運転の条件（単相の4つ＋三相で加わる2つ）
- 巻数比（変圧比）が等しい: 異なると循環電流が流れ、無駄な損失が発生する
- 極性が等しい: 異なると電圧が打ち消しあい短絡状態になる
- 百分率インピーダンスが等しい: 異なると負荷分担が変圧器容量に比例しない
- 抵抗とリアクタンスの比（R/X）が等しい: 異なると両機の電流の位相がずれ、合計容量を使い切れない

▶ 三相ではこの4つでは足りない。相回転が等しい・角変位（位相変位・結線群）が等しいの2つが加わる。Yd1 と Dy11 を並行運転できないのはこの角変位条件を満たさないためで、60°が閾値なのではなく「異なれば不可」（Y-Y と Yd1 の30°差でも不可）。結線の名前では決まらず、Δ-Y も遅れ30°に組めば（Dy1）Yd1 と角変位が一致する。

確認事項:
- 4条件それぞれの理由（満たさないと何が起きるか）を説明できるか
- 三相で加わる2条件（相回転・角変位）を言えるか。単相の条件で止まると三相の設問を落とす
- 「負荷分担は %Z に反比例（容量が違えば P_n/%Z の比）→ %Z が小さい方が先に定格に達する（過負荷になる）」を言えるか

### 原子力ほぼ毎回 問4 の枠。K2 の集計で H18〜R08上 の25回中23回逆に覚えると失点する3点

制御棒の向き: 挿入 → 中性子吸収が増え出力低下／引抜 → 出力上昇。緊急停止（スクラム）は全制御棒の一斉挿入。

BWR と PWR: 炉内の蒸気が直接タービンへ行くのが BWR（1系統・蒸気が放射性）。PWR は一次冷却水を沸騰させず蒸気発生器を介す（2系統）。逆に書いた選択肢が頻出。

熱効率: 原子力は火力より低い（軽水炉は約30〜35%）。安全上の制約で高温蒸気を使えないため。「原子力の方が高効率」は誤り。

確認事項:
- 減速材・冷却材（軽水）と制御棒材料（ハフニウム・ホウ素・カドミウム）を取り違えないか
- CANDU が天然ウランを使えるのは重水の中性子吸収が少ないためだと言えるか
- 核燃料サイクルの順（採掘→精錬→転換→濃縮→加工→原子炉→再処理）を言えるか

### 電気材料ほぼ毎回 問14 の枠。K2 の集計で H18〜R08上 の25回中24回方向を逆にすると失点する3点

珪素含有と鉄損: Si を増やすと電気抵抗率が上がり渦電流が流れにくくなる → 鉄損は減少。「増える」は方向が逆。

SF₆ の問題点: 無色・無臭・無毒で化学的に安定。問題は温暖化係数が CO₂ の約23,500倍であること。「毒性がある」は取り違え。

耐熱クラス: F＝155℃／H＝180℃（B＝130℃）。F と H を入れ替えた選択肢に注意（電力・機械・法規 H28〜R8上 の15回では未出題）。

確認事項:
- アルミの導電率は銅の約60%だが、比重が約1/3なので重量あたりで有利＝ACSR が主流、と説明できるか

## 3.Day 1（試験前日）— B問題計算の最終確認

### 送電線路の計算手順電圧降下・電力損失の計算ステップ
- 負荷電流 I を求める:  $I = P / (\sqrt{3}\,V_r\cos\phi)$ （ $V_r$ ＝受電端の線間電圧）
- 電圧降下  $v = \sqrt{3}\,I(R\cos\phi + X\sin\phi)$  を計算
- 電力損失  $P_{\text{loss}} = 3I^2R$  を計算
- 送電端電圧  $V_s = V_r + v$ （受電端基準の場合）

ミスしやすい点:
- IはP[W]・V[V]で計算→[A]になっているか単位確認
-  $\sin\phi = \sqrt{1 - \cos^2\phi}$  を計算し忘れる
- 受電端電圧Vrか送電端電圧Vsか問題文をよく読む

確認事項:
- 上記4ステップを見ずに再現できるか
- sinφの計算を素早く行えるか（cos=0.8→sin=0.6、cos=0.6→sin=0.8）

### 変圧器効率の最大条件鉄損 = 銅損のとき効率最大になる数学的根拠

効率  $\eta = P_{\text{out}} / (P_{\text{out}} + P_i + P_c)$
-  $P_i$  = 鉄損（負荷に無関係・一定）
-  $P_c$  = 銅損（負荷電流Iの2乗に比例:  $P_c = m^2 P_{cn}$ 。 $m = I/I_n$  ＝負荷率、 $P_{cn}$  ＝定格時の銅損）

最小化するのは合計損失ではなく出力あたりの損失である。 $\eta = \dfrac{mP_n\cos\phi}{mP_n\cos\phi + P_i + m^2 P_{cn}}$ （ $P_n$ ＝定格容量[kV·A]） 分子分母を  $m$  で割ると、 $\eta$  最大 ⇔  $f(m)=\dfrac{P_i}{m} + mP_{cn}$  最小。ここで積  $\dfrac{P_i}{m}\cdot mP_{cn} = P_i P_{cn}$  が  $m$  に依らず一定だから、AM-GM より両項が等しいとき和が最小＝ $P_i = m^2 P_{cn} = P_c$ 。「合計損失 P_i+P_c を最小化」は誤り（ $P_i + m^2P_{cn}$  は  $m$  について単調増加で、最小化すると  $m=0$  になってしまう）。AM-GM も「積が最小」ではなく「積が一定」が前提である。

確認事項:
- 「鉄損＝銅損」が最大効率（＝出力あたり損失が最小）の条件であることを導けるか。「合計損失が最小」ではない（総損失は負荷とともに単調に増える）
- 最大効率時の負荷率  $m = \sqrt{P_i / P_{cn}}$  を式から導けるか
