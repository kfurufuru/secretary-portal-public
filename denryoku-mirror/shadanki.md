# 遮断器・断路器（CB・DS）

負荷電流・事故電流を実際に切るのが遮断器（CB）、無負荷時の電路分離専用が断路器（DS）。操作順序（入はDS→CB・切はCB→DS）と消弧媒体（OCB油/ABB空気/GCB・GISはSF6/VCBは真空）が論点。開閉装置は問6〜問7 に置かれることが多く、GIS が最頻。出題頻度: 高（変電・問6〜問7 が中心）難易度: ★★☆出題形式: 論説・穴埋（操作順序/消弧媒体/遮断能力）

## 1.直感的理解 — CBは「切れる」DSは「切れない」

遮断器の本質は、電力系統で電流を強制的に止める機器。負荷電流（正常）も事故電流（異常）も両方遮断できるのが遮断器（CB）、無負荷時の電路分離専用が断路器（DS）。DSは電流を切る能力を持たない点が、すべての論点の出発点になる。役割分担をアナロジーで（最重要）

| 機器 | アナロジー | 負荷電流遮断 | 事故電流遮断 |
| --- | --- | --- | --- |
| 断路器（DS） | 工事用バルブ（電気が来ていない確認用） | ✕ | ✕ |
| 遮断器（CB） | 高速シャッター（電気が流れていても切れる） | ○ | ○ |
| 負荷開閉器（LBS） | 通常用バルブ（事故時は使えない） | ○ | ✕ |
操作順序（電力 R3 問8、法規 R4下 問9 で出題）— 入はD→C・切はC→D
- 投入時：DS → CB の順（先にDSを閉→その後CBを閉）
- 開放時：CB → DS の順（先にCBを開→その後DSを開）

断路器（DS）は電流遮断能力を持たない。DSの接触子はアーク消弧機能を持たないため、電流が流れた状態で開放するとアーク放電が持続し機器を破損する。投入時はまずDSを閉じて回路を形成し、その後CBを閉じる。負荷電流はCBが入った瞬間から流れ始めるため、DSは負荷電流が流れていない状態で操作できる。開放時は先にCBを開いて負荷電流を切ってからDSを開く。逆にするとDSがアーク電流を遮断しようとして焼損する。「入はD→C・切はC→D」と5秒で書き出してから選択肢と照合する。

- 構造消弧室が無く、空気中でそのまま開く

> 写真の断路器には消弧室がなく、負荷電流を切れない（R03 問8 (1)「消弧装置をもたないため、負荷電流の遮断を行うことはできない」）。だから入れるときは DS → CB、切るときは CB → DS（開放の順 CB → DS は電力 R03 問8 (2)・法規 R4下 問9 で出題）。単線の模式で、実際は CB の両側に DS を置くことが多い。📊 このセクションの理解度:◎○△×

## 2.設備を歩く — 系統内の配置と物理構造

CBの前後にDSを配置するのが標準。保守時にはCBを開放してから両端のDSを開き、保守区間を完全に系統から切り離す。系統側から「DS → CB → DS → 負荷側」と並び、OCR等の継電器がトリップ指令をCBに送る。遮断器の共通動作（消弧で種類が決まる）

トリップ指令 → 操作機構（バネ／油圧／電磁）が動作 → 接触子が開離 → その瞬間にアークが発生 → 消弧媒体（油／空気／SF6／真空）で消弧 → 電流遮断完了、という流れは全遮断器に共通。このアークをどう消弧するかで遮断器の種類が決まる。📊 このセクションの理解度:◎○△×

【引っかけ】断路器（DS）の誤操作（電力 R3 問8 で出題）

「断路器は電流を遮断できる」→誤り。断路器には電流遮断能力がない。負荷電流が流れた状態でDSを開放するとアーク放電が発生し、機器破損・感電の危険がある。必ずCBで電流を遮断してからDSを操作すること。試験では「断路器で事故電流を遮断した」という記述は誤り。LBS・PAS・UGSは「事故電流は切れない」点で共通

LBS・PAS・UGSは負荷電流は開放できるが短絡電流は遮断不可。短絡電流はCBに任せる構成が前提（PAS・UGSのSOG動作は、地絡＝即時開放／短絡＝上位CB遮断後に無電圧開放）📊 このセクションの理解度:◎○△×

## 5.消弧物理（GIS・VCBが主流になった理由）VCB（真空遮断器）

真空中でも、開いた電極から蒸発した金属蒸気の中でアーク（真空アーク）が電流ゼロ点まで続く。電流がゼロになる瞬間に金属蒸気がすばやく拡散・凝縮し、真空の高い絶縁耐力がすぐ回復するので消弧する。保守が少なく、油も不要で環境負荷が小さい。接触子の摩耗も小さく、開閉寿命が長い。GIS（ガス絶縁開閉装置）

SF6ガスは空気の約3倍の絶縁耐力を持つ。高絶縁性により機器をコンパクト化でき、都市部の狭い敷地に建設できる。CB・DS・LA（避雷器）等を、接地した金属容器（ガス区画ごとに分かれて連なる）に収めた一体型設備で、保守時の手間が大幅に削減される。
- 容器には、大気圧より高い圧力の SF6 ガスを詰める（R07上 問6 で「大気圧以下」が誤り）。
- 充電部を支えるスペーサなどの絶縁物には、エポキシ樹脂を使う。
- 充電部が密閉されているので、大気中の汚染物の影響を受けず、信頼性が高い。そのかわり、内部事故が起きたときの復旧時間は長い（容器を開けて直す必要がある）。
- 容器の中に金属の異物が入ると絶縁性能が下がるので、製造・据付けでは異物の混入を防ぐ。

R06上 問6 の正答は (2)（SF6 ガス・エポキシ樹脂・高い・長い）。問題文と正答は、試験センターの問題 PDF と解答 PDF で確認した。【引っかけ】GISの絶縁媒体（SF6 ガスは電力 H28〜R8上 の15回中10回に登場）

「GISは圧縮空気を絶縁媒体に使用する」→誤り。GISはSF6（六フッ化硫黄）ガスを使用。圧縮空気を使用するのは空気遮断器（ABB）。GISではSF6ガスが絶縁・消弧の両方を担う。SF6ガスの環境問題（近年論点）

SF6は100年GWP（地球温暖化係数）がCO2の約23,500倍（IPCC AR5。AR6では25,200に更新）と非常に高い。漏洩防止・回収・再使用の管理が国際的に厳格化されている。試験では直接問われにくいが、近年の論点として頭の片隅に。📊 このセクションの理解度:◎○△×
