# 地中送電・電力ケーブル

架空送電線を地中に埋めたもの。都市部・海底・景観保護で使われる。架空線との「L小・C大・フェランチ効果が起きやすい」の逆転と、CV／OFケーブルの誘電損・最高使用温度の比較が頻出。充電電流 Ic=ωCV の計算も問われる。
**出題頻度:** 高（毎年級・問9前後で循環出題）
**難易度:** ★★☆
**出題形式:** 論説・穴埋め・計算（充電電流/誘電損）

## 1.直感的理解 — 地中ケーブルの3大問題

地中送電は**架空送電線を地中に埋めたもの**。都市部・海底・景観保護が必要な地域で使われ、雷・風雪・塩害の影響を受けにくく信頼性が高い。一方で、建設費が高い・放熱が困難・充電電流が大きいという課題がある。架空線が空気で放熱するのに対し、地中ケーブルは**土に頼って放熱する**ため放熱が難しい。
3大問題の「なぜ」をセットで覚える
- **コスト高** — 掘削工事・専用管路・マンホール設置が必要。架空の5〜10倍以上。
- **放熱困難** — 大電流では土壌では放熱が追いつかず、許容電流が制限される。
- **充電電流大** — 導体と遮へい層の間隔が数mm〜数十mmと小さく、静電容量 C が架空線より桁違いに大きい。充電電流 $I_c = \omega C E$（$E$＝相電圧）なので、C が大きいほど充電電流も大きく、長距離ほど顕著になる。

## 2.設備を歩く — CVケーブルの断面構造

主流の CV ケーブル（架橋ポリエチレン絶縁ビニルシース）は、内側から外側へ次の6層で構成される。

| 層 | 名称 | 役割 |
| --- | --- | --- |
| ① | 導体 | 電流を流す主体。銅またはアルミ |
| ② | 内部半導電層 | 導体表面の電界を均一化（電界集中を防ぐ） |
| ③ | 絶縁体（XLPE） | 電気絶縁の主体。架橋ポリエチレン |
| ④ | 外部半導電層 | 絶縁体外面の電界を均一化 |
| ⑤ | 遮へい | 漏れ電流・誘導電流を流す。接地する |
| ⑥ | シース（ビニル防食層） | 機械的保護・防水 |

半導電層が絶縁体の内外両側にある理由（因果理解）
導体の断面は完全な真円でなく表面に微小な凹凸があり、導体の角や凸部には電界が集中する（尖った導体ほど電荷密度が高くなるガウスの法則の帰結）。**内部半導電層**は導体と絶縁体の間に均一な電位面を作る緩衝層として働き、電界集中を防いで絶縁体への局所的なストレスを抑える。**外部半導電層**も絶縁体外面の電界を均一化し、遮へい層との界面での電界集中を防ぐ。両側に設けることで絶縁体全体に均一な電界が印加され、絶縁寿命が向上する。

## 3.同軸円筒ケーブルの電界分布と電位傾度

電力ケーブルは、中心の**円筒導体**を絶縁体が包み、その外を**遮へい層（外側の円筒）**が同心状に覆う**同軸円筒構造**。導体と遮へいの間（絶縁体の中）には架空送電線と同じく放射状の電界ができるが、外側が遮へいで閉じている点が違う。導体半径を $d/2$、遮へい内半径を $D/2$ とすると、絶縁体内の距離 $r$ の点の電界は次式で表される。
C1
**同軸円筒内の電界（絶縁体中・d/2 ≤ r ≤ D/2）**
$E(r) = \dfrac{V}{r\,\ln(D/d)}\;[\text{V/m}]$
V=導体・遮へい間の電圧。分母 ln(D/d) は後述の静電容量 C=2πε/ln(D/d) と同じ項。E は 1/r で減衰し、内側の導体表面（r=d/2）で最大になる。
**電界は内側の導体表面で最大**（電位傾度が最大）、遮へい側で最小になる。導体表面の最大電位傾度は次式で、絶縁体はこの最大値に耐えなければならない。
C2
**導体表面の最大電位傾度**
$E_{\max} = \dfrac{V}{(d/2)\,\ln(D/d)} = \dfrac{2V}{d\,\ln(D/d)}\;[\text{V/m}]$
r=d/2（導体表面）での値。細い導体・薄い絶縁ほど E_max が大きくなり、絶縁ストレスが増す。
左: 同軸円筒ケーブル断面（導体・絶縁体・遮へい）と絶縁体内の放射状電界。右: 電界 E は導体表面（d/2）で最大、遮へい（D/2）で最小の 1/r 分布。
架空送電線のコロナ（円筒導体の電界）と同じ物理
これは架空送電線ページの「円筒導体まわりの電界 $E = \lambda/(2\pi\varepsilon_0 r)$」と同じ 1/r の放射状電界。違いは、架空線が**開放空間**で電界が遠方まで広がるのに対し、ケーブルは**遮へいで閉じた同軸空間**で電界が絶縁体内で完結し外へ漏れない点。どちらも**導体表面で電界が最大**になり、そこが絶縁の弱点になる。
なぜ半導電層で導体表面をならすのか（設備構造との接続）
最大電位傾度 $E_{\max}$ は導体表面に集中するため、導体表面に微小な凹凸や突起があると、その先端で電界がさらに局所的に跳ね上がって絶縁体を傷める。**内部半導電層**は導体表面をなめらかな等電位面にならし、$E_{\max}$ を設計値どおりに抑える。設備構造の「半導電層で電界を均一化」は、この最大電位傾度の局所集中を防ぐ操作である。
絶縁は薄いほどよい…わけではない（電界と静電容量のトレードオフ）
絶縁層を薄く（D/d を 1 に近づける）すると静電容量 $C = 2\pi\varepsilon/\ln(D/d)$ は大きくなるが、同時に $E_{\max} = 2V/(d\ln(D/d))$ も大きくなり絶縁破壊しやすくなる。実務では導体径・絶縁厚を、$E_{\max}$ が絶縁材料の耐電界以下に収まるよう設計する。3種では「導体表面で電界最大・薄い絶縁ほど電位傾度が大きい」という定性関係を押さえれば十分。

## 4.架空送電 vs 地中送電 比較表（最重要）

架空線と地中ケーブルで **L・C・フェランチ効果のしやすさが逆転**する点が試験の急所。

| 項目 | 架空送電線 | 地中ケーブル |
| --- | --- | --- |
| 建設費 | 低い | 高い（5〜10倍以上） |
| 保守・復旧 | 巡視は容易・事故復旧は早い | 故障は少ないが、**事故点の探査・復旧に長時間**かかる |
| 信頼性・事故頻度 | 低（雷・風雪・塩害の影響大） | 高（外部環境の影響小） |
| 事故復旧時間 | 短い（目視で発見しやすい） | 長い（掘削が必要） |
| 充電電流 | 小さい | **大きい**（静電容量 C が大） |
| インダクタンス L | 大きい | **小さい**（導体間距離が小さい） |
| 静電容量 C | 小さい | **大きい**（導体間距離が小さい） |
| フェランチ効果の発生しやすさ | 比較的少ない | **発生しやすい**（C が大のため） |
| 熱放散 | 容易（空気冷却） | 困難（土壌依存） |
| 環境影響・景観 | 鉄塔が目立つ・土地が使えない | 地中化で景観保護・土地は使える |

## 5.ケーブルの種類比較（CV と OF）

| 種類 | 絶縁材料 | 誘電正接 tanδ | 最高使用温度 | 特徴 |
| --- | --- | --- | --- | --- |
| OFケーブル（油浸紙絶縁油入） | 浸油紙 | 大きい（目安 0.002〜0.004） | 75〜85℃ | **絶縁油を加圧・給油し、絶縁層内にボイド（空隙）が生じるのを防ぐ**方式。給油設備が要り油圧管理が必要・漏油リスク |
| CVケーブル（XLPE絶縁ビニルシース） | XLPE | **小さい**（目安 0.0003〜0.001） | **90℃** | 軽量・油不要・現在の主流 |
| CVTケーブル | XLPE（単心3条） | 小さい | 90℃ | 単心ケーブルを3本撚り合わせ |

CV が OF より誘電損が少ない理由（因果理解）
誘電損 $P_d = \omega C V^2 \tan\delta$ から、絶縁材料の誘電正接 $\tan\delta$ が誘電損を左右する。OFケーブルの絶縁体（浸油紙）は油を含む有機紙で、双極子（分子の正負の電荷の中心がずれた構造）が交番電界で向きを変えるたびにエネルギーを消費する。この分子レベルの摩擦が誘電損の正体。XLPE は分子構造が均一で双極子が少なく $\tan\delta$ が桁違いに小さいため、同じ電圧・静電容量でも誘電損が OF の数分の一になる。最高使用温度も CV（90℃）が OF（75〜85℃）より高く、CV の方が許容電流を大きく取れる。

- **硬銅線 ↔ 亜鉛めっき鋼線**：赤銅色で導体用が硬銅線、銀色で支持・補強用が亜鉛めっき鋼線（電流より強度）。
- **硬銅線 ↔ アルミ線**：導電性の銅（配電・引込）と、軽量で長スパン向きのアルミ（架空送電導体）。
- **CV ↔ CVT**：1本の丸形が CV、単心3本をより合わせたのが CVT（三相3線）。
- **IV ↔ HIV**：見た目はほぼ同じ。**耐熱グレードが HIV**。
- **ACSR ↔ TACSR**：どちらも鋼心アルミより線で**外観だけでは判別できない**。問題文の「**耐熱・大容量・電流増加**」の記述があれば TACSR（耐熱アルミ合金）と判断する。
- **高圧絶縁電線 ↔ ACSR**：被覆ありで電柱の配電が高圧絶縁電線、被覆なしの裸より線で鉄塔の送電が ACSR。

## 7.布設方式の3分類（管路式・暗きょ式・直接埋設式）

地中電線路の布設方式は**管路式・暗きょ式・直接埋設式**の3つ。当Wikiの分野別集計では近年の下期に布設方式を含む地中電線路の論説が続けて挙がっている（**年度・問番号は試験センター公表の過去問で要確認**）。**「放熱（許容電流）」と「外傷・保守性」が裏返しのトレードオフになる**点が狙われる。（施設基準の条文そのものは法規科目の範囲）

| 比較軸 | 直接埋設式 | 管路式 | 暗きょ式（洞道） |
| --- | --- | --- | --- |
| 布設方法 | ケーブルを直接土中に埋設 | 埋設した管に引き入れる | 地下の暗きょ内に布設 |
| 建設費・工期 | **安い・短い** | 中 | **高い・長い** |
| 放熱・許容電流 | **良い**（土壌に直接接触） | **悪い**（管内の空気層で熱がこもる） | 換気により確保（多条時は相互加熱に注意） |
| 外傷・第三者被害 | **受けやすい** | 受けにくい | 受けにくい |
| 多条数の布設 | 不向き | 中 | **最も多条に対応** |
| 増設・引替・保守 | **困難**（掘削が必要） | 容易（マンホールから引替。増設は予備管がある場合） | **容易**（人が立ち入れる） |

【頻出】「安い方式ほど放熱が良い」— 直感と逆になる
**直接埋設式は最も安く工期も短いのに、管路式より放熱が良く許容電流を大きく取れる**。ケーブルが土に直接触れて熱が逃げるため。逆に管路式は**管内の空気層が断熱材のように働き、放熱が悪く許容電流が小さくなる**。「管路で保護されている＝性能も上」と考えると逆を選ばされる。（同一条件・少条数での比較。直接埋設でも多条を近接させれば相互加熱で許容電流は下がる）
ただし直接埋設式は**外傷を受けやすく、増設・事故復旧に掘削が必要**という弱点があり、これが管路式・暗きょ式の長所とちょうど裏返しになる。**「安い・放熱良い」と「守られている・保守しやすい」はセットで手に入らない**と押さえる。

## 8.公式マップ（最重要）

01
**充電電流（ケーブルはコンデンサ・E は相電圧）**
$I_c = \omega C E = 2\pi f C E\,[\text{A}]$
ω=2πf（角周波数）、C=ケーブルの静電容量[F]、E=相電圧（対地電圧）[V]（三相なら線間電圧÷√3）。ケーブルに交流を印加すると Q=CE が充電され、電流は電荷の時間微分で振幅 ωCE。三相の充電容量を問われたら Q_c=3ωCE²=ωCV²（V=線間）で、下の誘電損と同じ「E か V か」の取り違えが起きる。
02
**誘電損（絶縁体の損失）**
$P_d = \omega C E^2 \tan\delta\,[\text{W}]$
E は対地電圧（相電圧）で【1相分】。三相合計は 3ωCE²tanδ で、線間電圧 V で書き直すと E=V/√3 より ωCV²tanδ となり字面が1相分の式と同じになる（√3の2乗=3 が相数3と打ち消すため）。E と V のどちらの式かを取り違えて3倍を重ねる／落とすのが最頻出ミス。tanδ=誘電正接（絶縁材料の損失特性）。理想コンデンサは有効電力0だが、実際は損失角δだけ90°からずれ P=VI sinδ。δが小さく sinδ≈tanδ として整理。OFより CVの方が tanδ が小さく誘電損が少ない。
03
**ケーブルの静電容量（同軸構造）**
$C = \dfrac{2\pi\varepsilon}{\ln(D/d)}\,[\text{F/m}]$
D=外側導体（遮へい）径、d=内側導体径。D/d が小さい（導体と遮へいが近い）ほど C が大きい。地中ケーブルは絶縁層が薄く C が大、架空線は導体間距離が大きく C が小。
C が大きいか小さいかは「導体間距離」で決まる
**架空送電線**は導体間（または導体と大地間）の距離が数m〜数十mと大きいので C は小さい。**地中ケーブル**は絶縁層が薄く導体と遮へい層の距離が数mm〜数十mmと小さいので C は大きい。この「距離が近い＝C大」が、充電電流大・フェランチ効果が起きやすいことの根本原因。
ケーブルの損失は3つ — 抵抗損・誘電体損・シース損
ケーブルで発生する損失は次の3つ。どれか1つを問われることが多いので**3点セットで覚える**。
1. **抵抗損（導体損）** — 導体の抵抗に電流が流れて生じる $I^2 R$。負荷電流の2乗で増え、**通常の負荷運転時には3損失中で最大**。ただし**無負荷・軽負荷では電流が小さく、電圧で決まる誘電体損の方が相対的に大きくなる**。
2. **誘電体損（誘電損）** — 絶縁体の分子摩擦。1相分は $P_d = \omega C E^2 \tan\delta$（$E$＝対地電圧）で、**三相合計はその3倍**（線間電圧 $V$ で書けば $\omega C V^2 \tan\delta$）。**電圧が掛かっていれば無負荷でも発生**するのが特徴。
3. **シース損** — 金属シース（遮へい層）に生じる損失。**単心ケーブル**では導体電流がつくる磁束でシースに電圧が誘起され、**シースの両端を接地すると循環電流が流れて発熱する**（シース回路損）。ほかに渦電流損もある（3心ケーブルは3相の磁束がほぼ打ち消し合うため問題になりにくい）。

**シース回路損（循環電流）の低減策＝クロスボンド接地**。ケーブルの**大区間（メジャーセクション）を3等分した小区間ごとに3相のシースを順番に入れ替えて接続**すると、大区間トータルでシースの誘起電圧の和がほぼゼロになり、循環電流が流れなくなる（短距離線路では**片端接地**も用いられる）。なお**渦電流損はクロスボンドでは消えない**点に注意

## 9.解法パターン（充電電流の計算）

充電電流 Ic=ωCE（E は相電圧）の見分け方と手順
**見分け方**：「地中ケーブル」「静電容量 ○ μF/km」「充電電流」のキーワードが揃っている。
1. $\omega = 2\pi f$ を計算（f=50Hz なら ω=2π×50≈314 rad/s）
2. 静電容量を F に換算（μF/km なら線路長[km]を掛けて全体の C[F] に）
3. 三相なら相電圧 $E = V_L/\sqrt{3}$ を使って $I_c = \omega C E$ に代入（**線間電圧 $V_L$ をそのまま入れない**——√3 倍に誤る）

例題: 線路長10km・静電容量0.2μF/km・66kV系統・f=50Hz の充電電流は？
① 全体の静電容量：
$C = 0.2\times10^{-6}\times 10 = 2\times10^{-6}\,\text{F}$
② 角周波数：$\omega = 2\pi\times50 \approx 314\,\text{rad/s}$
③ 三相なので相電圧を使う：$V = \dfrac{66{,}000}{\sqrt{3}} \approx 38{,}105\,\text{V}$
④ 充電電流：
$I_c = 314 \times 2\times10^{-6} \times 38{,}105 \approx 23.9\,\text{A}$

## 10.引っかけ・誤答ポイント

【頻出1】L と C の大小が架空と逆
「地中ケーブルは架空送電線よりインダクタンス L が大きく、静電容量 C が小さい」→ **誤り**。導体間距離が小さいため **L は小さく・C は大きい**。架空線とまったく逆になる点が狙われる。
【頻出2】フェランチ効果は地中ケーブルで起きやすい
「フェランチ効果は架空送電線の方が起きやすい」→ **誤り**。フェランチ効果（受電端電圧が送電端電圧より高くなる現象）は**静電容量 C が大きいほど発生しやすい**。地中ケーブルは C が桁違いに大きく、軽負荷・無負荷時に充電電流による進み無効電力が大きくなるため、フェランチ効果が顕著になる。
【頻出3】CV と OF の最高使用温度
「CVケーブルの最高使用温度は OF ケーブルより低い」→ **誤り**。CV（XLPE絶縁）は **90℃**、OF（浸油紙絶縁）は75〜85℃。CV の方が高く、許容電流を大きく取れる。
【頻出4】事故復旧時間は信頼性とは別の指標
「地中ケーブルの事故復旧は架空送電線より短時間で済む」→ **誤り**。事故**頻度**（信頼性）は地中の方が低い（高信頼）が、一度事故が起きると掘削が必要なため**復旧時間は長い**。信頼性と復旧時間を混同させる引っかけ。
