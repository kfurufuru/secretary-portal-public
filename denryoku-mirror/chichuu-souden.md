# 地中送電・電力ケーブル

架空送電線を地中に埋めたもの。都市部・海底・景観保護で使われる。架空線との「L小・C大・フェランチ効果が起きやすい」の逆転と、CV／OFケーブルの誘電損・最高許容温度の比較も問われる（R05下・H30）。充電電流 Ic=ωCE（E は相電圧）の計算も問われる。出題頻度: 高（R04下 から問10 で8回連続）難易度: ★★☆出題形式: 論説・穴埋め・計算（充電電流/誘電損）

## 1.直感的理解 — 地中ケーブルの3大問題

地中送電は架空送電線を地中に埋めたもの。都市部・海底・景観保護が必要な地域で使われ、雷・風雪・塩害の影響を受けにくく信頼性が高い。一方で、建設費が高い・放熱が困難・充電電流が大きいという課題がある。架空線が空気で放熱するのに対し、地中ケーブルは土に頼って放熱するため放熱が難しい。3大問題の「なぜ」をセットで覚える
- コスト高 — 掘削工事・専用管路・マンホール設置が必要で、架空より大幅に高い。
- 放熱困難 — 大電流では土壌では放熱が追いつかず、許容電流が制限される。
- 充電電流大 — 導体と遮へい層の間隔が数mm〜数十mmと小さく、静電容量 C が架空線より桁違いに大きい。充電電流  $I_c = \omega C E$ （ $E$ ＝相電圧）なので、C が大きいほど充電電流も大きく、長距離ほど顕著になる。📊 このセクションの理解度:◎○△×

## 2.設備を歩く — CVケーブルの断面構造

主流の CV ケーブル（架橋ポリエチレン絶縁ビニルシース）は、内側から外側へ次の6層で構成される。

| 層 | 名称 | 役割 |
| --- | --- | --- |
| ① | 導体 | 電流を流す主体。銅またはアルミ |
| ② | 内部半導電層 | 導体表面の電界を均一化（電界集中を防ぐ） |
| ③ | 絶縁体（XLPE） | 電気絶縁の主体。架橋ポリエチレン |
| ④ | 外部半導電層 | 絶縁体外面の電界を均一化 |
| ⑤ | 遮へい（金属遮へい層） | 接地して絶縁体の外側を大地の電位にそろえ、電界を絶縁体の中に閉じ込める（静電遮へい）。充電電流・地絡電流の通り道にもなる |
| ⑥ | シース（ビニル防食層） | 機械的保護・防食。CV ケーブルは水トリー（水と電界による絶縁劣化）を防ぐため、金属シースや遮水層を別に設ける場合がある（R07上 問10(3) の正しい記述） |
半導電層が絶縁体の内外両側にある理由（因果理解）

導体の断面は完全な真円でなく表面に微小な凹凸があり、導体の角や凸部には電界が集中する（尖った導体ほど電荷密度が高くなるガウスの法則の帰結）。内部半導電層は導体と絶縁体の間に均一な電位面を作る緩衝層として働き、電界集中を防いで絶縁体への局所的なストレスを抑える。外部半導電層も絶縁体外面の電界を均一化し、遮へい層との界面での電界集中を防ぐ。両側に設けることで絶縁体の内外の界面がなめらかな等電位面になり、局所的な電界集中が抑えられて絶縁寿命が向上する。ただし半径方向の電界の強さまでそろうわけではない。電界は導体側で最大になり、外へ向かって 1/r で弱まる（3節）。📊 このセクションの理解度:◎○△×

## 3.同軸円筒ケーブルの電界分布と電位傾度

電力ケーブルは、中心の円筒導体を絶縁体が包み、その外を遮へい層（外側の円筒）が同心状に覆う同軸円筒構造。導体と遮へいの間（絶縁体の中）には架空送電線と同じく放射状の電界ができるが、外側が遮へいで閉じている点が違う。導体半径を  $d/2$ 、遮へい内半径を  $D/2$  とすると、絶縁体内の距離  $r$  の点の電界は次式で表される。C1同軸円筒内の電界（絶縁体中・d/2 ≤ r ≤ D/2） $E(r) = \dfrac{V_0}{r\,\ln(D/d)}\;[\text{V/m}]$ V_0=導体・遮へい間の電圧（＝対地電圧。三相では8節の相電圧 E と同じ値。線間電圧 V をそのまま入れない）。分母 ln(D/d) は後述の静電容量 C=2πε/ln(D/d) と同じ項。E は 1/r で減衰し、内側の導体表面（r=d/2）で最大になる。

電界は内側の導体表面で最大（電位傾度が最大）、遮へい側で最小になる。導体表面の最大電位傾度は次式で、絶縁体はこの最大値に耐えなければならない。C2導体表面の最大電位傾度 $E_{\max} = \dfrac{V_0}{(d/2)\,\ln(D/d)} = \dfrac{2V_0}{d\,\ln(D/d)}\;[\text{V/m}]$ r=d/2（導体表面）での値。絶縁の厚さが同じなら細い導体ほど、導体径が同じなら薄い絶縁ほど E_max が大きくなり、絶縁ストレスが増す。

左: 同軸円筒ケーブル断面（導体・絶縁体・遮へい）と絶縁体内の放射状電界。右: 電界 E は導体表面（d/2）で最大、遮へい（D/2）で最小の 1/r 分布。架空送電線のコロナ（円筒導体の電界）と同じ物理

これは架空送電線ページの「円筒導体まわりの電界  $E = \lambda/(2\pi\varepsilon_0 r)$ 」と同じ 1/r の放射状電界。違いは、架空線が開放空間で電界が遠方まで広がるのに対し、ケーブルは遮へいで閉じた同軸空間で電界が絶縁体内で完結し外へ漏れない点。どちらも導体表面で電界が最大になり、そこが絶縁の弱点になる。なぜ半導電層で導体表面をならすのか（設備構造との接続）

最大電位傾度  $E_{\max}$  は導体表面に集中するため、導体表面に微小な凹凸や突起があると、その先端で電界がさらに局所的に跳ね上がって絶縁体を傷める。内部半導電層は導体表面をなめらかな等電位面にならし、 $E_{\max}$  を設計値どおりに抑える。設備構造の「半導電層で電界を均一化」は、この最大電位傾度の局所集中を防ぐ操作である。絶縁は薄いほどよい…わけではない（電界と静電容量のトレードオフ）

絶縁層を薄く（D/d を 1 に近づける）すると静電容量  $C = 2\pi\varepsilon/\ln(D/d)$  は大きくなるが、同時に  $E_{\max} = 2V_0/(d\ln(D/d))$  も大きくなり絶縁破壊しやすくなる。実務では導体径・絶縁厚を、 $E_{\max}$  が絶縁材料の耐電界以下に収まるよう設計する。3種では「導体表面で電界最大・導体径が同じなら薄い絶縁ほど電位傾度が大きい」という定性関係を押さえれば十分。📊 このセクションの理解度:◎○△×

## 4.架空送電 vs 地中送電 比較表（最重要）

架空線と地中ケーブルで L・C・フェランチ効果のしやすさが逆転する点が試験の急所。

| 項目 | 架空送電線 | 地中ケーブル |
| --- | --- | --- |
| 建設費 | 低い | 高い |
| 保守・復旧 | 巡視は容易・事故復旧は早い | 故障は少ないが、事故点の探査・復旧に長時間かかる |
| 信頼性（事故頻度の低さ） | 低い＝事故頻度は高い（雷・風雪・塩害の影響大） | 高い＝事故頻度は低い（外部環境の影響小） |
| 事故復旧時間 | 短い（目視で発見しやすい） | 長い（掘削が必要） |
| 充電電流 | 小さい | 大きい（静電容量 C が大） |
| インダクタンス L | 大きい | 小さい（導体間距離が小さい） |
| 静電容量 C | 小さい | 大きい（導体間距離が小さい） |
| フェランチ効果の発生しやすさ | 比較的少ない | 発生しやすい（C が大のため） |
| 熱放散 | 容易（空気冷却） | 困難（土壌依存） |
| 環境影響・景観 | 鉄塔が目立つ・土地が使えない | 地中化で景観保護・土地は使える |

## 5.ケーブルの種類比較（CV と OF）

| 種類 | 絶縁材料 | 誘電正接 tanδ | 最高使用温度 | 特徴 |
| --- | --- | --- | --- | --- |
| OFケーブル（油浸紙絶縁油入） | 浸油紙 | 大きい（目安 0.002〜0.004） | 75〜85℃ | 絶縁油を加圧・給油し、絶縁層内にボイド（空隙）が生じるのを防ぐ方式。給油設備が要り油圧管理が必要・漏油リスク |
| CVケーブル（XLPE絶縁ビニルシース） | XLPE | 小さい（目安 0.0003〜0.001） | 90℃ | 軽量・油不要・現在の主流 |
| CVTケーブル | XLPE（単心3条） | 小さい | 90℃ | 単心ケーブルを3本撚り合わせ |

tanδ と最高使用温度は教材でよく使われる目安で、一次資料では確かめていない。試験センター公表の電力の問題冊子で読んだ地中ケーブルの問題（H29 問10、H30〜R04上 の問11、R04下〜R08上 の問10）には、この数値は出ていない。大小は、誘電体損が R05下 問10（(3)「一般に OF ケーブルの方が小さい」が誤りの肢）、常時導体最高許容温度が H30 問11（(3)「CV の方が高い」が正しい記述）で問われた。H27 以前は公表の冊子が無く、照合していない。CV が OF より誘電損が少ない理由（因果理解）

誘電損  $P_d = \omega C E^2 \tan\delta$ （1相分。 $E$ ＝相電圧）から、絶縁材料の誘電正接  $\tan\delta$  が誘電損を左右する。OFケーブルの絶縁体（浸油紙）は油を含む有機紙で、双極子（分子の正負の電荷の中心がずれた構造）が交番電界で向きを変えるたびにエネルギーを消費する。この分子レベルの摩擦が誘電損の正体。XLPE は分子構造が均一で双極子が少なく  $\tan\delta$  が小さい（上の表の目安で 1/2〜1/13 程度）ため、同じ電圧・静電容量なら誘電損も同じ割合で小さくなる。最高使用温度も CV（90℃）が OF（75〜85℃）より高いので、導体断面・布設条件が同じで、熱抵抗も同程度なら、CV の方が許容電流を大きく取りやすい。📊 このセクションの理解度:◎○△×

## 6.見た目で見分けるケーブル・電線図鑑（全種横断）

電験では名称・用途だけでなく、断面や外観のイメージから種類を問われることがある。低圧・一般用／高圧・特別高圧／その他の線材・導体の3群に分け、外観と見分けポイントを整理する。第5節の CV / OF 比較と合わせ、外観 → 名称 → 用途を一続きで覚えるとよい。この節の使い方（重要）

本節は地中送電に限らず、ケーブル・電線を横断的に集めた資料である。このうち地中送電で主に使うのは CV・CVT・OF の3種（OF は既設中心で、新設は CV 系が主流）。IV・HIV・VVF・VVR は屋内低圧配線、CVV は制御・信号回路用、ACSR・TACSR・硬銅線・耐熱銅合金線・高圧架空配電線は架空線、亜鉛めっき鋼線・鋼より線は支持・保護用であり、地中送電の選択肢ではない。「このページで見た＝地中用」と早合点しないこと。

掲載画像は外観の全体像をつかむためのイメージである。層構成・素線数・寸法などの細部は製品や規格により異なるので、CV ケーブルの正確な断面（導体→内部半導電層→架橋ポリエチレン絶縁→外部半導電層→金属遮へい層→防食層）は第2節の構造図・本文で確認すること。外観識別が有効なのは VVF↔VVR・CV↔CVT・銅系↔アルミ系・単線↔より線 など。ACSR↔TACSR や 硬銅線↔耐熱銅合金線は外観だけでは判別できず、問題文の記述で判断する。

## 8.公式マップ（最重要）01充電電流（ケーブルはコンデンサ・E は相電圧） $I_c = \omega C E = 2\pi f C E\,[\text{A}]$ ω=2πf（角周波数）、C=ケーブルの1線当たりの静電容量[F]（過去問も「心線1線当たりの静電容量」で与える。R06下 問10）、E=相電圧（対地電圧）[V]（三相なら線間電圧÷√3）。ケーブルに交流を印加すると Q=CE が充電され、電流は電荷の時間微分で振幅 ωCE。三相の充電容量を問われたら Q_c=3ωCE²=ωCV²（V=線間）で、下の誘電損と同じ「E か V か」の取り違えが起きる。02誘電損（絶縁体の損失） $P_d = \omega C E^2 \tan\delta\,[\text{W}]$ E は対地電圧（相電圧）で【1相分】。三相合計は 3ωCE²tanδ で、線間電圧 V で書き直すと E=V/√3 より ωCV²tanδ となり字面が1相分の式と同じになる（√3の2乗=3 が相数3と打ち消すため）。E と V のどちらの式かを取り違えて3倍を重ねる／落とすのが最頻出ミス。tanδ=誘電正接（絶縁材料の損失特性）。理想コンデンサは有効電力0だが、実際は損失角δだけ90°からずれ P=EI sinδ。I=ωCE/cosδ を代入すると P=ωCE²tanδ（近似なしに成り立つ）。OFより CVの方が tanδ が小さく誘電損が少ない。03ケーブルの静電容量（同軸構造） $C = \dfrac{2\pi\varepsilon}{\ln(D/d)}\,[\text{F/m}]$ D=外側導体（遮へい）径、d=内側導体径。D/d が小さい（導体と遮へいが近い）ほど C が大きい。地中ケーブルは絶縁層が薄く C が大、架空線は導体間距離が大きく C が小。C が大きいか小さいかは「導体間距離」で決まる

架空送電線は導体間（または導体と大地間）の距離が数m〜数十mと大きいので C は小さい。地中ケーブルは絶縁層が薄く導体と遮へい層の距離が数mm〜数十mmと小さいので C は大きい。この「距離が近い＝C大」が、充電電流大・フェランチ効果が起きやすいことの根本原因。ケーブルの損失は3つ — 抵抗損・誘電体損・シース損

ケーブルで発生する損失は次の3つ。どれか1つを問われることが多いので3点セットで覚える。
- 抵抗損（導体損） — 導体の抵抗に電流が流れて生じる  $I^2 R$ 。負荷電流の2乗で増え、通常の負荷運転時には3損失中で最大。ただし無負荷・軽負荷では負荷電流による抵抗損が小さくなり、電圧で決まる誘電体損の比重が大きくなる（無負荷でどちらが大きいかは、ケーブルの長さと tanδ で決まる。下の「抵抗損と誘電損を棒の長さで比べる」）。
- 誘電体損（誘電損） — 絶縁体の分子摩擦。1相分は  $P_d = \omega C E^2 \tan\delta$ （ $E$ ＝対地電圧）で、三相合計はその3倍（線間電圧  $V$  で書けば  $\omega C V^2 \tan\delta$ ）。電圧が掛かっていれば無負荷でも発生するのが特徴。
- シース損 — 金属シース（遮へい層）に生じる損失。単心ケーブルでは導体電流がつくる磁束でシースに電圧が誘起され、シースの両端を接地すると循環電流が流れて発熱する（シース回路損）。ほかに渦電流損もある（3心ケーブルは3相の磁束がほぼ打ち消し合うため問題になりにくい）。

シース回路損（循環電流）の低減策＝クロスボンド接地。ケーブルの大区間（メジャーセクション）を3等分した小区間ごとに3相のシースを順番に入れ替えて接続すると、大区間トータルでシースの誘起電圧の和がほぼゼロになり、循環電流はほとんど流れなくなる（短距離線路では片端接地も用いられる）。なお渦電流損はクロスボンドでは消えない点に注意R08上 問10 を原理で解く — I²R と V²/R で向きが逆になる

R08上 問10 は、電力ケーブルの損失の正誤を5肢で問うた。誤りは (5) である（試験センター公表の問題冊子と解答で確認）。
- (1) 表皮効果：交流電流は導体の表面側に偏る。断面積が大きいほど偏りが効くので、分割導体・素線絶縁導体で抵抗損を減らす（正しい）。
- (2) 近接効果：隣の相の電流がつくる磁界で電流の分布が偏る。相間距離が短いほど強いので、離すと抵抗損が減る（正しい）。
- (3) 誘電損：式02 の ωCE²tanδ で、C は誘電率に比例する。だから誘電損は誘電率・tanδ・電圧の2乗に比例する（正しい）。
- (4) クロスボンド接地：3相のシースの誘起電圧を打ち消し、シース回路損を減らす（正しい。上の段落）。
- (5) 渦電流損：誤りの核心は導電率の向きである（H29 問10(4)「導電率の高い金属シース材の採用は渦電流損の低減に効果がある」も同じ誤りの肢で、2回出た）。金属シースに誘起される起電力 e は、導体電流の磁界の変化で決まり、金属シースの導電率にはほぼよらない。損失は e²/R なので、導電率が高い（R が小さい）金属シースほど渦電流が大きく、損失は増える。前半の「厚さの薄い金属シースで減らす」は正しい。薄いほど渦電流の通り道の R が大きくなり、e²/R が小さくなるからである。

何が決まっているかで向きが逆になる。導体の抵抗損は、流れる電流 I が負荷で決まるので I²R で、R を下げる（導電率を上げる）と減る。金属シースの渦電流損は、起電力 e が磁界で決まるので e²/R で、R を下げると増える。同じ「抵抗による発熱」でも、電流が決まるのか電圧が決まるのかを先に見る（この見方は導体の抵抗損と金属シースの渦電流損の比較に使う。シース回路損はクロスボンドで循環の経路を断って減らす）。

e が導電率によらないのは、渦電流がつくる磁界の反作用を無視した基本の見方である。3種の正誤判定はこの見方で足りる。

### 抵抗損と誘電損を棒の長さで比べる

抵抗損は電流の2乗で決まるので負荷で大きく変わる。誘電損は電圧の2乗・静電容量・tanδで決まり（R08上 問10 の(3)「印加電圧の 2 乗に比例」は正しい記述）、負荷によらない。負荷電流による抵抗損と誘電損の比は、抵抗も静電容量も長さに比例するので、長さではほとんど変わらない（充電電流による抵抗損は別。下の無負荷の段落）。

例: 線間電圧 66 kV・50 Hz の 3心 CV ケーブル、長さ 10 km、1線の静電容量 2 μF（0.2 μF/km、9節の例題と同じ）、tanδ 0.0005（上の表の目安の範囲）、1線の交流導体抵抗 0.8 Ω（0.08 Ω/km。表皮効果・近接効果を含めた値として仮定）、負荷 50 MW・力率 1。計算の流れを見るための例示値で、過去問の数値でも代表値でもない。負荷時の充電電流とシース損は省いた。
- 定格負荷の抵抗損 3I²RI = 50 MW ÷ (√3 × 66 kV) = 437.39 A。3 × 437.39² × 0.8459.14 kW
- 定格負荷の誘電損 ωCV²tanδ2π × 50 × 2 μF × (66 kV)² × 0.0005（三相合計。相電圧 E なら 3ωCE²tanδ、式02）1.37 kW
- 負荷 1/2 の抵抗損電流が 1/2 なので 1/4114.78 kW
- 負荷 1/2 の誘電損電圧が同じなので変わらない1.37 kW

この例では、定格負荷の抵抗損は誘電損の約 340 倍、負荷 1/2 でも約 84 倍で、損失はほぼ抵抗損だけになる。充電電流を省いたこの計算では、誘電損が抵抗損を上回るのは、負荷電流が約 24 A（定格の約 5.5%）以下のときだけである（充電電流による抵抗損を足すと、力率1・電圧一定の近似で境目は約 19.5 A に下がる。遅れ力率の負荷では、充電電流が負荷電流の無効分を打ち消すので、境目は逆に上がることもある）。上の Box の「軽負荷」で誘電体損が抵抗損を実際に上回るのは、この程度のごく軽い負荷のときである。

比は電圧・負荷・ケーブル定数で変わる。C・tanδ・R を同じと仮定して同じ電力を2倍の電圧で送ると、電流が 1/2 なので抵抗損は 1/4 に減り、誘電損は4倍に増える（この例なら比は約 340 倍から約 21 倍へ）。ただしこれは同じケーブルで電圧だけを変えた仮定の比較である。実際には電圧の階級ごとに絶縁の厚さや導体の太さが違い、C や tanδ も変わるので、誘電損が4倍になるとは限らない。

無負荷でも誘電損は残る。ただし無負荷のケーブルにも充電電流（式01）が流れるので、導体の抵抗損もゼロにはならない。この例の充電電流は送電端で約 24 A で（上の境目の約 24 A と近いのは、この例の数値による偶然）、受電端（開放端）へ向かって 0 A まで直線的に減る。そのため抵抗損は約 0.46 kW で、誘電損 1.37 kW より小さい。「無負荷なら損失は誘電損だけ」とは言えない。この例では誘電損の方が大きいが、いつもそうとは限らない。短い線路で電圧の分布の変化を無視できる近似では、無負荷の抵抗損は充電電流の2乗と抵抗の積なので長さの3乗で増え、誘電損は長さに比例するだけである（長い線路は分布定数回路として扱う必要がある）。長いケーブルや tanδ の小さいケーブルでは、抵抗損の方が大きくなりうる。📊 このセクションの理解度:◎○△×

## 9.解法パターン（充電電流の計算）充電電流 Ic=ωCE（E は相電圧）の見分け方と手順

見分け方：「地中ケーブル」「静電容量 ○ μF/km」「充電電流」のキーワードが揃っている。
-  $\omega = 2\pi f$  を計算（f=50Hz なら ω=2π×50≈314 rad/s）
- 静電容量を F に換算（1線当たりの μF/km なら線路長[km]を掛けて全体の C[F] に）
- 三相なら相電圧  $E = V/\sqrt{3}$  を使って  $I_c = \omega C E$  に代入（線間電圧  $V$  をそのまま入れない——√3 倍に誤る）例題: 線路長10km・静電容量0.2μF/km・66kV系統・f=50Hz の充電電流は？自分で解いてから、解き方と答えを開く

① 全体の静電容量：

 $C = 0.2\times10^{-6}\times 10 = 2\times10^{-6}\,\text{F}$

② 角周波数： $\omega = 2\pi\times50 \approx 314\,\text{rad/s}$

③ 三相なので相電圧を使う： $E = \dfrac{66{,}000}{\sqrt{3}} \approx 38{,}105\,\text{V}$

④ 充電電流：

 $I_c = 314 \times 2\times10^{-6} \times 38{,}105 \approx 23.9\,\text{A}$

### 故障点の位置標定 — 3つの方法と、地絡・断線への使い分けR04上 問11・R06上 問10

地中ケーブルは目で故障点を探せないので、端から電気的に測って位置を出す。どの方法がどの事故に使えるかは、測定原理から決まる。

| 方法 | 測り方 | 地絡 | 断線 |
| --- | --- | --- | --- |
| パルスレーダ法 | 故障相の一端からパルス電圧を入れる。故障点ではサージインピーダンスが変わるので、パルスが反射して戻る。往復の時間と伝搬速度から距離を出す | ○ | ○ |
| 静電容量測定法 | ケーブルの静電容量は長さに比例する。健全相と故障相の静電容量を測り、その比とこう長から距離を出す | × | ○ |
| マーレーループ法 | 健全相と故障相の導体どうしを遠端で接続してループをつくり、ホイートストンブリッジの平衡条件から距離を出す | ○ | ×（断線するとループができない） |
マーレーループ法の式 — ブリッジの平衡から x を出す（R06上 問10）

ケーブル線路長  $L$ 、装置側の端から故障点までを  $x$ 、ブリッジの全目盛を 1000、平衡したときにケーブル A（故障相）側の端子までの目盛を  $a$  とする。ブリッジの4辺は、目盛  $a$  と  $1000-a$ 、ケーブル A の故障点まで（長さ  $x$ ）、ケーブル B を回って故障点まで（長さ  $L + (L - x) = 2L - x$ ）である。抵抗は長さに比例するので、平衡条件は

 $\dfrac{a}{x} = \dfrac{1000-a}{2L-x} \quad\Rightarrow\quad x = \dfrac{2aL}{1000} = \dfrac{aL}{500}$

この式は、健全相（ケーブル B）が切れておらず遠端でループをつくれること、ケーブル A・B が同一仕様・同一長で単位長さ当たりの導体抵抗が等しいこと、遠端の接続線と装置の接続線の抵抗を無視できることを前提に成り立つ（後の2つは R06上 問10 の問題文の前提）。

電源の電流は、故障点の地絡抵抗を通って流れる。地絡抵抗が高いと電流が小さくなり、平衡点を見分けにくい。だから地絡抵抗が十分低いことが、精度よく標定する条件になる。

R04上 問11 は (5)「断線事故には静電容量測定法とマーレーループ法が適用できる」が誤り。R06上 問10 の正答は (4)（ホイートストン・導体・ $aL/500$ ・十分低い）。式の形は、問題の図の目盛の向き（ケーブル A 側の目盛が  $a$ ）による。問題文と正答は、試験センターの問題 PDF と解答 PDF で確認した。📊 このセクションの理解度:◎○△×

## 10.引っかけ・誤答ポイント【引っかけ1】L と C の大小が架空と逆

「地中ケーブルは架空送電線よりインダクタンス L が大きく、静電容量 C が小さい」→ 誤り。導体間距離が小さいため L は小さく・C は大きい。架空線とまったく逆になる点が狙われる。【引っかけ2】フェランチ効果は地中ケーブルで起きやすい

「フェランチ効果は架空送電線の方が起きやすい」→ 誤り。フェランチ効果（受電端電圧が送電端電圧より高くなる現象）は静電容量 C が大きいほど発生しやすい。地中ケーブルは C が桁違いに大きく、軽負荷・無負荷時に充電電流による進み無効電力が大きくなるため、フェランチ効果が顕著になる。【引っかけ3】CV と OF の最高使用温度

「CVケーブルの最高使用温度は OF ケーブルより低い」→ 誤り。CV（XLPE絶縁）は 90℃、OF（浸油紙絶縁）は75〜85℃。CV の方が高く、導体断面・布設条件が同じで熱抵抗も同程度なら、許容電流を大きく取りやすい。H30 問11(3) では「CV ケーブルは…OF ケーブルと比較して…常時導体最高許容温度が高いため、送電容量の面で有利」が正しい記述として出た（数値は問われていない）。【引っかけ4】事故復旧時間は信頼性とは別の指標

「地中ケーブルの事故復旧は架空送電線より短時間で済む」→ 誤り。事故頻度（信頼性）は地中の方が低い（高信頼）が、一度事故が起きると掘削が必要なため復旧時間は長い。信頼性と復旧時間を混同させる引っかけ。📊 このセクションの理解度:◎○△×
