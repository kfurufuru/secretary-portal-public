# 開閉装置・保護継電器（hub）

電力系統の「センサー → 判断 → 切る」3段を俯瞰するハブ。計器用変成器（VT・CT）・保護継電器・遮断器/断路器の繋がりを掴む。問8枠＋問7枠はほぼ毎回計2問出題される固定枠で、変電分野の得点の柱になる最重要領域。
**出題頻度:** 最頻出（5年で14問・問8/問7枠）
**難易度:** ★★☆
**出題形式:** 論説・穴埋め中心

## 1.直感的理解 — センサー → 判断 → 切る

変電所の保護は **「異常を測る → 異常か判断する → 実際に切る」** の3段で動く。各段を別々の機器が担い、本ハブはその3者の役割分担と繋がりを俯瞰する。各機器の詳細は機能別の3ページに分離してある。
この3役割で全体を整理する
- **センサー（計器用変成器）** — VT・CT が系統の高電圧・大電流を 110 V・5 A に縮小して取り出す
- **判断装置（保護継電器）** — OCR・DGR・差動(87)・距離(21) 等が異常を検出してトリップ指令を出す
- **実行装置（遮断器・断路器）** — CB が指令を受けて負荷電流・事故電流を実際に切る

検出から遮断までは数十〜数百ミリ秒。継電器自身は電流を切らず、CB に「切れ」を指令するだけである点に注意。

「継電器が電流を切る」と書いたら誤り
切るのは **遮断器（CB）**。継電器は CT・VT の二次信号を見て整定値と比較し、トリップ指令を出すだけ。「判断」と「実行」を必ず分けて読むこと。逆に断路器（DS）は判断も電流遮断もできず、無電流時の電路分離専用である。

遮断器の消弧媒体（種類比較・論説頻出）
- **OCB（油遮断器）** — 絶縁油・旧式
- **ABB（空気遮断器）** — 圧縮空気・旧式
- **GCB（ガス遮断器）** — **SF6 ガス**・絶縁性能が高く小型化可能・都市型変電所の主流。**GIS は遮断器ではない**——GCB・DS・LA 等をまとめて SF6 容器に収めた**ガス絶縁開閉装置**（設備一式）で、「GIS は遮断器の一種である」は誤。
- **VCB（真空遮断器）** — 真空・保守容易・環境負荷小・変電所/工場の主流

GIS の絶縁・消弧媒体は **SF6（六フッ化硫黄）ガス**で、圧縮空気を使う ABB との取り違えが最多。VCB は真空中で気体分子がなくアークを維持できず、電流ゼロ点で消弧する。

## 4.公式マップ（センサーの換算）

本ハブの計算はセンサー（計器用変成器）の換算が中心。「比は一次/二次」を必ず確認すること。
01
**変流比・変圧比（一次値の換算）**
$I_1 = I_2 \times K_n,\quad V_1 = V_2 \times K_v$
Kn=変流比（例 200/5=40）、Kv=変圧比（例 6600/110=60）。二次計器値に比を掛けて一次値を得る。CTは電流を巻数に反比例、VTは電圧を巻数に比例で縮小する。
02
**残留回路（零相電流の取り出し）**
$I_{res} = 3 I_0\ (\text{2nd}),\quad I_g = 3 I_0\ (\text{1st})$
3つの相CT二次をY結線した残留回路には和電流=3I0が流れる。平衡時は0、地絡時のみ非0。二次の3I0を3で割り、変流比を掛けて一次零相電流に写し取る。
例題: 残留回路 0.6 A・変流比 200/5 → 一線地絡電流は？
① 残留回路電流 $= 3 I_0\,(\text{2nd}) = 0.6\,\text{A}$ なので二次零相電流 $I_0(\text{2nd}) = 0.6 / 3 = 0.2\,\text{A}$
② 変流比 $K_n = 200 / 5 = 40$
③ 一次零相電流 $I_0 = 0.2 \times 40 = 8\,\text{A}$
④ 一線地絡電流 $I_g = 3 I_0 = 3 \times 8 = 24\,\text{A}$
「3で割って 40倍して 3倍する」と覚える（数学的には二次の $3I_0$ に変流比を掛けて一次へ写すのと同じ）。

## 6.引っかけ・誤答ポイント

3役割を横断する頻出トラップ
- **CT 二次開放を「過大電流で焼損」と誤認** — 正しくは過大「電圧」。一次電流が全量励磁電流化し鉄心が磁気飽和して二次に異常高電圧が発生する。CT の禁則は開放 NG、VT は短絡 NG（左右対称で混同最多）。
- **断路器(DS)で事故電流を切れると誤認** — DS はアーク消弧能力がなく、無電流時の電路分離専用。投入は DS→CB、開放は CB→DS の順を逆にすると DS が焼損する。
- **GIS は圧縮空気で絶縁と誤認** — GIS は SF6 ガス。圧縮空気を使うのは空気遮断器(ABB)。VCB は真空で消弧（SF6 ではない）。
- **DGR を「大きさだけで判定」と誤認** — DGR は大きさに加え方向（位相）も判定し、自構内向きのみ動作して波及事故を防ぐ。入力は ZCT（零相電流）＋EVT（零相電圧）のセット。
- **差動継電器(87)が外部短絡でも動作と誤認** — 87 は内部故障のみ動作。外部短絡では一次・二次の差が出ず誤動作しない（保護範囲が内部に限定）。

## 7.正誤判定の急所

| 命題 | 判定 | 理由 |
| --- | --- | --- |
| 計器用変成器は VT と CT の総称である | **正** | JIS 用語。VT・CT 両方を含む上位概念 |
| CT の二次側を開放しても問題ない | **誤** | 鉄心磁気飽和で異常高電圧が発生し焼損・感電 |
| VT の二次側を短絡しても問題ない | **誤** | 過大短絡電流で巻線焼損。CT と左右対称の禁則 |
| 断路器は事故電流を遮断できる | **誤** | DS は電流遮断能力なし。遮断は CB の役割 |
| 遮断器投入時は CB→DS の順で操作する | **誤** | 投入は DS→CB。開放が CB→DS |
| GIS は圧縮空気を絶縁媒体に使用する | **誤** | SF6（六フッ化硫黄）ガス。圧縮空気は ABB |
| 真空遮断器の消弧媒体は真空である | **正** | 真空中はアークを維持できず電流ゼロ点で消弧 |
| 地絡方向継電器(DGR)は電流の大きさだけで判定する | **誤** | 大きさに加え方向（位相）も判定 |
| 差動継電器(87)は変圧器の外部短絡でも動作する | **誤** | 内部故障のみ動作。外部短絡では差が出ない |
| OCR の反限時特性は電流が大きいほど短時間で動作する | **正** | 重大事故ほど早期遮断の論理 |
