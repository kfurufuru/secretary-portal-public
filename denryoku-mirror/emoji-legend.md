# 絵文字マーカー凡例

各ページの本文で使われる絵文字マーカーと、その意味・使用場面の一覧。マーカーを見ればそのブロックが「直感的理解」「解法パターン」「落とし穴」などのどれに当たるかを一目で判別できる。
**種別:** リファレンス
**使い方:** マーカーで本文ブロックの種類を判別

## 1.マーカー一覧

本文中の見出しや囲み枠に付く絵文字は、そのブロックの役割を表す。意味と使用場面を以下にまとめる。

| マーカー | 意味 | 使用場面 |
| --- | --- | --- |
| 🧠 | 直感的理解・アナロジー | 「水流＝電流」のような比喩で掴む |
| 🏭 | 設備を歩く（設備構成） | 設備フロー図・主要機器の役割 |
| ⚖️ | 比較表 | 水車の種類比較、熱サイクル比較 |
| 🔍 | 公式の意味マップ | 公式の意味・使える条件 |
| 🛤️ | 解法パターン | 計算問題の「型」 |
| 🕳️ | 落とし穴・頻出ミス | 間違えやすいポイント |
| 📝 | 正誤判定の急所 | 正誤問題でよくある誤文パターン |
| 🎯 | 重要ポイント | 特に押さえるべき事項 |
| ⚡ | 5秒で思い出す | 速攻暗記フレーズ |
| 📊 | 出題実績 | 年度別の出題記録 |
| 😱💀🔥💥 | 事故・危険 | 安全に関わる重大事項 |
| ✅ | 確認済み | 教科書と照合済み |
| ⚠️ | 未確認 | 要検証 |

マーカーの読み方
マーカーは本文の内容そのものではなく「読み方の指示」。**🛤️ なら解法の型として手を動かす、🕳️ なら自分の誤答パターンと照合する**、というように学習の構えを切り替える目印として使う。
