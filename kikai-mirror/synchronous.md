# 同期機

同期速度で回転する交流機。発電所の主機として用いられる同期発電機と、力率改善に使われる同期調相機・同期電動機を扱う。

ミクロ（なぜ）：同期電動機として見ると、固定子の三相交流が作る回転磁界の磁極と回転子の直流界磁の磁極が異極どうしで吸引し合い、磁気的に結合する。負荷が増えると回転子は負荷角 δ だけ遅れて引っ張られるが、回る速さ自体は落ちない＝滑りゼロで常に同期速度。δ が π/2 を超えると結合が保てず脱調する（発電機では逆に回転子側が δ だけ先行して引っ張る）。
🔬 ミクロの因果（なぜ滑りゼロで同期速度のまま回るか）
1. **固定子の三相交流が回転磁界**を作る（回転の速さは $N_s = 120f/p$ に固定）
2. **回転子の直流界磁の磁極**が回転磁界の異極と吸引し合い、磁気的に結合する
3. **負荷が増えると負荷角 δ が開き**、遅れたまま引っ張られてトルクが増す（$P = \frac{EV}{x_s}\sin\delta$ は δ = π/2 で最大）
4. 結果、**滑りゼロで常に同期速度**で回る。ただし δ が π/2 を超えると結合が外れて**脱調**

## 1.構造と動作

固定子（電機子）に三相巻線、回転子に界磁を持つ。回転子は 常に同期速度 $N_s = 120f/p$ で回る。誘導機と異なり滑りはゼロ。
理解を深める — 起電力の正体は理論「電磁誘導」
同期発電機が電圧を生むのは、回転する **界磁の磁束** が固定子（電機子）巻線を周期的に切るから。これは理論で学ぶ **電磁誘導（ファラデーの法則）** $e=-N\dfrac{d\Phi}{dt}$ そのもの。磁束が $\Phi=\Phi_m\cos\omega t$ と正弦波状に変化するので、起電力も正弦波になり、1相分の実効値は $E=4.44\,k_w fN\Phi_m$。ここで $k_w$ は **巻線係数**（1以下・実機で 0.9〜0.96 程度）で、変圧器と違い同期機の電機子巻線は**複数スロットに分布して巻かれ（分布巻）、コイル辺の間隔が極ピッチより短い（短節巻）**ため、各コイルの起電力が少しずつ位相差を持ち、単純な和より小さくなることを表す。変圧器は集中巻なので $k_w \approx 1$ となり $E=4.44fN\Phi_m$ だが、同期機では $k_w$ が与件として問題文に示される。
周波数は回転速度と極数で決まる：$f=\dfrac{p N_s}{120}$（同期速度 $N_s=120f/p$ の裏返し）。「同期速度で回す → 決まった周波数の正弦波起電力」という機械の動作は、理論の **電磁誘導＋磁束鎖交** を回転体に適用しただけ、と捉えると腑に落ちる。
→ 理論Wiki「3.1 インダクタンス・電磁誘導」でファラデー則・磁束鎖交を深掘り
4.44 はどこから来るか — e = Blv から基本式を導く導出6段。数値を覚えるのではなく作れるようにする
公式 $E=4.44\,k_w fN\Phi_m$ の **4.44** は天下りの定数ではなく、導体1本の $e=Blv$ から6段で作れる。正体は $\sqrt{2}\,\pi$（$\sqrt{2}$ が実効値変換、$\pi$ が正弦波の平均値 $2/\pi$ の逆数）。
— 図1.3.1 極ピッチと磁束密度分布（円周方向に展開した図） —

| 段 | 式 | 意味 |
| --- | --- | --- |
| 1 | $\tau=\dfrac{\pi D}{p}$ | 極ピッチ。固定子内径 D の円周を極数 p で割る |
| 2 | $v=2\tau f$ | 界磁の周速。**1周期で 2 極ピッチ**（N極＋S極）進む |
| 3 | $e=Blv$ | 導体1本の瞬時起電力（$B=B_m\sin\omega t$） |
| — | $\dfrac{\pi x}{\tau}=\dfrac{\pi vt}{\tau}=2\pi ft=\omega t$ | **図の空間の正弦と、段3の時間の正弦は同じもの**。固定された導体の上を界磁が $x=vt$ で通り過ぎるため |
| 4 | $\Phi=\dfrac{2}{\pi}B_m\,\tau\,l$ | 1極の磁束。正弦波分布の**平均値**×極の面積 |
| 5 | $e_{rms}=\dfrac{\pi}{\sqrt{2}}f\Phi=2.22f\Phi$ | 導体1本の実効値 |
| 6 | $E=4.44fN\Phi$ | 1相の**直列**巻数 N ＝ 導体 **2N 本**（1巻きにつき2辺） |

段4を段3に代入すると $B_m=\dfrac{\pi\Phi}{2\tau l}$ なので
$e_{rms}=\dfrac{B_m l v}{\sqrt{2}}=\dfrac{1}{\sqrt{2}}\cdot\dfrac{\pi\Phi}{2\tau l}\cdot l\cdot 2\tau f=\dfrac{\pi}{\sqrt{2}}f\Phi\;\;(=2.2214f\Phi)$
これを2倍して $\sqrt{2}\,\pi=4.4429\approx 4.44$。実機ではさらに巻線係数 $k_w$ を掛けて $E=4.44k_w fN\Phi_m$（分布巻・短節巻で各コイルの起電力に位相差が出る分の目減り）。上の導出は $k_w=1$（集中巻・全節巻）の理想形にあたり、**変圧器の $E=4.44fN\Phi_m$ と同じ形になる**のはこのため。
この導出で落とすところ（3点）
- $\dfrac{2}{\pi}B_m$ は**平均値**。実効値 $B_m/\sqrt{2}$ と取り違えると $\Phi$ が狂う（理論から持ち越す定番の混同）
- $v=2\tau f$ の **2** — 1周期で進むのは1極ピッチではなく**2**極ピッチ。極数によらず成立する（$v=\pi D n=\pi D\dfrac{N_s}{60}=\pi D\dfrac{2f}{p}=2\tau f$）
- **N 巻 ＝ 導体 2N 本** — 1本と数えると答えが半分（2.22 と 4.44 を分ける段）

同じ係数 4.44 は静止器にも出る → 2.1 変圧器 セクション3「誘導起電力と磁束」（そちらでは $2\pi/\sqrt2$ と書いているが $\sqrt2\,\pi$ と同じ値）。

## 2.電機子反作用

**同期発電機では**、負荷力率により電機子起磁力の作用が変わる:
- **遅れ力率**（誘導性） — 減磁作用、電圧低下
- **進み力率**（容量性） — 増磁作用、電圧上昇
- **力率1** — 交差磁化作用（電機子起磁力が界磁に直交）

図1.3.1 同期発電機の電機子反作用。電機子起磁力が界磁起磁力に対してどの向きに立つかで作用が決まる。直交なら交差磁化、逆向きなら減磁（遅れ力率）、同じ向きなら増磁（進み力率）。同期電動機では遅れと進みの対応が入れ替わる。
発電機と電動機で逆になる（定番ひっかけ）
同期電動機では対応が逆：遅れ力率=増磁・進み力率=減磁。「遅れ=減磁」は**発電機の場合**と、必ず主語を付けて覚える。

## 3.V カーブと位相特性

同期電動機の **V カーブ** は界磁電流 If を横軸、電機子電流 Ia を縦軸にとった V 字曲線。底点で電機子電流が最小となり力率1、左側（不足励磁）で遅れ・右側（過励磁）で進み力率となる。
— 図1.3.2 同期電動機の V カーブ（界磁電流 If と電機子電流 Ia の関係） —
主要公式
01
**同期発電機の起電力**
$E = V + I(r_a + jx_s)$
x_s: 同期リアクタンス
02
**短絡比**
$K_s = \dfrac{I_{f0}}{I_{fs}} \approx \dfrac{1}{x_s\,[\mathrm{p.u.}]}$
短絡比大 ⇒ 安定度高・電圧変動小（1/xs は電機子抵抗無視の近似）
03
**出力（円筒形・1相分）**
$P = \dfrac{E V}{x_s}\sin\delta$
δ: 内部相差角。π/2 で最大出力。**E・V は相電圧で、この式は1相分**。三相合計は $P_{3\phi}=3\dfrac{EV}{x_s}\sin\delta$ で、線間値を使うなら $P_{3\phi}=\dfrac{E_L V_L}{x_s}\sin\delta$ と同じ値になる。
混同に注意
同期機の **同期速度** は誘導機と同じ $N_s = 120f/p$。しかし 滑りは存在しない。誘導機の式を流用してはならない。

## 5.始動法・乱調・自己励磁（頻出理論論点）

- **始動法** — 同期電動機は始動トルクがない（回転磁界に静止した回転子が追従できない）。**自己始動法**（制動巻線をかご形導体として利用。始動中は界磁巻線を抵抗経由で短絡し高電圧誘起を防ぐ）／始動電動機法／低周波（インバータ）始動。
- **乱調** — 負荷急変で内部相差角 δ が振動する現象。**制動巻線**が滑りに応じた誘導トルクで振動を**減衰**させる。はずみ車は慣性を増して急変を緩やかにする補助で、それ自体は減衰要素ではない。
- **自己励磁現象** — 無負荷の長距離送電線など**容量性負荷**を接続すると、残留磁気と進み電流の増磁作用で電圧が異常上昇する現象。同じ線路条件で比較すれば、**短絡比が大きい**（同期リアクタンスが小さい）発電機ほど起こりにくい。

## 6.例題

例題 1.3.1（短絡比と短絡電流）
**問:** 定格容量 5000 kVA、定格電圧 6.6 kV の三相同期発電機の短絡比が 1.25 のとき、同期リアクタンス $x_s$［p.u.］と三相短絡時の持続短絡電流を求めよ。
$x_s = \dfrac{1}{K_s} = \dfrac{1}{1.25} = 0.8\;[\mathrm{p.u.}]$
$I_n = \dfrac{5000{\times}10^3}{\sqrt{3}\times 6600} \approx 437\;[\mathrm{A}] \quad\Rightarrow\quad I_s = K_s \times I_n = 1.25 \times 437 \approx 547\;[\mathrm{A}]$
💡 短絡比は「短絡電流が定格電流の何倍か」そのもの（$I_s = K_s I_n$）。$x_s = 1/K_s$ の逆数関係とセットで覚える。この値は界磁電流を無負荷定格電圧相当に保ったときの**定常（持続）短絡電流**で、突発短絡直後の電流はこれより大きい。
