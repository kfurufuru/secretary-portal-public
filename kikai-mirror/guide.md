## 2.学習中に意識すること

公式を覚えたかどうかではなく、その式について何を言えるかで理解度を測る。 ホーム1節の5層に対応する、解く前・解きながら・解いたあとの問いを並べる。1問解くたびに全部やる必要はないが、△× を付けた問題は必ず7つとも通す。

|  | 口に出す問い | 通らなかったときにやること |
| --- | --- | --- |
| 1 | これは何の言い換えか（本質） | その単元の「理解を深める」を読む。理論科目のどの原理に戻るかを確かめる |
| 2 | なぜその形になるのか（導出） | 「なぜ〜」の節か折りたたみの導出を1度だけ手で追う。2度目からは思い出すだけでよい |
| 3 | 問題文のどの語がこの式を呼んだのか（適用） | 下の3節の表で、その式を呼ぶ合図を確認する |
| 4 | この式を使ってはいけない場面を1つ言えるか（適用の裏） | 同じく3節の表。ここが言えない式は、条件を変えられると必ず落とす |
| 5 | 何が固定で何が動くか | 「電圧一定か、電流一定か、磁束一定か」を先に決める。ここが曖昧なまま式に入れない |
| 6 | 増減の向きで検算できるか | 効率が悪いほど時間は延びる／%Z が小さいほど短絡電流は大きい、のように向きで確かめる |
| 7 | 誤答の選択肢はどんな考え違いで出た値か | 選択肢は無作為ではない。1つずつ「これは何を取り違えた人の値か」を言う |
正解しても、2 が言えなければ △ に落とす

過去問トラッカーは正解／不正解ではなく「言えるか」で判定する運用にしてある。 答えが合っていても「なぜその式か」を1行で言えなければ「言えない → △」で △ に落とす。 覚えていただけの正解を ◎ にすると、忘却曲線がその問題を長く寝かせてしまい、 試験前に戻ってこない。◎ は「見ずに正解し、迷いがなく、理由を1行で言えて、（時間を測る過去問では）目安時間内」のときだけ付ける（学習記録ページの ◎○△× の定義と同じ。導出まで戻れることは「理由を1行で言える」の中身）。

## 3.なぜこの式を使うのか／使ってはいけないのか

同じ量を求めるように見えて、前提が違えば別の式になる。 機械科目の失点はここに集中する。式とセットで「呼ぶ合図」と「使ってはいけない場面」を持つ。

| 式 | この式を呼ぶ合図 | 使ってはいけない場面（使うと必ず外す） |
| --- | --- | --- |
| $e = B\ell v$ 導体1本の起電力 | $B,\ \ell,\ D,\ n$ が与えられ、 $K$ も $\phi$ も無い | 極数・全導体数・並列回路数が与えられて機械全体の $E$ を問われているとき（ $E=\frac{pZ}{60a}\phi n$ を使う）。 逆に「1巻き」と書かれていたら $2B\ell v$ （有効導体2本） |
| $V_d = 1.35\,V_L$ 三相全波の平均 | 三相ブリッジ整流 | 単相（全波は $0.90V$ ・半波は $0.45V$ ）。 また $1.35$ の相手は線間電圧。相電圧に掛けない（相なら $2.34$ 倍） |
| $I_s = \frac{100}{\%Z}I_n$ 短絡電流 | 変圧器の端子直近で短絡 | 上位系統・線路・発電機のインピーダンスが与えられているとき。 合成してから計算する（この式は安全側に大きく出る概算） |
| $\varepsilon \approx p\cos\theta \pm q\sin\theta$ 電圧変動率 | 降下が定格に比べ十分小さい通常の変圧器 | $p,\ q$ が数十%に達する機器（捨てた第2項 $b^2/200$ が効く）。 符号は遅れが ＋・進みが −で、進みでは負にもなる |
| 比例推移二次抵抗と滑りの比 | 巻線形（二次抵抗を外から加減できる） | かご形。二次抵抗を変えられないので比例推移で始動を改善できない |
| Y-Δ 始動の $1/3$ | かご形の全電圧始動との比較 | 電流だけ $1/\sqrt3$ と考えるのは誤り。始動電流（電源側の線電流）も始動トルクもどちらも $1/3$ |
| 全日効率の負荷率 | 日負荷曲線から $\mathrm{kVA}\div$ 定格容量 | 力率を掛けない。銅損は巻線電流＝kV·A で決まるため。 また鉄損は電源に繋がっている間ずっと出る（無負荷でも消えない） |
| V結線 $86.6\,\%$ と $57.7\,\%$ | 利用率は分母が残り2台、出力比は分母がΔ3台 | 分子はどちらも $\sqrt3 V I$ なので、分母を取り違えると必ず外す。 異容量V結線や灯動共用では各器を個別計算する |
| 加熱COP $=$ 冷却COP $+\,1$ | 同一サイクル・同一運転状態 | 別条件で測った市販機の定格暖房COPと定格冷房COPを直接結ぶのは誤り |
| 顕熱 $Q=cm\Delta T$ と潜熱 $Q=mL$ | 温度が変わるなら顕熱、状態が変わるなら潜熱 | 潜熱に $\Delta T$ を掛けない。乾燥では水の顕熱は最初の全量・潜熱は減った分だけと、掛ける質量が違う |
この表は「網羅」ではない

ここに載せたのは、取り違えやすい式の代表である（全日効率は H21〜R8上 の本試験に出ていない。加熱COP＝冷却COP＋1 は、H23 問12 の問題文の地の文に「暖房時は 1＋Q/W」と書かれただけで、空欄にも計算にも出ていない。%Z の短絡電流は、変圧器では出ていない（H23 問15(a) は %Z そのものを求める）が、同期機の H29 問5 が百分率同期インピーダンスから三相短絡電流を出させた）。載っていない式なら安全、という意味ではない。 新しい式を覚えるときは、その場で「呼ぶ合図」と「使ってはいけない場面」を自分で1つずつ書き足すこと。使ってはいけない場面を言えない式は、まだ覚えたことになっていない。

## 4.学習の回し方（1単元 = 1サイクル）

単元を全部読んでから最後に過去問をまとめて解く、という進め方はしない。1単元ごとに「学習 → その単元の過去問 → △× の復習 → 次の単元」を1サイクルとして回す。 読んだ直後に解かないと、どこが分かっていないかが分からないまま次へ進むことになる。1サイクルの中身
- 学習 — 単元ページを読む。冒頭の確認問題で現在地を測り、各節の末尾で「結論を隠して1行で言えるか」を ◎△× で付ける
- 過去問 — その単元の過去問を 5〜10 問。過去問の進捗 に ◎○△× を残す
- 復習 — 間違えた問は正答とその理由を確かめ、その日のうちに一度、何も見ずに解き直せるところまで戻す。ただし当日の再正解は克服に数えず、記録は △（同じ日の解き直し）にとどめて、日を空けて解き直す。△× はチャットに貼って学習ログに残す
- 次の単元へ — 前の単元の △× は、日を空けてから戻る

- 問15 は機器か制御 — 分野が散るので、A問題の勉強がそのまま効く範囲を厚くしておくこの規則性に賭けすぎない

主要4単元（同期機・三相誘導電動機・直流機・変圧器）で 1回あたり 8.0問。ここが崩れると A問題だけで合格ラインに届かなくなる。

### 60点モデルと安全圏モデル

配点は A問題 5点・B問題 10点（小問 5点×2）。端数の出ない数字で積む——1問あたりを一律「約6点」などと按分すると、 A問題と B問題の差が消えて計画が答案と合わなくなる。

|  | 最低合格モデル（60点） | 安全圏モデル（70点） |
| --- | --- | --- |
| A問題 | 主要4単元から 6問＋その他から 2問＝ 8問 / 40点 | 主要4単元から 7問＋その他から 3問＝ 10問 / 50点 |
| B問題 | 問16 完答＋選択問題 1問完答＝ 2問 / 20点 | 同じく 2問 / 20点 |
| 合計 | 60点 | 70点 |
| 取りこぼしの余地 | A問題を6問落として到達。B問題2問が前提 | A問題を4問落としても到達。B問題が1問崩れても 60点で残る |
B問題は完答できなくても (a) を取る

B問題は (a) と (b) がそれぞれ 5 点で、(a) だけ正解でも 5 点入る。 本Wikiの台帳の体感難易度（H21〜R8上 の88組）では、(a) が (b) より易しいのが29組、同じが48組で、(a) のほうが難しいのは11組である。完答できそうにないからと白紙にするのがいちばん損。 上のモデルはB問題2問完答で組んでいるが、実際には「完答1問＋(a)2つ」でも同じ 20 点になる。

### 後回しにする候補と、その判断の限界

直近22回のA問題での出題が少ない単元は、着手を後ろに回す候補になる。 ただし「出ない」と「捨てる」は違う。A問題に出ないからといって捨てられない単元がある

照明はA問題では22回で6問しか出ていないが、選択問題の枠（問17）には10回出ている。 A問題の件数だけを見て捨てると、選択問題で選べる分野が片方だけになり、難しい側を強いられる。「A問題での頻度」と「B問題の枠での頻度」は別々に見ること。

本当に後回しにできるのは、A問題にもB問題の枠にも現れていない単元である。 直近22回で出題が1件も無い単元は付録A「出題傾向データ」4節に一覧がある。 それらも試験範囲には入っているので、選択肢を切れる程度までは目を通しておく。

## 7.本番の解き方と検算

ここまでは「何を分かっておくか」の話である。ここからは試験当日に手をどう動かすか。 持ち物・時間配分・解く順番・捨て問の決め方・検算の手順・撤退の線を、あらかじめ決めておく。当日に考えることを減らすほど、考える力を問題に回せる。

### 持ち物と、使えるもの

|  | 決まっていること | 当日ここで事故る |
| --- | --- | --- |
| 電卓 | 四則演算と開平（ $\sqrt{\phantom{x}}$ ）ができるものだけ。 数式が記憶できる電卓・関数電卓・印字機能付きは使用すると不正行為。音を出すのも不可。貸与は無い | 開平の無い電卓を持って行くと詰む。 $\%Z=\sqrt{p^2+q^2}$ ・ 横流・脈動率・ $\sqrt3$ がらみは機械科目で常に出る。事前に $\sqrt{\phantom{x}}$ キーの押し方を確認しておく |
| CBT方式 | 持ち込めるのは電卓1台のみ。筆記用具とメモ用紙は会場が貸す （ボールペン・黒）。持参の筆記用具や時計は使えない | 腕時計が使えないので、残り時間は画面のタイマーで見る。 科目を連続受験するとき、休憩時にメモ用紙を交換しないまま次の科目に入るのは不正行為 |

| 時刻 | 機械は90分（法規のみ65分）。開始時刻から30分経過すると入室できない | CBTは自分のタイミングで終了・退出できるが、終了ボタンを押したら戻れない |

### 時間配分 — 90分・解答17問

A問題14問で70点、B問題3問で30点。B問題1問はA問題2問ぶんである。A問題で粘ってB問題に時間を残さないのが、いちばん重い失敗。

| 区間 | 目安 | やること |
| --- | --- | --- |
| 0〜45分 | A問題14問1問3分 | 頭から順に。3分で解けなければ飛ばす（飛ばした問に印）。ここは走り抜ける区間 |
| 45〜58分 | 問15・問16（必須） | 1問6〜7分。(a) の値を (b) で使う構成が多いので (a) を丁寧に |
| 58〜62分 | 問17・問18を両方読む | 選ぶのに使ってよいのは2分まで。基準は次の見出し |
| 62〜75分 | 選んだ1問 | 決めたらもう戻らない。乗り換えは時間を二重に使う |

### 問17と問18、どちらを選ぶか

問17・問18は選択問題で、両方解答すると採点されない。選ぶ基準は1つでよい。(a) が確実に解けるほうを選ぶ

B問題は (a) で出した値を (b) で使う構成が多く、(a) を外すと (b) も連鎖して落ちる。 「(b) が解けそう」で選ぶと、(a) が詰まった時点で (b) も落ち、その問は0点になる。 逆に (a) さえ取れれば 5 点は残る（得点モデルの節）。(a) の解法が最初の30秒で見えたほうを採る。迷ったら、(b) が (a) の値を使うか（使わなければ (b) 単独でも取れる）と、手が動く量（時間）で決める。

令和8年度上期の例。問17は電熱（顕熱＋潜熱＋効率）で、 使う式は3本だが計算量が多い。問18は論理式の簡単化で、計算は要らないが 式変形を1つ誤ると (a)(b) とも落ちる。手が動く量が見えるのは問17のほうである。 自分がどちらの型で速いかは、過去問を解いた記録 （E 学習記録で 「B問題のみ」に絞れる）を見れば分かる。

### 検算の7手

時間が足りないときでも①②③は必ずやる。合計10秒で済み、事故の大半をここで止められる。

|  | 手 | やること | 例 |
| --- | --- | --- | --- |
| ① | 単位 | 式の両辺で単位が揃うか | $c\,m\,\Delta T$ は kJ/(kg·K)×kg×K＝kJ。 $mL$ は kg×kJ/kg＝kJ |
| ② | 桁 | 有効数字1桁で暗算し、選択肢と桁が合うか | 答えが選択肢の10倍・1/10なら、たいてい $60$ か $10^3$ の取り違え |
| ③ | 向き | 増減が常識と合うか | 効率が悪いほど所要時間は延びる。 $\%Z$ が小さいほど短絡電流は大きい |
| ④ | 極端値 | 境界を代入して破綻しないか | 滑り $s=0$ で二次銅損が0になるか。 $\delta=0$ で出力が0になるか |
| ⑤ | 逆算 | 得た答えを問題文の条件へ戻す | 求めた $E$ からベクトル図を描き直して、力率が題意どおりか見る |
| ⑥ | 選択肢 | 自分の値が「誤答用に置かれた値」と一致していないか | 次の見出しで詳しく |
| ⑦ | 別解 | 別ルートで解き直す（時間があるときだけ） | 一次換算で解いたものを二次換算でも解く |

### 選択肢は「情報」である — 誤答の値の多くは、具体的な間違いで再現できる

令和8年度上期・問2（直流発電機、 $D=0.5\,\mathrm{m}$ 、 $\ell=0.5\,\mathrm{m}$ 、 $B=0.4\,\mathrm{T}$ 、 $n=1500\,\mathrm{min^{-1}}$ 、1巻きコイルの  $e$ ）の 選択肢を、それぞれ「何を間違えた人の値か」で並べ直すと、次のようになる。

| 選択肢 | 値[V] | その値になる間違いの例 |
| --- | --- | --- |
| (1) | 2.50 | 周速で $\pi$ を忘れた（ $v=Dn/60$ ）× 導体1本で止めた |
| (2) | 5.00 | 周速で $\pi$ を忘れた × 導体2本 |
| (3) | 7.85 | 周速は正しいが、1巻き＝導体1本と数えた（半径を直径の位置に入れて導体2本で数えても 7.85 になる） |
| (4) | 15.7 | 正解。 $v=\pi Dn/60=39.3$ 、 $e=2B\ell v=15.7$ （有効導体は2本） |
| (5) | 942 | $/60$ を忘れた（ $\mathrm{min^{-1}}$ のまま）× 導体2本 |
「選択肢にあったから合っている」は成り立たない

5つのうち4つが、名前の付く具体的な間違いの結果である。R8上 問2 では、惜しい間違いの値が選択肢に用意されていた（毎回ではない）。 とくに (3) 7.85 は、周速まで正しく出せた人が導体を1本と数えたときの値と一致する。試験センターは誤答の作り方を公表していないので、表の右の列は「その値になる間違いの例」であって、出題者の意図ではない。

だから検算⑥は「自分の値が選択肢にあるか」ではなく 「自分の値は、どの間違いをした人の値か」を疑う手順になる。 出した値が  $\sqrt3$  倍・2倍・逆数・ $60$  倍のどれかで別の選択肢に化けるなら、その取り違えを自分がしていないかを確かめてからマークする。

### 捨て問の決め方 — 初見30秒で3つに仕分ける

ここでいう捨て問は、解くのをあきらめて、消去法でマークだけする問である。 決めるのは試験中、問題を初めて読んだとき。単元を前もって捨てる話ではない （単元の後回しは6節「後回しにする候補と、その判断の限界」）。A問題はどの問も5点で、難しい問を解いても点は増えない。だから重い問に時間を使う理由が無い。

| 初見30秒で見えたもの | 仕分け | いつ解くか |
| --- | --- | --- |
| 求める量と、最初に使う式の両方 | 今解く | その場で。ただし3分を超えたら下の「撤退の線」で飛ばす |
| 式は見えたが、計算が長い・図を描き直す必要がある | 後回し（問番号に印） | 時間配分の表の75〜88分の枠 |
| 求める量は分かるが式が出てこない／見たことのない装置・用語 | 捨て問 | その場で消去法で絞ってマークし、先へ進む。75〜88分で時間が余れば戻る |
捨て問は A問題で何問までなら計画が崩れないか

上の得点モデルから計算できる。 安全圏モデル（70点）は A問題を4問落としても届く。 最低合格モデル（60点）なら6問まで落とせるが、B問題2問の完答が前提である。

捨て問が4問を超えたら、残りの A問題は捨てずに取りに行く。 後回しの問へ戻る時間を、マーク確認の手前まで使う。B問題は捨て問にしない。完答できなくても (a) だけで5点入る（得点モデルの節の囲み）。

捨て問でも空欄にはしない。マークの期待値と、絞り方は次の見出しにある。 その場でマークしておくと、あとで戻らなかったときの空欄と、マーク欄のずれの両方を防げる。

### 撤退の線と、最後のマーク
- 1問3分で飛ばす。5点のために10分使うと、確実に取れるはずの別の5点を2問落とす
- 計算が3行を超えて見通しが立たないなら、方針が違う。式を選び直すか飛ばす。 正しい方針なら機械科目のA問題は3行前後で答えに届く
- 分からなくても必ずマークする。五肢択一なので空欄は0点だが、 当てずっぽうでも期待値は1点。2択まで絞れれば2.5点である。 明らかに違う選択肢を消すだけでも得点は上がる
- 飛ばすときはその場でマーク欄も飛ばす。筆記方式でのマークずれは、 気付いた時点で直す時間が残っていない
- 最後に見るのは3点だけ。空欄ゼロ／問17・18が片方だけ／ずれが無いかここに書いた運用ルールの出どころ

電卓の条件・持ち込み品・試験時間（機械90分）・入室禁止時刻・選択問題の扱いは、 試験センターの受験案内および試験概要（2026-09 取得）と、問題冊子の注意事項で確認したもの。時間配分・解く順番・捨て問の仕分け（初見30秒）は本Wikiの提案であって、公表された推奨ではない。 制度は改定されることがあるので、自分が受ける回の受験案内で必ず確認すること。
