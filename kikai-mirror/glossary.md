# 用語集・索引

本Wikiに登場する重要用語を五十音順に掲載。

### あ

IGBT
IGBT
絶縁ゲートバイポーラトランジスタ。電圧駆動（FET型ゲート）と低オン電圧（バイポーラ型主回路）を両立。中容量インバータの主役。
渦電流損
UZUDENRYUU SON
磁束変化により鉄心内に流れるうず電流によるジュール損（うず電流損とも表記）。板厚t・周波数f・最大磁束密度Bmの各2乗に比例し、鉄心の抵抗率に反比例（∝ t²f²Bm²/ρ）。薄い鋼板の積層と、抵抗率を高めるけい素の添加で低減する。
一次遅れ要素
ICHIJI OKURE
伝達関数 G(s) = K / (1 + Ts) で表される基本要素。Tは時定数で、ステップ応答は t = T で最終値の約63.2%に達する（100%ではない）。RC回路や温度系が代表例。

### か

かご形回転子
KAGOGATA
導体棒の両端を端絡環で短絡した誘導電動機の回転子。ブラシ・スリップリングが不要で堅牢だが、巻線形と違い外部から二次抵抗を加減できないため比例推移による始動改善は使えない。
界磁制御
KAIJI SEIGYO
直流電動機の速度制御法の一つ。界磁電流を減らす（弱め界磁）と磁束φが減り N = (V − IaRa) / kφ の分母が小さくなって速度は上昇する。定出力制御となる。電機子側の抵抗制御（損失大）・電圧制御（ワードレオナード方式など）との区別が頻出。
逆起電力
GYAKU KIDENRYOKU
電動機の電機子に生じる起電力 E = V − IaRa = kφN。始動時は N = 0 で逆起電力が無いため始動電流が非常に大きく、始動抵抗を電機子回路に入れて制限する。
輝度
KIDO
光源面をある方向から見たときの、単位投影面積あたりの光度 [cd/m²]。受照面に入る光束で定義する照度 [lx] との混同が定番の引っかけ。
起磁力
KIJIRYOKU
磁気回路に磁束を生じさせる能力 F = NI [A]。磁気回路のオームの法則 φ = F / Rm で磁束が決まる（Rm:磁気抵抗 = l / μA）。電気回路の起電力に対応させて覚える。
ゲイン余裕・位相余裕
GAIN MARGIN
開ループ周波数特性から安定度を測る指標。位相が−180°となる周波数でゲインが0dBまでどれだけ低いかがゲイン余裕 [dB]、ゲインが0dB（1倍）の周波数で位相が−180°までどれだけ余裕があるかが位相余裕。ともに正なら安定。
慣性モーメント
KANSEI MOMENT
回転体の回りにくさ J [kg·m²]。蓄えられる運動エネルギーは E = (1/2)Jω²。はずみ車効果 GD² との関係は J = GD²/4（4で割るのを忘れるのが定番ミス）。
コンデンサ始動
CONDENSER START
単相誘導電動機の始動法。補助巻線に直列コンデンサを入れ、主巻線との位相差の大きい進み電流で回転磁界を作る。抵抗の位相差を使う分相始動より始動トルクが大きい。

### さ

滑り
SUBERI
誘導機において同期速度と回転子速度の差の比。s = (Ns − N) / Ns。0 < s < 1 が電動機域、s < 0 が発電機域、s > 1 が制動域。
全日効率
ZENJITSU KOURITSU
配電用変圧器のように負荷が時間変化する場合に、1日（24時間）の電力量[kWh]で評価した効率。ηd = 出力電力量 /（出力電力量＋鉄損電力量＋銅損電力量）×100。出力電力量は日負荷曲線の各時間帯について kVA×力率×時間 を合計、鉄損電力量は 鉄損×通電時間（負荷ゼロでも無負荷通電中なら発生。電源切離し中は発生しない）、銅損電力量は 全負荷銅損×負荷率²×時間 で求める。負荷率は kVA÷定格容量[kVA] で取り、力率は掛けない（銅損は巻線電流＝kVA で決まるため）。複数時間帯を1つにまとめるときは等価負荷率 xe = √(Σxk²tk / T) を使う。通常効率が kW（ある負荷状態）で評価するのに対し、全日効率は kWh（1日全体）で評価する点が最大の違い。
進み補償
SUSUMI HOSHOU
自動制御の安定度・速応性向上に用いる位相進み要素。ゲイン交差周波数付近に位相進みを与えて位相余裕を改善し、速応性を高める。
照度
SHOUDO
単位面積あたりに入射する光束。E = F / A [lx]。点光源では距離の二乗に反比例（逆二乗の法則）。
整流回路
SEIRYU KAIRO
交流を直流に変換する回路。半波・全波・ブリッジ・三相全波があり、平均値・実効値・脈動率がそれぞれ異なる。
サイリスタ
THYRISTOR
ゲート信号でターンオンする三端子半導体スイッチ。一旦オンすると電流ゼロまでオフできない。位相制御整流に使用。
サイクロコンバータ
CYCLOCONVERTER
交流をいったん直流に変換せず、直接異なる周波数の交流に変換する電力変換装置。低速大容量の交流電動機駆動に用いる。整流器＋インバータを経由する間接方式との区別。
サーボ機構
SERVO
時々刻々変わる目標値に制御量を追従させる制御（追値制御）。制御量は位置・角度・姿勢など。温度・流量などを一定値に保つプロセス制御（定値制御が主体）との対比が頻出。
シーケンス制御
SEQUENCE CONTROL
あらかじめ定められた順序または条件に従って制御の各段階を逐次進めていく制御。リミットスイッチ等による条件判定は使うが、制御量を目標値と連続的に比較して訂正するフィードバック制御とは動作原理が異なる。
循環電流
JUNKAN DENRYU
変圧器の並行運転で極性や巻数比（定格電圧）が一致しないとき、負荷と無関係に巻線間を流れ続ける電流。巻線の過熱・焼損の原因。並行運転条件のどれが崩れると何が起きるかの対応が頻出。
水平面照度
SUIHEIMEN SHOUDO
水平な受照面上の照度。点光源から距離r・入射角θのとき Eh = (I / r²)·cosθ（入射角余弦の法則）。法線照度 I/r² に cosθ を掛け忘れるのが定番ミス。
整流子
SEIRYUSHI
直流機で電機子巻線に生じる交流起電力を直流に変換する機械的整流装置。ブラシとの間の火花を防ぐ整流改善には、補極の設置（電圧整流）と接触抵抗の大きい炭素ブラシの使用（抵抗整流）がある。
制動巻線
SEIDOU MAKISEN
同期機の磁極面に設けたかご形の導体。負荷急変時に回転子が同期速度のまわりで振動する乱調を制動して抑え、同期電動機では自己始動用のトルクも与える。
COP
SEISEKI KEISUU
成績係数。ヒートポンプなどで、加熱・冷却能力 [kW] を消費電力 [kW] で割った値（熱量 [kJ] ÷ 消費電力量 [kJ] でも同じ）。外気から熱をくみ上げるため1を大きく超える（電熱器は最大1）。同一サイクルでは加熱COP = 冷却COP + 1。
全波整流
ZENPA SEIRYU
交流の正負両半波を利用する整流。単相全波（ブリッジ整流回路）のダイオード整流では直流平均電圧 Ed = 0.9E（E:実効値）、半波整流では 0.45E。サイリスタで制御角（点弧角）αをとると誘導性負荷・電流連続時 Ed = 0.9E·cosα。
最大効率
SAIDAI KOURITSU
変圧器の効率が最大になる条件は鉄損＝銅損（無負荷損＝負荷損）。銅損は負荷率αの2乗で変わるため、α = √(鉄損 / 全負荷銅損) の負荷率で最大となる。全日効率では電力量 [kWh] ベースで同じ条件を考える。

### た

同期速度
DOUKI SOKUDO
回転磁界が回る速度。Ns = 120f / p（p:極数, f:周波数[Hz]）。誘導機の回転速度は滑り分の速度を差し引いた N = (1−s)Ns となる。
電機子反作用
DENKISHI HANSAYOU
電機子電流が作る磁束が界磁主磁束を歪ませる現象。直流機では中性軸偏移と減磁、同期発電機では遅れ力率で減磁・進み力率で増磁・力率1で交差磁化が生じる（同期電動機では逆）。
短絡比
TANRAKU HI
同期機の指標。無負荷で定格電圧を発生させるのに必要な界磁電流を、三相短絡時に定格電流を流すのに必要な界磁電流で割った値（Ks = If0/Ifs ≈ 1/xs[p.u.]）。短絡比が大きいほど安定度が高く電圧変動率が小さい。
デューティ比
DUTY RATIO
チョッパ等のスイッチング素子で、1周期中にオン状態である時間の比率。降圧チョッパでは Vo = D · Vi。
伝達関数
DENTATSU KANSUU
線形システムの入力と出力をラプラス変換し、その比 G(s) = Y(s)/X(s) で表したもの。
他励
TAREI
界磁巻線を電機子と別の独立電源で励磁する直流機の励磁方式。界磁と電機子が並列の分巻、直列の直巻、両方を持つ複巻と合わせて4方式の特性比較が頻出。他励はワードレオナード方式など広範囲の速度制御に向く。
直巻電動機
CHOKUMAKI
界磁と電機子が直列の直流電動機。トルク特性は磁気飽和前でトルク∝電流の2乗、速度特性は負荷が減ると急上昇し、無負荷運転は危険速度に達するため禁止（ベルト駆動不可）。始動トルクが大きい。
短絡試験
TANRAKU SHIKEN
変圧器の二次側を短絡し一次側から定格電流を流す試験。インピーダンス電圧と負荷損（銅損）を測る。定格電圧を加えて鉄損・励磁電流を測る無負荷試験との対応（短絡=銅損／無負荷=鉄損）が定番の引っかけ。
単巻変圧器
TANMAKI HENATSUKI
一次・二次で巻線の一部（分路巻線）を共用する変圧器。直列巻線の容量が自己容量で、昇圧時 自己容量 = 負荷容量 × (V2 − V1) / V2。小形軽量で電圧変動も小さいが、一次二次が絶縁されない。
定常偏差
TEIJOU HENSA
十分に時間が経過した後も残る目標値と制御量の差（オフセット）。ステップ状の目標値に対し、積分要素を持たない系では比例制御だけだと残り、積分動作を加えると0にできる。微分動作は速応性の改善であり定常偏差は消せない、が定番の引っかけ。
等価回路
TOUKA KAIRO
変圧器や誘導電動機を電気回路に置き換えた解析模型。誘導電動機では二次側を一次側に換算し、機械出力を抵抗 r2(1 − s)/s で表す。励磁回路を電源側へ移したL形簡易等価回路が計算の標準形。
同期インピーダンス
DOUKI IMPEDANCE
同期発電機の内部を表すインピーダンス Zs = ra + jxs（xs:同期リアクタンス）。単位法の値は短絡比のほぼ逆数（Zs[p.u.] ≈ 1/Ks）。短絡電流・電圧変動率の計算に使う。
同期調相機
DOUKI CHOUSOUKI
無負荷で運転する同期電動機。界磁電流の加減で無効電力を連続的に調整でき、過励磁で進み電流（コンデンサ作用）、不足励磁で遅れ電流（リアクトル作用）となる。系統の力率調整・電圧調整に用いる。
ダイオード
DIODE
PN接合の2端子素子。順方向のみ導通する整流作用を持ち、制御端子がないためオンオフの制御はできない。ゲートでオンのみ制御できるサイリスタ、オンオフとも制御できるトランジスタ・IGBTとの制御性の違いが頻出。
抵抗加熱
TEIKOU KANETSU
電流のジュール熱（I²Rt）で加熱する方式。発熱体からの伝熱による間接式と、被加熱物自体に通電する直接式がある。誘導加熱・誘電加熱・アーク加熱など加熱方式ごとの原理の対応が頻出。

### な

ナイキスト線図
NYQUIST
周波数応答 G(jω) を複素平面上で ω=0→∞ にトレースした線図。−1+j0 点との関係で安定判別を行う。
二次入力
NIJI NYUURYOKU
誘導電動機で回転磁界から回転子に伝わる電力 P2。二次銅損 Pc2・機械出力 Pm との比は P2 : Pc2 : Pm = 1 : s : (1 − s)。トルクは T = P2 / ωs（同期ワット）で、効率・トルク計算の枢要。
二乗低減トルク
NIJOU TEIGEN TORQUE
トルクが回転速度の2乗に比例する負荷特性。ポンプ・送風機・ファンが代表で、軸動力は速度の3乗に比例する。インバータで回転数を下げると所要動力がほぼ3乗で減るため省エネ効果が大きい。
2進数
NISHINSUU
0と1の2値で数を表す基数2の表記。1桁が1ビット。基数変換や負数を表す2の補数、AND・OR・NOT・NAND・NOR などの論理回路、論理式の変形に使うド・モルガンの定理が情報分野の定番。

### は

比例推移
HIREI SUII
巻線形誘導機において、二次抵抗を k 倍にすると同一トルクを生じる滑りも k 倍になる現象。始動トルク改善や速度制御に利用。
百分率インピーダンス
%Z
変圧器の定格電流が流れたとき、内部インピーダンスで生じる電圧降下を定格電圧で割った百分率。短絡電流の計算や並列運転の負荷分担に用いる。
V結線
V KESSEN
単相変圧器2台で三相を供給する結線。同一定格2台で平衡三相負荷を供給する標準計算では、三相容量は √3·Sn（Sn:単器容量）、2台の合計容量に対する利用率は √3/2 ≈ 86.6%、Δ結線3台に対する出力比は 1/√3 ≈ 57.7%（異容量V結線や単相負荷を併給する灯動共用では各器の負担を個別計算する）。Δ-Δ結線の1台が故障したときの応急運転（V-V運転）や、需要増を見越した段階増設に用いる。
PWM制御
PWM
パルス幅変調。スイッチング素子のオン時間を変化させ、平均電圧や正弦波等価出力を作る方式。インバータの基本制御方式。
ブロック線図
BLOCK DIAGRAM
システムを伝達関数のブロックと信号線で表した図。直列・並列・フィードバック結合の合成則を用いて全体の伝達関数を求める。
発熱量
HATSUNETSURYOU
電気エネルギーが熱に変わる量。Q = P · t = I²Rt [J]。電熱では Q = c·m·ΔT で温度上昇を計算する。
ヒステリシス損
HYSTERESIS SON
鉄心の磁化の履歴（ヒステリシスループ）の面積に相当する損失。周波数f に比例し、最大磁束密度Bm の約1.6〜2乗に比例する（Ph ∝ f·Bm^1.6〜2）。f と Bm で次数が違う点が要注意。電源電圧一定のまま周波数が下がると Bm ∝ V/f が増えて鉄損は増加する。けい素鋼板の採用で低減。
ファラデーの法則
FARADAY
電気分解で電解液から電極に析出する物質量は、流れた電気量 Q = It と物質の電気化学当量Kに比例する（W = KIt）。電池の充放電量の計算にも使う。電磁誘導のファラデーの法則とは別物。
フィードバック制御
FEEDBACK
制御量を検出して目標値と比較し、その偏差を打ち消すように操作量を加減する閉ループ制御。外乱の影響を自動的に修正できるが、偏差が現れてからでないと動作しない。
閉ループ伝達関数
HEI LOOP
負帰還のフィードバック結合の合成伝達関数 W(s) = G / (1 + GH)（正帰還では分母が 1 − GH）。開ループ伝達関数（一巡伝達関数）GH との取り違えが定番の引っかけ。単位フィードバックでは H = 1。
並行運転
HEIKOU UNTEN
変圧器を並列で運転する方式。条件は極性の一致・巻数比（定格電圧）の一致・%Zの一致、三相ではさらに相回転と角変位の一致。ただし%Zだけは性質が別で、不一致でも運転自体はでき負荷分担が偏るだけ（極性・巻数比・角変位の不一致は循環電流や短絡になる）。負荷分担は共通の基準容量に換算した%Zに逆比例する（自己容量基準の%Zが等しければ定格容量に比例して分担）。
反発始動
HANPATSU SHIDOU
単相誘導電動機の始動法のうち、ブラシ間を短絡した整流子形回転子で始動する方式。始動トルクは最大。大小比較（反発 > コンデンサ > 分相 > くま取りコイル形）が定番の出題。
ボード線図
BODE DIAGRAM
横軸に角周波数（対数目盛）、縦軸にゲイン [dB] と位相をとった周波数応答の線図。一次遅れ要素は折れ点角周波数 ω = 1/T から −20dB/dec で減衰し、位相は0°→−90°に変化する。
補償巻線
HOSHOU MAKISEN
直流機の磁極片に埋め込み、電機子巻線と直列に接続して電機子反作用の磁束を打ち消す巻線。整流改善のため幾何学的中性軸に置く小磁極である補極との役割の違いが定番の引っかけ。
ポンプ
PUMP
揚水ポンプ用電動機の所要動力は P = 9.8QH / η [kW]（Q:流量 [m³/s]、H:全揚程 [m]、η:効率）。流量が [m³/min] で与えられたら60で割る単位変換が定番の引っかけ。余裕係数を掛けて容量を選定する。
Vカーブ
V CURVE
同期電動機の界磁電流（横軸）と電機子電流（縦軸）の関係曲線（位相特性曲線）。力率1で電機子電流が最小になり、過励磁側で進み力率、不足励磁側で遅れ力率となる。

### ま

巻数比
MAKISUUHI
変圧器の巻数の比 a = N1/N2 = E1/E2 = I2/I1。電圧は巻数に比例、電流は反比例（逆比）が定番の引っかけ。インピーダンスは a² 倍で換算する。タップ切換は巻数比を変えて電圧を調整する操作。
漏れリアクタンス
LEAKAGE REACTANCE
相手巻線と鎖交せずに漏れる磁束（漏れ磁束）によるリアクタンス。変圧器の%Zの主成分で、短絡電流を制限する働きをする。

### や

誘導起電力
YUUDOU KIDENRYOKU
直流機の電機子に生じる起電力 E = pZφN / 60a（p:極数、Z:全導体数、a:並列回路数、N [min⁻¹]）。E = kφN の形で使い、負荷時の発電機では E = V + IaRa で端子電圧より高く、電動機では逆起電力として V より小さい。
誘導発電機
YUUDOU HATSUDENKI
誘導機を同期速度より速く（滑り s < 0）外力で駆動すると発電機になる。励磁用の無効電力を系統など外部から受け取る必要がある（コンデンサによる自己励磁を用いない限り単独では発電できない）。構造が簡単で小水力・風力発電に用いる。
誘電加熱
YUUDEN KANETSU
高周波電界中で絶縁物（誘電体）内部に生じる誘電損（分極の遅れ）により加熱する方式。マイクロ波加熱（電子レンジ）が代表。導体に生じるうず電流で加熱する誘導加熱（IH調理器・金属の焼入れ）との対象物の違いが定番の引っかけ。

### ら

ルーメン
lm
光束の単位。光源から放出される可視光の総量。F = I · ω（I:光度[cd], ω:立体角[sr]）。
励磁電流
REIJI DENRYU
変圧器の一次側に無負荷でも流れる電流。磁束を作る磁化電流と鉄損を供給する鉄損電流のベクトル和。鉄心の磁気飽和のため波形はひずみ、第3高調波を多く含む。

### わ

Y-Δ始動
Y-DELTA START
かご形誘導電動機の始動法。始動時に固定子巻線をY結線とし、加速後Δ結線に切り換える。全電圧（じか入れ）始動に比べ始動電流・始動トルクとも 1/3 倍。1/√3 倍としないのが定番の引っかけ。
