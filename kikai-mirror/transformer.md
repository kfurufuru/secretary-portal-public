🔬 ミクロの因果（なぜ巻数比で電圧が変わるか）
1. **一次巻線に交流電圧 v₁** を加える → 励磁電流が鉄心に交番磁束 Φ を作る（鉄心＝磁束の通り道）
2. **共通磁束 Φ が一次・二次の両巻線を貫く**（漏れ磁束なしの理想変圧器なら同じ Φ）
3. 各巻線に電磁誘導で **e = N·dΦ/dt** が誘起 → 電圧は巻数 N に比例
4. 結果、**巻数比どおりに電圧が変わる**：$\dfrac{V_1}{V_2} = \dfrac{N_1}{N_2} = a$。負荷時の電流は逆比 $\dfrac{I_2}{I_1} = a$（V₁I₁ ≒ V₂I₂）

## 2.理想変圧器と巻数比

01 / 15
**巻数比と電圧・電流（理想変圧器での関係）**
$a = \dfrac{N_1}{N_2} = \dfrac{V_1}{V_2} = \dfrac{I_2}{I_1}$
$N_1,N_2$: 一次・二次巻数、$V,I$: 各側の電圧・電流。**電流は巻数比の逆比**になる。
これは「理想変圧器」での関係
上の式は次を**すべて無視した理想条件**で成り立つ。実際の変圧器では負荷時の端子電圧比・電流比はこの式から少しずれる。
- **巻線抵抗** $r_1, r_2$（銅損と電圧降下の原因）
- **漏れリアクタンス** $x_1, x_2$（電圧降下の原因）
- **鉄損**（鉄心のヒステリシス損・渦電流損）
- **励磁電流**（無負荷でも流れる電流。$I_1 = I_2/a$ が厳密には成り立たない理由）

ずれの正体を回路の形で表したものが、セクション4の**等価回路**。ずれの大きさを百分率で表したものが、セクション8の**電圧変動率**。
02 / 15
**一次換算（二次側の量を一次側へ寄せる）**
$r_2' = a^2 r_2,\quad x_2' = a^2 x_2,\quad I_2' = I_2 / a,\quad V_2' = a V_2$
インピーダンスは $a^2$ 倍、電流は $1/a$ 倍、電圧は $a$ 倍。一次換算と二次換算を計算の途中で混ぜない（どちら側に統一したかを必ず先に決める）。

## 4.実際の変圧器と等価回路

理想変圧器に、無視していた4つ（巻線抵抗・漏れリアクタンス・鉄損・励磁電流）を回路素子として描き足したものが等価回路。**電圧変動率・効率・短絡電流・並行運転はすべてこの1枚から導かれる**。
二次側の量は $r_2' = a^2 r_2$ のように一次換算してある。励磁回路を電源側の端に寄せた「簡易等価回路」で扱うことも多く、三種の計算ではその近似で十分。

| 回路素子 | 正体 | 効いてくる場所 | 求め方 |
| --- | --- | --- | --- |
| $r_1,\ r_2'$ | 巻線の抵抗 | **銅損**（負荷電流の2乗）・電圧降下 | 短絡試験 |
| $x_1,\ x_2'$ | 漏れ磁束によるリアクタンス | **電圧降下**（電圧変動率・%Z） |   |
| $r_0$ | 鉄損を電力として消費する等価抵抗 | **鉄損**（無負荷でも発生） | 無負荷試験 |
| $x_0$ | 鉄心を磁化するための励磁リアクタンス | **磁化電流**（磁束をつくる電流） |   |

発展 — この回路の正体は理論の「結合コイルのT形等価回路」理論とのつながり（開く）
この回路の正体は、理論で学ぶ **2つの結合コイルのT形等価回路**（$L_1-M,\ L_2-M,\ M$ の3インダクタ）そのもの。対応は次の通り：
- **励磁インダクタンス ↔ 相互インダクタンス $M$**（鉄心を共有し磁束を結合する分）
- **漏れリアクタンス ↔ $L_1-M,\ L_2-M$**（相手と結合しない漏れ磁束の分）

結合係数 $k=M/\sqrt{L_1 L_2}$ が1に近いほど漏れが小さく、理想変圧器（$k=1$・漏れゼロ）で $V_1/V_2=N_1/N_2$ が厳密に成立する。「なぜ巻数比で電圧が変わるか」は、相互誘導 $V_2=-N_2(d\Phi/dt)$ を二巻線が共有する磁束 $\Phi$ で受けるからだと理論まで遡ると腑に落ちる。
→ 理論Wiki「3.1 インダクタンス」で相互M・結合係数k・和動/差動を深掘り
この節の確認問題（2問）
等価回路の「直列4素子」と「並列の励磁回路」は、それぞれ何を表し、どちらの試験で求まる？直列 r₁, x₁, r₂′, x₂′ ＝ **銅損と電圧降下** → **短絡試験**／並列 r₀, x₀ ＝ **鉄損と磁化電流** → **無負荷試験**。ただし短絡試験で出るのは和 R_e = r₁+r₂′、X_e = x₁+x₂′ だけで、r₁ と r₂′ を分けるには直流抵抗測定が要る（三種は和のままで解ける）。電圧変動率・効率・短絡電流・並行運転は、すべてこの1枚から導かれる

## 5.無負荷試験（開放試験）

何を測って何を得るか
**二次側を開放し、一次側に定格電圧を加える**。負荷電流が流れないので直列の $r_1,x_1$ による降下はごくわずかで、測るのは実質**励磁回路だけ**。得られるのは 鉄損 $P_i$ と励磁枝 $r_0,\ x_0$。
二次側を**開放**し、一次に**定格電圧**を加える。負荷電流が流れないので直列インピーダンスの降下はごくわずかで、測っているのは実質**励磁回路だけ**。
- 測定量：**無負荷電流 $I_0$**、**入力電力 $P_0$**、印加電圧 $V_1$（＝定格電圧）
- **鉄損はおおむね $P_0$ とみなせる**。無負荷時に流れるのは励磁電流だけで、その一次銅損 $I_0^2 r_1$ は $P_0$ に比べて小さいため無視する（これは近似）

励磁電流 $I_0$ は、鉄損を負担する**有効分** $I_w$ と、磁束をつくる**磁化分** $I_\mu$ の直角合成になる。
04 / 15
**無負荷試験 — 励磁電流の分解と励磁枝**
$I_0^2 = I_w^2 + I_\mu^2,\qquad I_w = \dfrac{P_0}{V_1},\qquad I_\mu = \sqrt{I_0^2 - I_w^2}$
ここから $r_0 = V_1/I_w = V_1^{\,2}/P_0$、$x_0 = V_1/I_\mu$。$I_w$ は電圧と同相の成分なので $P_0 = V_1 I_w$ から出る。
鉄損を負担する $I_w$ は電圧と**同相**、磁束をつくる $I_\mu$ は電圧より**90° 遅れ**。直角三角形なので $I_0^2 = I_w^2 + I_\mu^2$。無負荷では磁化分が圧倒的に大きいため、無負荷力率は 0.1〜0.3 程度と非常に低い。
単相と三相で式をそのまま使わない
上の式は**単相、または三相の1相分**に対するもの。三相変圧器で三相電力 $P_{0,3\phi}$ と線間電圧・線電流を測った場合は、1相分に直してから当てはめる（Y結線なら相電圧は $V_{\ell}/\sqrt3$、相電流は線電流。Δ結線なら相電圧は線間電圧、相電流は $I_{\ell}/\sqrt3$）。結線が示されていない問題では、**1相分の値が与えられているのか三相合計なのかを必ず確認する**。

## 6.短絡試験（インピーダンス試験）

何を測って何を得るか
**二次側を短絡し、一次側に低い電圧を加えて定格電流を流す**。印加電圧が定格の数 % と低いので磁束が小さく鉄損は無視できる。測るのは実質**直列インピーダンスだけ**。得られるのは 全負荷銅損 $P_{cN}$ と $Z_e,\ R_e,\ X_e$、そして %Z。
二次側を**短絡**し、一次に**低電圧**を加えて定格電流を流す。磁束が小さく鉄損が無視できるので、測っているのは実質**直列インピーダンスだけ**。
- 測定量：**短絡時の印加電圧 $V_s$**（＝インピーダンス電圧）、**電流 $I_s$**（定格電流まで上げる）、**入力電力 $P_s$**
- **入力電力は定格電流時の銅損とみなせる**（鉄損が無視できるため）

**短絡試験 — 等価インピーダンス**
$Z_e = \dfrac{V_s}{I_s},\qquad R_e = \dfrac{P_s}{I_s^{\,2}},\qquad X_e = \sqrt{Z_e^{\,2} - R_e^{\,2}}$
$R_e = r_1 + r_2'$、$X_e = x_1 + x_2'$（基準側に換算した合計）。$R_e$ は $P_s = I_s^2 R_e$ から出る。

| --- | --- | --- |
| 二次側 | **開放** | **短絡** |

解法例 2.1.4（短絡試験から等価回路定数・%Z・全負荷銅損まで）
**与えられた値:** 単相変圧器 $10\;\mathrm{kV\cdot A}$、一次定格電圧 $1000\;\mathrm{V}$。短絡試験で $V_s = 50\;\mathrm{V}$、$I_s = 10\;\mathrm{A}$、$P_s = 200\;\mathrm{W}$ を得た（すべて一次側の測定値）。
**何を求めるか:** $Z_e,\ R_e,\ X_e$、%Z、全負荷銅損、短絡電流。
**① まず定格電流を出す**（短絡試験の電流が定格かを確認するため）
$I_n = \frac{S_N}{V_n} = \frac{10 \times 10^3}{1000} = 10\;[\mathrm{A}]$
$I_s = I_n$ なので、この短絡試験は**定格電流での測定**になっている。
**② 等価インピーダンス・等価抵抗・等価リアクタンス**
$Z_e = \frac{V_s}{I_s} = \frac{50}{10} = 5\;[\Omega],\qquad R_e = \frac{P_s}{I_s^{\,2}} = \frac{200}{10^2} = 2\;[\Omega]$
$X_e = \sqrt{Z_e^{\,2} - R_e^{\,2}} = \sqrt{5^2 - 2^2} = \sqrt{21} \approx 4.58\;[\Omega]$
**③ %Z**（定義の2つの式が一致することを確認）
$\%Z = \frac{V_s}{V_n}\times 100 = \frac{50}{1000}\times 100 = 5\;[\%] \;\;=\;\; \frac{I_n Z_e}{V_n}\times 100 = \frac{10 \times 5}{1000}\times 100 = 5\;[\%]$
**④ p・q に分けて検算**
$p = \frac{I_n R_e}{V_n}\times 100 = 2.0\;[\%],\qquad q = \frac{I_n X_e}{V_n}\times 100 \approx 4.58\;[\%]$
$\sqrt{p^2 + q^2} = \sqrt{2.0^2 + 4.58^2} \approx 5.00\;[\%] \;=\; \%Z \;\checkmark$
**⑤ 全負荷銅損と短絡電流**（$P_{cN}$ は定格電流時の銅損）
$P_{cN} = P_s = 200\;[\mathrm{W}]$
$I_s' = \frac{100}{\%Z}I_n = \frac{100}{5}\times 10 = 200\;[\mathrm{A}]$
**単位確認:** V÷A＝Ω ✓／W÷A²＝Ω ✓／%Z は無次元 ✓ **検算:** 短絡電流は定格の $100/5 = 20$ 倍。
**ここから電圧変動率へ直結する:** 力率 0.8 の定格負荷なら、$\varepsilon \approx p\cos\theta + q\sin\theta = 2.0\times0.8 + 4.58\times0.6 \approx 4.35\;[\%]$（遅れ）。進みなら $2.0\times0.8 - 4.58\times0.6 \approx -1.15\;[\%]$ で符号が反転する。**短絡試験1つから %Z・銅損・短絡電流・電圧変動率がすべて出る**のがこの試験の価値。
**ひっかけ注意:** $R_e$ の分母は $I_s^{\,2}$ であって $I_s$ ではない（$P = I^2R$ だから）。また $X_e = Z_e - R_e$ は誤り（直角合成なので二乗の差の平方根）。$5-2=3$ としないこと（正しくは 4.58）。
$R_e$ と $X_e$ は **90° ずれたベクトル**。図は実寸比（1 Ω = 100 px）なので、$Z_e - R_e = 1.25$ の破線が高さ 1.85 の頂点に届かないことが目で見て分かる。
力率経由でもう一度出す（独立2経路で検算する）
短絡試験の測定値だけで**力率**が出せる。ここから $R_e$ と $X_e$ を三角関数で出すと、三平方とは別の計算経路で同じ値に着地する。
$\cos\theta = \frac{P_s}{V_s I_s} \;\Longrightarrow\; R_e = Z_e\cos\theta,\qquad X_e = Z_e\sin\theta$
2つの経路（$R_e = P_s/I_s^2$ と $R_e = Z_e\cos\theta$）が同じ値になれば、**途中の算術ミスはまず拾える**。**試験本番で30秒で回せる検算**なので、値を出したら必ず通す。

## 7.損失・通常効率・全日効率

まず覚える結論（3つ）
- **通常効率は電力 [kW] の比、全日効率は電力量 [kWh] の比**（効率そのものは無次元で [%] 表示）。全日効率では出力・鉄損・銅損を すべて電力量 [kWh] に直してから 分母に入れる。通常効率の答えに時間を掛けても全日効率にはならない。
- **出力は「kV·A × 力率 × 時間」、鉄損は「一定 × 通電時間」、銅損は「全負荷銅損 × 負荷率² × 時間」**。この3つを別々に積算してから割り算する。
- **力率は出力 kWh に使い、負荷率は kV·A で取る**（銅損を決めるのは巻線電流で、定格電圧ならその電流が kV·A に比例する）。kV·A で与えられた負荷率に力率を掛けるのは誤り。ただし**負荷が kW で与えられたら先に $S = P/\cos\phi$ で kV·A へ換算**する（掛けるのでなく割る）。

本セクションでは力率角を $\phi$ と書く（同じ量をセクション2の電圧変動率では $\theta$ と表記している）。

### 鉄損と銅損 — どこで・いつ発生するか

変圧器の損失は **無負荷損** と **負荷損** に大別される。全日効率で効くのは大きさより「いつ発生しているか」の違い。
なお **無負荷損 ＝ 鉄損、負荷損 ＝ 銅損 は厳密には近似**。無負荷損には鉄損のほか誘電体損や励磁電流による巻線抵抗損が、負荷損には抵抗損のほか漂遊負荷損が含まれる。三種の計算では無負荷損を鉄損 $P_i$、負荷損を銅損 $P_c$ で代表させるのが前提。以下この前提で書く。

| 項目 | 鉄損 $P_i$ | 銅損 $P_c$ |
| --- | --- | --- |
| 主な発生場所 | 鉄心 | 巻線 |
| 主な内訳 | ヒステリシス損・渦電流損 | 巻線抵抗による $I^2R$ 損 |
| 負荷との関係 | **定格電圧・定格周波数ならほぼ一定**（負荷によらない） | **負荷電流の2乗に比例** |
| **無負荷通電中** （電源は入・負荷ゼロ） | 発生する | 三種の計算では**ほぼ 0** として扱う |
| **電源切離し中** （遮断器を開放） | 発生しない | 発生しない |

主線で使う鉄損の表現
**鉄損は、定格電圧・定格周波数で運転している間は、負荷にかかわらずほぼ一定と扱う。**「電圧の2乗に比例」は条件（周波数一定・近似）を省くと誤解のもとなので、全日効率の計算では上の表現を使う。
「無負荷」と「電源切離し」は別物
問題文の「無負荷」は**電圧は加わったまま負荷がゼロ**の状態で、鉄損は発生し続ける。**電源から切り離した（開放した）**ときだけ鉄損もゼロになる。「24時間通電」と書いてあれば $T_{\mathrm{on}}=24$、「12時間だけ電源に接続」ならその通電時間を使う。
鉄損の内訳と、電圧・周波数への依存性主線ではないが論説で問われる（補足を開く）
鉄損は主に次の2つからなり、いずれも磁束密度の最大値 $B_m$ に依存するが、**周波数・材料・鉄心条件（板厚）への依存の仕方は互いに異なる**。$E = 4.44 f N B_m A$ から $B_m \propto V/f$ なので、電圧と周波数の効き方も違ってくる。
- **ヒステリシス損** $P_h \propto f B_m^{\,n}$（鉄心の磁化・消磁のたびに履歴面積分のエネルギーが失われる）→ 周波数一定なら $P_h \propto V^{\,n}$。**Steinmetz 指数 $n$ は材料・動作範囲による経験値でおおむね 1.6〜2**（普遍の固定値ではない）。問題文で指数や比例関係が指定されていれば、必ずその指定を優先する
- **渦電流損** $P_e \propto f^2 B_m^2 t^2$（$t$: 鋼板の厚さ）→ 正弦波・鉄心条件一定・$V \simeq E$ の古典的近似で $B_m \propto V/f$ を代入し**印加電圧 $V$ の関数として表すと** $P_e \propto V^2$ となり、式上の $f$ が相殺される。無条件に「周波数に依存しない」のではない（$B_m$ を一定に保つ条件なら $P_e \propto f^2$）。成層鉄心（薄い鋼板を積層）で $t$ を小さくするのはここを減らすため

したがって「鉄損は電圧の2乗に比例」は、**周波数一定のもとで、ヒステリシス損の指数 $n$ も 2 とみなした近似**。三種の全日効率問題では電圧・周波数は定格一定なので、結局「一定値」として扱えばよい。
→ 理論Wiki「磁気回路」で Ph の出どころ（ヒステリシスループの面積 Wh=∮H dB → Ph=f·Wh）と、上の Bm 一定条件つきの周波数依存を B-H 曲線の図つきで深掘り（H18問3・R01問3）

#### なぜ銅損は負荷率の2乗になるのか

銅損は巻線抵抗の発熱そのもの（$P_c = I^2 R$）。電圧が一定なら電流は皮相電力に比例（三相では $I = S / (\sqrt{3}V)$）なので、
$\frac{I}{I_N} = \frac{S}{S_N} = x \;\Longrightarrow\; P_c = \left(\frac{I}{I_N}\right)^2 P_{cN} = x^2 P_{cN}$
06 / 15
**銅損は負荷率の2乗に比例**
$P_c = x^2 P_{cN},\qquad x = \dfrac{S}{S_N}$
$P_{cN}$: 全負荷銅損（定格電流時の銅損）、$S_N$: 定格容量 [kV·A]。**全負荷銅損と実際の銅損を混同しない**。

| 負荷率 $x$ | 100% | 80% | 60% | 50% | 40% | 20% |
| --- | --- | --- | --- | --- | --- | --- |
| 銅損倍率 $x^2$ | 1.00 | 0.64 | 0.36 | 0.25 | 0.16 | 0.04 |

ここを間違える
負荷が半分なら銅損も半分、ではない。50% 負荷では銅損は 25%。軽負荷の時間帯の銅損は、感覚よりずっと小さくなる。

#### 負荷率は原則 kV·A 基準（力率を掛けない）

負荷率の**本質は電流比** $x = I/I_N$。定格電圧・平衡負荷という通常の条件では、電流は皮相電力に比例するので kV·A どうしの比で取れる。
$x = \frac{I}{I_N} = \frac{\text{負荷の皮相電力}\;[\mathrm{kV\cdot A}]}{\text{定格容量}\;[\mathrm{kV\cdot A}]} = \frac{S}{S_N}$
$x = \tfrac{S\cos\phi}{S_N}$ と力率を掛けるのは**誤り**。
巻線の発熱を決めるのは**電流**であり、三相では $I = S/(\sqrt{3}V)$。電圧が一定なら電流は kV·A に比例するので、負荷率は kV·A どうしの比で取る。**kV·A で与えられた負荷**に力率を掛けてしまうと、同じ電流でも力率が低い時間帯の銅損を過小評価する。
負荷が kW で与えられたときは、先に kV·A へ直す
「力率を掛けない」は **負荷が kV·A（皮相電力）で与えられている場合**の話。問題文が **kW（有効電力）** で与えてきたら、まず $S = P/\cos\phi$ で皮相電力に換算してから $x = S/S_N$ とする。
$x = \frac{S}{S_N} = \frac{P}{S_N \cos\phi}$
（負荷が $P\;[\mathrm{kW}]$ で与えられたときの形）
例: 定格 100 kV·A の変圧器に「40 kW・力率 0.8」の負荷 → $S = 40/0.8 = 50$ kV·A、$x = 0.5$（$40/100 = 0.4$ としない）。**掛けるのではなく割る**のがポイント。
覚え方
**力率は出力 kWh に使う。kV·A 負荷率は銅損に使う。**（kW 与件なら、まず力率で**割って** kV·A にする）

### 通常効率 — ある運転点を kW で評価する

ある負荷率 $x$・力率 $\cos\phi$ の定常的な運転点における効率。**すべて電力 [kW] のまま**扱う。
07 / 15
**通常効率（損失から算定する規約効率）**
$\eta = \dfrac{P_{\mathrm{out}}}{P_{\mathrm{out}} + P_i + x^2 P_{cN}} \times 100\;[\%]$
出力 $P_{\mathrm{out}} = x S_N \cos\phi\;[\mathrm{kW}]$。分母は「出力＋鉄損＋銅損」＝入力。**規約効率**とは入力と出力を直接実測する**実測効率**に対し、別に求めた損失からこの式で算出する効率のこと（「ある負荷状態の効率」という意味ではなく、算出方法を指す用語）。

### 全日効率とは — 1日を kWh で評価する

配電用変圧器のように**負荷が時間帯で大きく変わる**設備では、ある一点の効率では実力を表せない。そこで日負荷曲線をもとに **1日分の電力量 [kWh]** で評価するのが全日効率。
08 / 15
**全日効率**
$\eta_d = \dfrac{W_{\mathrm{out}}}{W_{\mathrm{out}} + W_i + W_c} \times 100\;[\%]$
Wout: 1日の出力電力量、Wi: 1日の鉄損電力量、Wc: 1日の銅損電力量（いずれも kWh）。

| 比較項目 | 通常効率 | 全日効率 |
| --- | --- | --- |
| 評価対象 | ある定常運転点 | 1日全体 |
| 計算に用いる量 | 電力 **[kW]** | 電力量 **[kWh]** |
| 鉄損 | その時点の損失 $P_i$ | 通電時間分を積算 $P_i T_{\mathrm{on}}$ |
| 銅損 | その負荷率での損失 $x^2 P_{cN}$ | 各時間帯を積算 $P_{cN}\sum x_k^2 t_k$ |
| 主な対象 | 電力用変圧器など | **配電用変圧器**など |

いちばん多い誤り
通常効率を求めてから**時間を適当に掛ける**のは誤り。出力・鉄損・銅損をそれぞれ電力量にしてから分母に入れる。鉄損と銅損では「掛ける時間」が違う（鉄損＝通電時間、銅損＝各負荷時間）ので、一括で時間を掛けることはできない。

#### 長い式を一気に覚えない — 3つの箱に分ける

① 出力電力量 $W_{\mathrm{out}}$
$W_{\mathrm{out}} = \sum_k S_k \cos\phi_k\, t_k$
kV·A は皮相電力なので、**負荷に実際に渡した有効電力量**を出すには力率を掛ける。
② 鉄損電力量 $W_i$
$W_i = P_i\, T_{\mathrm{on}}$
$T_{\mathrm{on}}$ は**電圧が加わっている時間**。24時間通電のときだけ $P_i \times 24$。
③ 銅損電力量 $W_c$
$W_c = P_{cN} \sum_k x_k^2\, t_k$
$x_k = S_k / S_N$（力率は掛けない）。各時間帯ごとに2乗してから足す。
↓ 最後に全日効率へ代入
09 / 15
**全日効率（3つの箱を代入した展開式）**
$\eta_d = \dfrac{\sum_k S_k\cos\phi_k t_k}{\sum_k S_k\cos\phi_k t_k + P_i T_{\mathrm{on}} + P_{cN}\sum_k \left(\frac{S_k}{S_N}\right)^2 t_k} \times 100$
この形を丸暗記する必要はない。3つの箱を別々に計算してから、上の 07 / 09 に入れれば同じこと。

#### 24時間タイムライン — 出力・鉄損・銅損はいつ出ているか

鉄損は**電圧が加わっている19時間**ぶん連続して発生し、負荷がゼロの時間帯（14時から19時）でも消えない。銅損は**負荷がある時間だけ**で、しかも高さは負荷率の2乗。電源を切り離した19時から24時は3つとも発生しない。この図の状況なら $W_i = P_i \times 19$ であって $P_i \times 24$ ではない。

### 全日効率の5ステップ解法

1. **各時間帯の出力電力量**を出す — $W_{\mathrm{out},k} = S_k \cos\phi_k\, t_k$（kV·A に力率を掛ける）
2. **合計する** — $W_{\mathrm{out}} = \sum_k W_{\mathrm{out},k}$
3. **鉄損電力量** — $W_i = P_i T_{\mathrm{on}}$（24時間と決めつけず通電時間を確認）
4. **銅損電力量** — $W_c = P_{cN}\sum_k (S_k/S_N)^2 t_k$（負荷率は kV·A 基準・2乗してから足す）
5. **全日効率** — $\eta_d = W_{\mathrm{out}} / (W_{\mathrm{out}} + W_i + W_c) \times 100$（0〜100% に収まるか検算）

### 典型例題（途中式をすべて書く）

例題 2.1.2（全日効率）
**問:** 定格容量 100 kV·A、鉄損 0.6 kW、全負荷銅損 1.5 kW の単相変圧器がある。1日の負荷が「80 kV·A・力率 0.8 で 8 時間」「40 kV·A・力率 0.9 で 8 時間」「残り 8 時間は無負荷」であり、変圧器は**24時間通電**している。全日効率を求めよ。
**Step 1・2 出力電力量**（無負荷の8時間は出力ゼロなので足さない）
$W_{\mathrm{out}} = 80 \times 0.8 \times 8 + 40 \times 0.9 \times 8 = 512 + 288 = 800\;[\mathrm{kWh}]$
**Step 3 鉄損電力量**（無負荷の8時間も通電しているので24時間ぶん）
$W_i = 0.6 \times 24 = 14.4\;[\mathrm{kWh}]$
**Step 4 銅損電力量**（負荷率 $x_1 = 80/100 = 0.8$、$x_2 = 40/100 = 0.4$。力率は掛けない）
$W_c = 1.5\left[\left(\tfrac{80}{100}\right)^2 \times 8 + \left(\tfrac{40}{100}\right)^2 \times 8\right] = 1.5\,[\,0.64 \times 8 + 0.16 \times 8\,] = 1.5 \times 6.4 = 9.6\;[\mathrm{kWh}]$

**検算:** 出力 800 ＋ 損失 24.0 ＝ 入力 824.0 kWh。効率は 0〜100% の範囲に収まっている。損失のうち鉄損が 14.4 kWh と銅損 9.6 kWh を上回るのは、負荷率が低い時間帯が長い配電用変圧器の典型的な姿。 **※この等式は分母を足し直しただけなので必ず成立する（転記ミス検出専用）。**$W_c$ 側は「負荷率に力率を掛けない」「負荷率が半分なら銅損は 1/4」を下の頻出ミス表で別途確認する——力率を掛けてしまうと $W_c$ は 6.47 kWh になるが、この等式も 0〜100% も「鉄損 > 銅損」もすべて通ってしまう。

| 誤り | 正しい考え方 |
| --- | --- |
| kW と kWh を混ぜる | 全日効率では**すべて kWh にそろえる** |
| kV·A × 時間 で出力を求める | **kV·A × 力率 × 時間**（皮相電力のままでは有効電力量にならない） |

| 全負荷銅損をそのまま使う | その時間帯の実銅損は $x^2 P_{cN}$ |

この一文だけ持ち帰る
出力は「**kV·A × 力率 × 時間**」、鉄損は「**一定 × 通電時間**」、銅損は「**全負荷銅損 × 負荷率² × 時間**」。
等価負荷率 — 複数の時間帯を1つにまとめる主線を理解した後の補足（開く）
銅損電力量だけを見れば、変動する負荷を「ある一定の負荷率 $x_e$ で $T$ 時間運転した」と置き換えられる。これが**等価負荷率**。
$x_e = \sqrt{\frac{\sum_k x_k^2 t_k}{T}}, \quad T = \sum_k t_k \qquad\Longrightarrow\qquad W_c = P_{cN}\, x_e^2\, T$
T の取り方を必ず分子とそろえる
$T$ は**等価化する評価期間**で、分子の時間区分の合計 $\textstyle\sum_k t_k$ と必ず一致させる。1日を等価化するなら、無負荷や電源切離しの時間も $x_k = 0$ の区間として数え、$T = 24$ h に含める。**含める区間を変えると $x_e$ の値が変わる**ので、$W_c = P_{cN}x_e^2T$ が元の $P_{cN}\sum x_k^2 t_k$ と一致するのは分子と分母をそろえたときだけ。
定義から分かるとおり、これは**単純平均ではなく二乗平均平方根（RMS）**。銅損が負荷率の2乗で効くので、2乗して平均してから平方根を取る必要がある。
**例:** 100% 負荷で12時間、無負荷で12時間（$T = 24$）のとき
$x_e = \sqrt{\frac{1^2 \times 12 + 0^2 \times 12}{24}} = \sqrt{0.5} \approx 0.707$
単純平均の負荷率は 50% だが、銅損計算上の等価負荷率は約 70.7%。平均で 50% と置いて $0.5^2 = 0.25$ を使うと、銅損を半分に見誤る（正しくは $0.707^2 = 0.5$）。

### 最高効率の条件との橋渡し

**通常効率**が最大になるのは、負荷とともに増える銅損が、一定の鉄損に追いついたとき。
鉄損は水平（負荷によらない）、銅損は放物線（$x^2$ に比例）。**2本が交わる負荷率で効率が最大**になる。最大点の周辺は平らなので、多少ずれても効率はあまり落ちない。一方**軽負荷側では急激に落ちる**（出力が小さいのに鉄損は同じだけ出続けるため）。
10 / 15
**最高効率の条件（通常効率）**
$P_i = P_c = x^2 P_{cN}$
鉄損 ＝ 銅損 のときに最高効率。**電圧・周波数・力率 $\cos\phi$・巻線抵抗を一定として負荷率 $x$ だけを変えたとき**の条件（力率が $x$ とともに変わる場合は出力が $x$ に比例しないので一般には成り立たない）。これを満たす負荷率は $x = \sqrt{P_i / P_{cN}}$。配電用変圧器は軽負荷の時間が長いので、**全負荷より低い負荷率**で効率が最大になるよう設計されることが多い。
全日効率にそのまま当てはめない
「全日効率が最大 ＝ 鉄損電力量 ＝ 銅損電力量」と**無条件に断定してはいけない**。負荷の形（日負荷曲線）が変われば最適点も変わるからである。限定つきなら次のように言える。
同じ負荷パターンを一定倍率で拡大・縮小して全日効率の最大条件を考える場合には、1日の鉄損電力量と1日の銅損電力量が等しくなる点が対応する。
ここで固定しているのは **各時間帯の力率・時間区分の長さ・通電時間・電圧と周波数・鉄損と全負荷銅損（巻線抵抗一定）**。動かすのは負荷の大きさの倍率 $m$ だけ。
なぜ「一定倍率で拡大・縮小」なら Wi = Wc になるのか導出を開く
負荷パターン全体を $m$ 倍する（$S_k \to m S_k$）と、出力電力量は $m$ に比例、銅損電力量は負荷率の2乗で効くので $m^2$ に比例し、鉄損電力量は変わらない。$A = \sum S_k\cos\phi_k t_k$、$B = P_{cN}\sum x_k^2 t_k$ と置くと
$\eta_d(m) = \frac{mA}{mA + W_i + m^2 B}$
分子分母を $mA$ で割ると $\eta_d = 1/\left(1 + \dfrac{W_i}{mA} + \dfrac{mB}{A}\right)$。分母のうち $m$ に依存する2項の和は、相加相乗平均から $2\sqrt{W_i B}/A$ 以上で、等号は $W_i/(mA) = mB/A$ すなわち $m^2 B = W_i$ のとき。$m^2 B$ はそのときの銅損電力量 $W_c$ なので、**$W_i = W_c$** で最大となる。
通常効率の $P_i = P_c$ と形は同じだが、**比べているのは電力 [kW] ではなく電力量 [kWh]**。主線では両者を混同しないこと。

## 8.電圧変動率

**何を求めるか**：負荷をかけたときに二次端子電圧がどれだけ下がるか。まず定義から押さえる。
11 / 15
**電圧変動率の定義**
$\varepsilon = \dfrac{V_{20} - V_2}{V_2}\times 100\;[\%]$
$V_{20}$: 無負荷時の二次電圧、$V_2$: 定格負荷時の二次端子電圧。分母は無負荷電圧ではなく定格負荷時の $V_2$（電験の定義）。
これを等価回路の $p,\ q$ で近似したのが次の式。**近似式**であることに注意（降下が定格電圧に比べて小さいことを使っている）。
12 / 15
**電圧変動率の近似式（遅れ力率／進み力率）**
$\varepsilon \approx p\cos\theta \pm q\sin\theta$
複号は ＋が遅れ力率・−が進み力率。$p$: 百分率抵抗降下 [%]、$q$: 百分率リアクタンス降下 [%]、$\theta$: 力率角。**違いは $q\sin\theta$ の符号だけ**。
— 図2.1.1 電圧変動率のベクトル図（遅れ力率・降下は誇張） —
図の要点は3つ。**①** $I_2r$ は $I_2$ と同方向、**②** $jI_2x$ は $I_2$ より 90° 進み、**③** 端子電圧に効くのは降下の**水平成分（$V_2$ 方向の成分）**だけ。この水平成分を足し合わせると $I_2r\cos\theta + I_2x\sin\theta$ になり、$V_2$ で割って百分率にすると $p\cos\theta + q\sin\theta$ がそのまま出てくる。近似式は「降下ベクトルの水平成分」を読んでいるだけである。
— 図2.1.2 進み力率では jI₂x の水平成分が逆向きになる（降下は誇張） —
進み力率では ε が負になりうる ＝ 負荷をかけた方が電圧が高い
$\varepsilon$ が負とは、定義 $\varepsilon = (V_{20}-V_2)/V_2$ が負、すなわち $V_2 > V_{20}$（負荷時の端子電圧が無負荷時より**高い**）ということ。進み力率（コンデンサ性負荷）では $jI_2x$ の水平成分が $V_2$ と逆を向き、電圧を押し上げる側に働くために起こる。
長距離送電線の軽負荷時に受電端電圧が送電端より上がる**フェランチ効果**と同じ機構。「負荷をかければ必ず電圧は下がる」と思い込んでいると、この符号で失点する。
数値例 — 同じ変圧器でも力率で符号が変わる
**問:** $p = 2\;\%$、$q = 5\;\%$ の変圧器に力率 0.8 の定格負荷をかけた。(1) 遅れ力率のとき (2) 進み力率のときの電圧変動率を求めよ。
$\cos\theta = 0.8$ より $\sin\theta = 0.6$。
$(1)\;\; \varepsilon \approx 2 \times 0.8 + 5 \times 0.6 = 1.6 + 3.0 = 4.6\;[\%]$
$(2)\;\; \varepsilon \approx 2 \times 0.8 - 5 \times 0.6 = 1.6 - 3.0 = -1.4\;[\%]$
(2) は負。**進み力率では端子電圧が無負荷時より上がる**。$q$ が $p$ より大きい変圧器ほど、この符号反転は起こりやすい（実機の変圧器は一般に $q > p$）。
この節の確認問題（1問）
電圧変動率の簡易式は？ε ≈ p·cosθ + q·sinθ（遅れ力率では sinθ が正）

## 9.百分率インピーダンスと短絡電流

**何を求めるか**：変圧器の内部インピーダンスの「大きさの程度」を、容量や電圧が違っても比較できる共通のものさしで表す。
13 / 15
**%Z の定義**
$\%Z = \dfrac{V_s}{V_n}\times 100 = \dfrac{I_n Z_e}{V_n}\times 100\;[\%]$
$V_s$: 二次側を短絡して定格電流を流すのに必要な印加電圧（インピーダンス電圧）、$V_n$: 定格電圧、$I_n$: 定格電流、$Z_e$: 基準側に換算した等価インピーダンス。**いずれも同じ側（一次なら一次）でそろえる**。
つまり %Z は「**定格電流を流したときの内部電圧降下が、定格電圧の何 % か**」。セクション6の短絡試験で得た $R_e,\ X_e$ をそれぞれ百分率にしたものが $p,\ q$ で、%Z はその直角合成になる。
$p = \frac{I_n R_e}{V_n}\times 100,\qquad q = \frac{I_n X_e}{V_n}\times 100 \qquad\Longrightarrow\qquad \%Z = \sqrt{p^2 + q^2}$
したがって **短絡試験 → $R_e,X_e$ → $p,q$ → %Z → 電圧変動率と短絡電流** が1本の線でつながる。$p,q$ はセクション8の電圧変動率でそのまま使う量である。
14 / 15
**短絡電流（簡易式）**
$I_s = \dfrac{100}{\%Z}\, I_n\;[\mathrm{A}]$
%Z = 5 % なら短絡電流は定格の 20 倍。%Z が小さいほど短絡電流は大きい（電圧変動は小さいが遮断器の負担は重い）。
この簡易式が前提にしていること（実系統ではそのまま使えない）
- **変圧器の端子直近で短絡した**場合を想定している
- **上位電源・発電機・ケーブル・母線などのインピーダンスをすべて無視**している（電源を無限大母線とみなしている）
- 実際の系統短絡電流は、変圧器以外のインピーダンスも共通基準容量に換算して**合成してから**計算する。合成インピーダンスは必ず変圧器単独より大きくなるので、この簡易式は実際より大きめの（安全側の）短絡電流を与える

例題 2.1.1（%Z と短絡電流）
**問:** 三相変圧器、定格容量 500 kV·A、二次定格電圧 6.6 kV、%Z = 4.0 % のとき、二次側短絡電流を求めよ（変圧器端子直近での短絡・上位系統のインピーダンスは無視する）。
$I_n = \dfrac{500{\times}10^3}{\sqrt{3}\times 6600} \approx 43.7\;[\mathrm{A}]$
$I_s = \dfrac{100}{4.0}\times 43.7 \approx 1.09\;[\mathrm{kA}]$
三相の定格電流は $I_n = S_N/(\sqrt3 V_n)$。単相の $S_N/V_n$ と混同しない。

### %Z から何が分かるか — 3つに分けて覚える

① 短絡電流の大きさ
%Z が**小さい**ほど短絡電流は**大きい**。$I_s = (100/\%Z)I_n$ より反比例。遮断器の遮断容量を決める。
② 電圧変動率
%Z が小さいほど電圧降下は**小さくなりやすい**。ただし $\varepsilon$ は %Z の大きさだけでは決まらない（次の注意を参照）。
③ 並行運転の負荷分担
%Z が小さい器ほど**多く負担しやすい**。ただし容量も効くので $S_N/z$ の比で判断する。
②には条件がつく — 電圧変動率は %Z だけでは決まらない
電圧変動率は $\varepsilon \approx p\cos\theta \pm q\sin\theta$ で、**抵抗分 $p$・リアクタンス分 $q$・負荷力率**の3つに依存する。%Z が同じでも、$p$ と $q$ の内訳や力率が違えば $\varepsilon$ は変わるし、進み力率なら負にもなる。「%Z が小さい ＝ 電圧変動率も必ず小さい」と短絡させないこと。
実務補足 — 実系統の短絡電流はこの式では出ない試験の主線ではない（開く）
変圧器単体の %Z だけで求めた短絡電流は、電源を無限大母線とみなした**上限側の概算**。実際の系統計算では、共通の基準容量に換算したうえで次をすべて合成する。
- 電源側（上位系統）のインピーダンス
- 発電機のインピーダンス（過渡・次過渡で値が違う）
- ケーブル・架空線のインピーダンス
- 母線・変流器などの機器インピーダンス
- 変圧器が複数ある場合はその合成、および系統構成（母線連絡の開閉状態）

合成インピーダンスは必ず変圧器単独より大きくなるので、**実際の短絡電流は簡易式の値より小さくなる**。遮断器の選定では簡易式で安全側に見積もったうえで、詳細計算で確認する。

## 10.並行運転

**何を求めるか**：2台以上の変圧器を並列につないだとき、それぞれが何 kV·A を負担するか。

### 並行運転の条件

**必須条件（満たさないと循環電流・短絡が起き、運転そのものが成立しない）**
1. **変圧比（巻数比）が等しい** — 違うと無負荷でも巻線間に循環電流が流れる
2. **極性が等しい** — 違うと短絡と同じ状態になる（最も危険）
3. **三相では相順および位相変位（角変位）が等しい** — Y-Y と Y-Δ のように角変位が 30° 違う組は並行運転できない

**分担を適正にする条件（満たさなくても運転はできるが、負担が偏って設備を使い切れない）**
- **%Z（自己容量基準）が等しい** — 等しいと負担が**定格容量に比例**する。違っても運転自体はできるが、%Z の小さい器に負担が偏る（次項の一般式）。ただし「並行運転の条件」を列挙させる設問では %Z 一致も条件に数えるのが通例なので、条件を問われたら落とさないこと
- **抵抗分とリアクタンス分の比（X/R 比＝インピーダンス角）が等しい** — 大きく異なると、分担電流に位相差が生じる。各器の電流の**ベクトル和**が負荷電流なので、位相がずれると合計の皮相電力が各器の和より小さくなり、設備を使い切れない

※ この 2 層の区別（変圧比 → 無負荷の循環電流／%Z → 負荷時の分担の偏り／X/R → 分担電流の位相差）は、**破ったときに起きる現象が層ごとに違う**という意味であって、条件リストから %Z を外してよいという意味ではない。

### 負荷分担 — 「%Z の逆比」だけを覚えてはいけない

並列なので**両器にかかる電圧降下は共通**。よって電流は実インピーダンスの逆比で分かれる。これを各器の自己容量基準の %Z で書き直すと、次の一般式になる。
15 / 15
**並行運転の負担配分（一般式）**
$S_A : S_B = \dfrac{S_{NA}}{z_A} : \dfrac{S_{NB}}{z_B}$
$S_A,S_B$: 各器の負担容量 [kV·A]、$S_{NA},S_{NB}$: 各器の定格容量 [kV·A]、$z_A,z_B$: 各器の %Z [%]（**それぞれ自分の定格容量を基準にした値**）。

| 条件 | 一般式の帰結 | 覚え方 |
| --- | --- | --- |
| **定格容量が同じ**（$S_{NA}=S_{NB}$） | $S_A : S_B = 1/z_A : 1/z_B$ | 負担は **%Z に反比例** |
| **%Z が同じ**（$z_A=z_B$） | $S_A : S_B = S_{NA} : S_{NB}$ | 負担は **定格容量に比例** |
| **両方とも違う** | 一般式 $S_{NA}/z_A : S_{NB}/z_B$ で計算するしかない |   |

点線が各器の**定格容量の枠**、塗りが**実際の負担**。棒の長さは kV·A に比例（同一縮尺）。容量差を無視した式では、小さい方の A に負担が寄って枠を大きくはみ出す。
「%Z に反比例」だけを暗記した人が落ちる穴
**問:** A（100 kV·A・%Z = 4 %）と B（300 kV·A・%Z = 6 %）を並行運転し、合計 300 kV·A の負荷を供給する。各器の負担は？
**正しい計算（一般式）**
$S_A : S_B = \frac{100}{4} : \frac{300}{6} = 25 : 50 = 1 : 2$
$S_A = 300\times\frac{1}{3} = 100$ kV·A（負荷率 100 %）、$S_B = 300\times\frac{2}{3} = 200$ kV·A（負荷率 67 %）。どちらも定格以内。
**誤り（%Z の逆比だけを使った場合）**
$S_A : S_B = \frac{1}{4} : \frac{1}{6} = 3 : 2 \;\Rightarrow\; S_A = 180,\; S_B = 120$
A の負担が 180 kV·A＝定格 100 kV·A に対して 180 % の過負荷という、現実には焼損する答えになる。**容量が違う組み合わせで「%Z の逆比」を使ってはいけない**。
3ケースを同じ式で解く（数値で確認）
いずれも一般式 $S_A : S_B = S_{NA}/z_A : S_{NB}/z_B$ に入れるだけ。**覚える式は1つでよい**。
**例1 定格容量が同じ**（A: 500 kV·A・5 %／B: 500 kV·A・10 %）
$S_A : S_B = \frac{500}{5} : \frac{500}{10} = 100 : 50 = 2 : 1$
容量が同じなので **%Z の逆比**になる。%Z が小さい A が2倍負担する。
**例2 %Z が同じ**（A: 500 kV·A・5 %／B: 1000 kV·A・5 %）
$S_A : S_B = \frac{500}{5} : \frac{1000}{5} = 100 : 200 = 1 : 2$
%Z が同じなので **定格容量の比**になる。両器とも同じ負荷率になり、設備を無駄なく使える。
**例3 容量も %Z も違う**（A: 500 kV·A・5 %／B: 1000 kV·A・10 %）
$S_A : S_B = \frac{500}{5} : \frac{1000}{10} = 100 : 100 = 1 : 1$
容量が2倍でも %Z が2倍なら、負担容量は同じになる。ここで「%Z の逆比」だけを使うと $1/5 : 1/10 = 2:1$ となり、**A が2倍負担するという逆の答え**が出てしまう。容量と %Z の**両方**を見ること。
確認 — 2つの特別な場合
**(1) 同容量・%Z 違い:** A（100 kV·A・4 %）、B（100 kV·A・5 %）、負荷 90 kV·A。
$S_A : S_B = \frac{100}{4} : \frac{100}{5} = 25 : 20 = 5 : 4 \;\Rightarrow\; S_A = 50,\; S_B = 40\;[\mathrm{kV\cdot A}]$
%Z が小さい A の方が多く負担する（インピーダンスが小さい＝電流が流れやすい）。
**(2) 同 %Z・容量違い:** A（200 kV·A・5 %）、B（100 kV·A・5 %）、負荷 150 kV·A。

## 11.V結線・単巻変圧器（頻出小論点）

## 12.単相3台のΔ-Δで1台故障 → V結線運転

まず覚える結論（3つ）
- **三相供給は続けられる**。線間電圧は3つとも得られる（これがΔ-Δ結線の代表的な利点）。
- **供給できる最大の三相皮相電力（バンク容量 [kV·A]）**が故障前の 1/√3 ≈ 57.7% に制限される（$\sqrt{3}S_n \div 3S_n$）。制限しているのは巻線電流なので、kW ではなく kV·A で効く。故障前の負荷皮相電力がバンク定格の 57.7% 以下なら落とす必要はない。
- 残った2台の合計容量に対する利用率は √3/2 ≈ 86.6%。**57.7% と 86.6% は分母が違うだけ**（Δ3台基準か、残り2台基準か）。

成立条件は **同一定格2台・平衡三相負荷・正しい極性と相順**。不平衡負荷では各器の巻線電流を個別に確認する。

### 57.7 % と 86.6 % — 分子は同じ、違うのは分母だけ

2つの割合は**まったく同じ出力 $\sqrt3\,VI$ を、違うものと比べている**だけ。取り違えの原因は分母なので、並べて確認する。
57.7 %
$\frac{\sqrt3\,VI}{3VI} = \frac{1}{\sqrt3} \approx 0.577$
分母＝正常なΔ結線**3台**の合計容量
「故障前と比べて何 % 供給できるか」。**故障前のバンク定格が基準**。
86.6 %
$\frac{\sqrt3\,VI}{2VI} = \frac{\sqrt3}{2} \approx 0.866$
分母＝いま使っている**2台**の定格容量合計
「残った設備をどれだけ使い切れているか」＝**利用率**。
なぜ 2 台なのに 100 % 取り出せないのか
2台の定格容量の合計は $2VI$ なのに、三相として取り出せるのは $\sqrt3\,VI$ しかない。理由は**1台ずつの中で、巻線電圧と巻線電流の位相が 30° ずれる**ことにある。V結線では各器の巻線電圧が線間電圧そのもの・巻線電流が線電流そのものになるが、この2つは同相にならず、負荷力率が 1 でも 30° ずれる。だから各器が送れる有効電力は $VI\cos(30^\circ \mp \theta)$ にとどまり、力率1でも1台あたり $VI\cos 30^\circ = 0.866\,VI$。2台合計で $2VI\cos 30^\circ = \sqrt3\,VI$（一般には $\sqrt3\,VI\cos\theta$）。この $\cos 30^\circ = 0.866$ が目減り分であり、これが利用率 86.6 % の正体である（各器の分担は下の「2台の負担」で詳述）。
1台を切り離しても b-c 間の電圧は $\dot V_{bc} = -(\dot V_{ab}+\dot V_{ca})$ として現れる。**制約は電圧ではなく巻線電流**（実負荷では電圧降下の分だけ不平衡が出る）。
なぜ 57.7% なのか（√3 の出どころ）導出を開く
**Δ-Δ（故障前）**：各変圧器は線間電圧 $V_L$ を受け、巻線電流は相電流 $I_p = I_L/\sqrt{3}$。1台の定格を $S_n = V_L I_p$ とすれば
$S_\Delta = 3 S_n = 3 V_L \dfrac{I_L}{\sqrt{3}} = \sqrt{3}\,V_L I_L$
**V-V（故障後）**：巻線が2辺しかないので、巻線電流は線電流そのもの（$1/\sqrt{3}$ に分かれる相手がいない）。定格電流 $I_n$ を超えられないので $I_L \le I_n$、したがって
$S_V = \sqrt{3}\,V_L I_L \le \sqrt{3}\,V_L I_n = \sqrt{3}\,S_n$
よって $\dfrac{S_V}{S_\Delta} = \dfrac{\sqrt{3}S_n}{3S_n} = \dfrac{1}{\sqrt{3}} \approx 0.577$、$\dfrac{S_V}{2S_n} = \dfrac{\sqrt{3}}{2} \approx 0.866$。**台数が 3→2 に減ったから 2/3 になる、ではない**のが要点。
2台の負担 — kV·A は等しいが、有効電力は偏る差がつく論点
**2台の皮相電力と巻線電流は等しい**：どちらも線間電圧 $V_L$ を受け線電流 $I_L$ を流すので $V_L I_L$ で同じ。したがって同一仕様の器なら銅損（$I^2R$）もほぼ等しく、発熱・温度上昇に大きな差はつかない（厳密には巻線抵抗の器差・励磁電流・冷却条件があるので完全一致ではない）。
異なるのは**個別の力率と有効・無効電力の分担**。負荷力率角 $\theta$（遅れ）のとき、各器の**有効電力係数** $P_i/(V_L I_L)$ は $\cos(30^\circ-\theta)$ と $\cos(30^\circ+\theta)$ に分かれる（力率の大きさはこの絶対値。進み・遅れと電力の向きは別に判定する）。無効電力側は $Q_i = V_L I_L \sin(\theta \mp 30^\circ)$ で同様に偏る。
- $\cos\theta = 1$（$\theta=0$）→ 大きさは2台とも $\cos 30^\circ = 0.866$（一方が遅れ・他方が進みで、無効電力は互いに打ち消し合う）。**有効電力の分担が等しくなるのはこの場合だけ**
- $\cos\theta = 0.866$（$\theta=30^\circ$）→ 一方は 1.0、他方は 0.5
- $\theta > 60^\circ$（遅れ力率 0.5 未満）→ $\cos(30^\circ+\theta) < 0$ となり、理想変圧器で考えると一方の有効電力の向きが逆になる（このとき他方が負荷合計より大きい有効電力を送り、その差分が逆向きの器を通って戻る。**負荷全体が発電に転じるわけではなく、合計は変わらない**）

合計は $V_L I_L\{\cos(30^\circ-\theta)+\cos(30^\circ+\theta)\} = \sqrt{3}\,V_L I_L\cos\theta$ で三相出力に一致する。**どちらの器がどちらの力率になるかは相順・残存した2辺・電流の向きの取り方で入れ替わる**ので、結線図を見ずに決めつけない。

- **Δの閉ループが消える** → 第3高調波（triplen）励磁電流をΔ内に循環させておけなくなる。その結果がどこに現れるか（線電流・電圧波形）は電源インピーダンス・鉄心構造・接地条件によるが、**Δ-Δの長所を1つ失う**のは確か。

無負荷試験と短絡試験を取り違えないために、問題文の最初に確認する2点は？①**二次側は開放か短絡か** → ②**電圧は定格か低電圧か**。二次開放・定格電圧なら**無負荷試験**（鉄損・r₀・x₀）、二次短絡・低電圧なら**短絡試験**（銅損・Z_e・R_e・X_e・%Z）。「求めるのは損失か・定数か・電流か」は判別材料にならない——どちらの試験でも損失・定数・電流は出るので、これは求める量の確認であって試験の判別ではない

## 14.1分復習（通し）

各節の末尾に置いてある確認問題を、ここに全部まとめてある（同じ問題・同じ答え）。 節ごとに解くのは**解説を読んだ直後に思い出せるか**を試すため、ここに通しがあるのは**試験直前に全体を1分で流す**ため。答えは畳んであるので、開く前に必ず自分で言ってみる。
2. 理想変圧器と巻数比
巻数比 a と電圧・電流の関係は？a = N₁/N₂ = V₁/V₂ = I₂/I₁（電流は巻数比の逆比）
3. 誘導起電力と磁束
E = 4.44 f N Φm の 4.44 はどこから来る？√2·π ≈ 4.44。Φ = Φm sinωt を微分すると起電力の**最大値**が 2πfNΦm になり、実効値にするため √2 で割る（2π/√2 = √2π）。**Φm は磁束の最大値**であって実効値ではない、が取り違えの元
電圧を変えずに周波数だけ下げると何が起きる？Φm ∝ V/f なので**磁束が増える** → 鉄心が飽和に近づく → **励磁電流が急増** → 発熱・うなり・保護動作。だからインバータで可変速駆動するときは V/f を一定に保つ
4. 実際の変圧器と等価回路
等価回路の「直列4素子」と「並列の励磁回路」は、それぞれ何を表し、どちらの試験で求まる？直列 r₁, x₁, r₂′, x₂′ ＝ **銅損と電圧降下** → **短絡試験**／並列 r₀, x₀ ＝ **鉄損と磁化電流** → **無負荷試験**。ただし短絡試験で出るのは和 R_e = r₁+r₂′、X_e = x₁+x₂′ だけで、r₁ と r₂′ を分けるには直流抵抗測定が要る（三種は和のままで解ける）。電圧変動率・効率・短絡電流・並行運転は、すべてこの1枚から導かれる
二次側の量を一次側に換算するとき、何を何倍する？（巻数比 a = N₁/N₂）インピーダンスは **a² 倍**（r₂′ = a²r₂・x₂′ = a²x₂）、電圧は **a 倍**、電流は **1/a 倍**。抵抗まで a 倍にしてしまうのが失点源。換算しても**損失は変わらない**ことで検算できる（a²r₂ × (I₂/a)² = r₂I₂²）
5. 無負荷試験（開放試験）
無負荷試験で Iw・Iμ・r₀・x₀ を出す順番と式は？①Iw = P₀/V₁（電力計 ≒ 鉄損・**電圧と同相の成分**）→ ②Iμ = √(I₀²−Iw²)（**直角合成**）→ ③r₀ = V₁/Iw（＝V₁²/P₀）→ ④x₀ = V₁/Iμ。短絡試験が**インピーダンスを分解**するのに対し、無負荷試験は**電流を分解**する。無負荷力率 cosθ₀ = Iw/I₀ は磁化分が主なので非常に低い（0.1〜0.3 程度）
6. 短絡試験（インピーダンス試験）
短絡試験で Ze・Re・Xe を出す順番と式は？①Ze = Vs/Is（**斜辺**）→ ②Re = Ps/Is²（電力計 ≒ 銅損・**電流基準**）→ ③Xe = √(Ze²−Re²)（**直角合成**）。②で Ps/Vs² としない、③で Ze−Re としないの2点が失点源
短絡試験の測定値だけで検算するには？cosθ = Ps/(VsIs) を出し、Re = Ze·cosθ、Xe = Ze·sinθ で再計算する。三平方とは**別の計算経路**なので途中の算術ミスを拾える。ただし2経路は代数的には同じ式（Ze·cosθ ≡ Ps/Is²）なので、**立式そのものの誤りは拾えない**
短絡試験の与件に定格が無いとき、何が求められて何が求められない？求められる＝Ze・Re・Xe（測定値だけで出る）／**求められない**＝%Z・電圧変動率・短絡電流（定格電圧 Vn または定格容量 SN が要る）。「定格電流を流した」だけでは Vn は確定しない
7. 損失・通常効率・全日効率
変圧器の最高効率の条件は？鉄損 = 銅損（P_i = x²P_cN）。そのときの負荷率 x = √(P_i / P_cN)。分母は全負荷銅損であって、そのときの実銅損ではない
通常効率と全日効率は何が違う？通常効率＝ある運転点を **kW の比**で評価（η = Pout /(Pout+Pi+x²PcN)）／全日効率＝1日全体を **kWh の比**で評価（ηd = Wout /(Wout+Wi+Wc)）。効率自体はどちらも無次元で [%] 表示。**主に重視される用途**が通常効率＝電力用変圧器、全日効率＝負荷変動の大きい配電用変圧器（同じ1台について両方を評価でき、対象機器が排他的に分かれるわけではない）
全日効率は kW と kWh のどちらで計算する？**kWh（電力量）**。出力・鉄損・銅損をそれぞれ電力量に直してから分母に入れる。通常効率を求めてから時間を掛けても全日効率にはならない（鉄損と銅損では掛ける時間が違うため）
出力電力量の式は？Wout = Σ Sk·cosφk·tk [kWh]。kV·A は皮相電力なので、有効電力量にするには**力率を掛ける**。無負荷の時間帯は出力ゼロなので足さない
鉄損電力量の式は？Wi = Pi × Ton [kWh]。Ton は**電圧が加わっている時間**。24時間通電のときだけ Pi×24 で、「12時間だけ電源に接続」ならその通電時間を使う
銅損電力量の式は？Wc = PcN × Σ xk²·tk [kWh]（xk = Sk/SN）。各時間帯ごとに**2乗してから足す**。全負荷銅損 PcN をそのまま使うのではない
50% 負荷のとき銅損は全負荷銅損の何%？**25%**（x² = 0.5² = 0.25）。半分ではない。銅損は I²R で、電圧一定なら I は kV·A に比例するので負荷率の2乗で効く
出力の計算には力率を使うのに、負荷率には原則使わないのはなぜ？出力は**有効電力**なので kV·A に力率を掛ける。一方、銅損を決めるのは**巻線電流**で、負荷率の本質は x = I/IN。三相では I = S/(√3V) なので、電圧一定なら電流は kV·A に比例し x = S/SN（kV·A どうしの比）で取れる。力率を掛けると低力率の時間帯の銅損を過小評価する。合言葉は「力率は出力 kWh に、kV·A 負荷率は銅損に」
負荷が「40 kW・力率0.8」と kW で与えられたら負荷率は？（定格 100 kV·A）**x = 0.5**。負荷率は皮相電力の比なので、まず S = P/cosφ = 40/0.8 = **50 kV·A** に換算してから x = 50/100 = 0.5。40/100 = 0.4 としない。「力率を掛けない」のは負荷が kV·A で与えられたときの話で、kW 与件では力率で**割って** kV·A に直す
無負荷通電中（電源は入・負荷ゼロ）に発生する損失は？**鉄損だけ**。銅損は三種の計算ではほぼ 0 として扱う（励磁電流によるわずかな銅損は無視する前提）
電源切離し中（開放）に発生する損失は？**鉄損も銅損も発生しない**。「無負荷」と「電源切離し」を混同すると、鉄損電力量の通電時間を取り違える
全日効率の計算順序（5ステップ）は？①各時間帯の出力電力量 Sk·cosφk·tk → ②合計して Wout → ③鉄損電力量 Wi = Pi·Ton → ④銅損電力量 Wc = PcN·Σxk²tk → ⑤ηd = Wout/(Wout+Wi+Wc)×100。最後に 0〜100% に収まるか検算する
8. 電圧変動率
電圧変動率の簡易式は？ε ≈ p·cosθ + q·sinθ（遅れ力率では sinθ が正）
9. 百分率インピーダンスと短絡電流
%Z = 5% のとき短絡電流は定格の何倍？20倍（I_s = (100/%Z)·I_n）
10. 並行運転
並行運転の必須条件は？（満たさないと運転そのものが成立しない側）①**変圧比（巻数比）が等しい**（違うと無負荷でも循環電流）②**極性が等しい**（違うと短絡と同じ状態・最も危険）③三相では**相順と位相変位（角変位）が等しい**（Y-Y と Y-Δ は 30° ずれるので組めない）。条件を列挙させる設問では %Z 一致も数えるのが通例なので落とさない
負担配分の一般式は？S_A : S_B = **S_NA/z_A : S_NB/z_B**（S_N＝各器の定格容量、z＝**自己容量基準**の %Z）。並列なので**電圧降下が共通**→ 電流は実インピーダンスの逆比、を %Z で書き直した形。**覚える式はこれ1つでよい**（各器のインピーダンス角が等しい前提。角度がずれると単純な足し算では配れない）
「%Z の逆比」で解いてよいのはどんなとき？**自己容量基準の %Z をそのまま**逆比にしてよいのは**定格容量が等しいときだけ**。共通の基準容量に換算した %Z なら容量が違っても常に逆比（一般式と同じことを言っている）。自己容量基準のまま逆比を使うと過負荷の答えが出る（A 100 kV·A・4 % ＋ B 300 kV·A・6 % で 300 kV·A を分担 → 正しくは 100 と 200 kV·A、%Z 逆比では A が 180 kV·A ＝ 定格の 180 %）。逆に %Z が等しいときは**定格容量の比**になる
11. V結線・単巻変圧器
単巻変圧器の自己容量（等価容量）は？自己容量 ＝ 負荷容量 × **(V_h − V_l)/V_h**（V_h: 高圧側電圧、V_l: 低圧側電圧。昇圧でも降圧でも同じ式）。**変圧比が1に近いほど**小さな自己容量で大きな負荷容量を扱える（小型・高効率）。欠点は**一次と二次が絶縁されない**こと
V結線の 86.6 % と 57.7 % は、それぞれ何に対する比？86.6 %（√3/2）＝**使用中2台の定格合計 2S₁** に対する利用率／57.7 %（1/√3）＝**Δ結線3台の合計容量 3S₁** に対する出力比。どちらも分子は同じ √3S₁ で、違うのは分母
12. Δ-Δ 1台故障 → V結線運転
V結線の出力と利用率は？出力 = √3 × 単器容量。利用率 √3/2 ≈ 86.6%（Δ結線3台比の出力は 57.7%）
Δ-Δ の1台が故障したら出力は何%になる？1/√3 ≈ 57.7%（2/3 = 66.7% ではない）。巻線電流が線電流そのものになり √3 倍の負担になるため
V結線で線間電圧が3つとも得られるのはなぜ？3つの線間電圧の和はゼロ（V̇ab+V̇bc+V̇ca=0）なので、2つを2台で作れば残り1つは V̇bc=−(V̇ab+V̇ca) として定まる（実負荷では電圧降下の分だけ不平衡が出る）
V結線の2台で「等しいもの」と「偏るもの」は？等しい＝皮相電力 V_L·I_L と巻線電流（同一仕様器なら損失・温度上昇もほぼ同等）／偏る＝個別力率と有効・無効電力の分担（有効電力係数は cos(30°−θ) と cos(30°+θ)）。有効分担が等しいのは力率1のときだけ
