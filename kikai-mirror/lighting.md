## 2.計算法則00球光源の全光束 $F = 4\pi I$ 均等放射の点光源。全立体角 4π [sr] × 光度 I。01逆二乗の法則 $E = \dfrac{I}{r^2}$ 点光源から距離 r の面の照度（垂直入射時）。02余弦の法則 $E = \dfrac{I\cos\theta}{r^2}$ θ: 法線と入射光のなす角。理解を深める — 照度が逆二乗になる理由は理論のクーロン電界と同じ幾何

点光源の照度  $E = \dfrac{I}{r^2}$  が距離の2乗に反比例するのは、照明だけの特別な法則ではない。理論の静電気で学ぶ点電荷の電界  $E = \dfrac{Q}{4\pi\varepsilon_0 r^2}$  が逆二乗になるのとまったく同じ幾何学的な理由による。どちらも点源から出たもの（光は光束  $F$ 、電荷は電気力線）が四方八方へ広がり、距離  $r$  の球面（表面積  $4\pi r^2$ ）に一様に分配される。そのため単位面積あたりの密度が  $1/r^2$  で薄まる。「総量は一定のまま、広がる面積が  $r^2$  で増える」——これが逆二乗則の正体。

立体角  $\omega$  を使うと光度は  $I = \dfrac{F}{\omega}$ （単位立体角あたりの光束）と定義され、半径  $r$  の球面が立体角  $\omega$  から切り取る面積は  $A = \omega r^2$ 。その面に届く光束  $F = I\omega$  をこの面積で割れば  $E = \dfrac{F}{A} = \dfrac{I\omega}{\omega r^2} = \dfrac{I}{r^2}$  となり、逆二乗則が立体角から自然に導かれる。電気力線が球面を貫く本数（電束）から電界を求めるガウスの法則と発想は完全に同型で、照度の逆二乗は理論の電気力線・クーロンの法則に還元できる。

## 3.輝度と光束発散度 — 完全拡散面

結論から：輝度  $L$  は「見かけの面積あたりの光度」、光束発散度  $M$  は「面から出ていく光束の密度」。 完全拡散面ならこの2つは  $M = \pi L$  で結ばれる。4π ではなく π が入るところで落としやすい。

出題実績（本Wikiの過去問台帳・R3〜R8上 の10回で照明 12 件）: 主戦場は逆二乗と余弦の法則（8 件）で、 このセクションが直接効くのは 3 件（R6上 問17b 球形光源の輝度・R7下 問17a 直線光源の光束発散度・R7下 問17b 無限長の直線光源の直下照度）。それより前の H29 問17a（円板光源の輝度）も同じ型である。 R7下 問17b は、逆二乗ではなく距離の1乗に反比例する（下の「無限長の直線光源」）。セクション2 を仕上げてからここへ来る順番が得点効率がよい。05輝度 $L = \dfrac{I}{A'}\;[\mathrm{cd/m^2}]$  $A'$  は見る方向への投影面積（＝見かけの面積）で、表面積ではない。球形光源なら投影は円なので  $A' = \pi D^2/4$ （直径  $D$  の円の面積）。 表面積  $\pi D^2$  を使うと4倍小さく出る。逆二乗の法則の  $r$ （光源から受照点までの距離）とは別物なので、同じ問題で混ぜない。06光束発散度 $M = \dfrac{F}{A}\;[\mathrm{lm/m^2}]$  $A$  は光を出している面の実面積（直径  $D$  の球なら  $4\pi (D/2)^2 = \pi D^2$ 、直径  $d$ ・長さ  $l$  の円筒なら側面  $\pi d l$ ）。 照度  $E$  と単位は同じ [lm/m²] だが、E は入ってくる光・M は出ていく光で向きが逆。07完全拡散面（ランバート面） $M = \pi L \;,\qquad M = \rho E$ どの方向から見ても輝度が同じ面が完全拡散面。反射面では入射照度  $E$  のうち反射率  $\rho$  ぶんが出ていくので  $M = \rho E$ 、 したがって  $L = \dfrac{\rho E}{\pi}$ 。π で割るのを落とすと 3.14 倍ずれる。例題 4.1.3（球形光源の光度・輝度・直下照度）

問: 全光束  $F = 12\,000\;\mathrm{lm}$ 、直径  $D = 0.3\;\mathrm{m}$  の完全拡散性で均等放射する球形光源がある。(a) 光度　(b) 輝度　(c) 床からの高さ 2.5 m に吊ったときの直下の水平面照度　を求めよ。解答を開く自分で解いてから

(a) 均等放射なので全立体角  $4\pi$  [sr] で割る。 $I = \dfrac{F}{4\pi} = \dfrac{12\,000}{4\pi} \approx 955\;[\mathrm{cd}]$

(b) 球を横から見ると円に見えるので、投影面積は  $\pi D^2/4$ 。 $A' = \dfrac{\pi \times 0.3^2}{4} \approx 0.0707\;[\mathrm{m^2}] \quad\Rightarrow\quad L = \dfrac{955}{0.0707} \approx 1.35\times10^{4}\;[\mathrm{cd/m^2}]$

(c) 直下は垂直入射なので逆二乗の法則そのまま。 $E = \dfrac{I}{h^2} = \dfrac{955}{2.5^2} \approx 153\;[\mathrm{lx}]$

整合の確認：球の表面積は  $\pi D^2 \approx 0.283$  m² なので $M = F/A = 12\,000/0.283 \approx 4.24\times10^{4}$  lm/m²。一方  $\pi L = \pi \times 1.35\times10^{4} \approx 4.24\times10^{4}$  で一致する。

ただしこれは独立な検算ではない。 $M = 4\pi I/(\pi D^2) = 4I/D^2$  と  $\pi L = \pi I/(\pi D^2/4) = 4I/D^2$  は代数的に同じ式なので、「投影面積を  $\pi D^2/4$  に取ったこと」と「 $M=\pi L$ 」が整合していることを見ているだけである。 なお  $M = \pi L$  が使えるのは完全拡散（ランバート）面のときだけで、「均等放射」だけでは足りない。 均等放射＝どの向きにも光度が同じ、完全拡散＝どの向きから見ても輝度が同じ。球ではこの2つは一致する。ここで落とす3点
- 輝度に表面積を使う — 輝度は見かけ（投影）の面積。球なら  $\pi D^2/4$ 。表面積  $\pi D^2$  を使うと4倍小さい
-  $M = \pi L$  を  $M = 4\pi L$  と書く —  $4\pi$  が出るのは全光束と光度の関係  $F = 4\pi I$  のほう。混同しない
- 反射面で  $L = \rho E$  としてしまう — 正しくは  $L = \rho E/\pi$ 。 $\rho E$  は光束発散度 M であって輝度ではない

### 直線（円筒）光源 — 投影面積は長方形

結論から：直管形の光源でも手順は球と同じで、変わるのは「実面積」と「投影面積」の形だけ。 直径  $d$ ・長さ  $l$  の円筒なら、光を出す実面積は側面  $\pi d l$ 、真横（真下）から見た投影面積は長方形  $d\,l$  である。 $\pi$  が付くのは実面積のほうだけで、投影は付かない。円筒光源の3ステップ

全光束  $F$  の完全拡散性の円筒光源について、軸に直角な向き（真下）を見る。 $M = \dfrac{F}{\pi d l} \;\longrightarrow\; L = \dfrac{M}{\pi} = \dfrac{F}{\pi^2 d l} \;\longrightarrow\; I_{\perp} = L \times (d\,l) = \dfrac{F}{\pi^{2}}$

光源の長さが距離に比べて十分短ければ、点光源とみなして  $E = I_{\perp}/h^2$ （直下）、傾けば  $\cos\theta$  を掛ける。 長さが距離に比べて無視できないときは逆二乗にならない（下の例題の寸法では、長さ方向に積分した厳密値より約6%大きく出る）。試験では問題文の指示（「点光源とみなす」など）に従う。球で同じ手順を踏むと  $I = L\pi (D/2)^2 = F/(4\pi)$  に戻るので、手順そのものは公式00 と同じものである。例題 4.1.4（直管光源の直下照度）

問: 全光束  $F = 3000\;\mathrm{lm}$ 、直径  $d = 0.03\;\mathrm{m}$ 、長さ  $l = 1.2\;\mathrm{m}$  の 完全拡散性の直管光源を、床から  $h = 2.0\;\mathrm{m}$  の高さに水平に取り付けた。光源表面の光束発散度・輝度と、真下の床の照度（点光源とみなす）を求めよ。解答を開く自分で解いてから $M = \dfrac{3000}{\pi \times 0.03 \times 1.2} \approx 2.65\times10^{4}\;[\mathrm{lm/m^2}]$  $L = \dfrac{M}{\pi} \approx 8.44\times10^{3}\;[\mathrm{cd/m^2}] \quad,\quad I_{\perp} = L \times (0.03\times1.2) \approx 304\;[\mathrm{cd}]$  $E = \dfrac{I_{\perp}}{h^2} = \dfrac{304}{2.0^2} \approx 76\;[\mathrm{lx}]$

検算： $I_{\perp} = F/\pi^2 = 3000/9.87 \approx 304$  cd。 $d$  と  $l$  が約分で消えるので、真下の光度は寸法によらず全光束だけで決まる（完全拡散の円筒に限る）。 桁が合わなければ、投影面積に  $\pi$  を付けてしまっている可能性が高い。

M・L は光源表面の量で、床の量ではない。床の光束発散度・輝度は、床の反射率が無いと求まらない（例題4.1.5 の  $M = \rho E$ ）。無限長の直線光源 — 照度は距離の1乗に反比例

光源が距離に比べて十分長く、無限長とみなすときは、点光源の近似は使えない。 単位長さあたりの光束を  $F'$ 〔lm/m〕とすると、完全拡散の円筒では、軸に直角な向きの単位長さあたりの光度が  $I'_{\perp} = F'/\pi^2$ 〔cd/m〕になる（上の  $I_{\perp} = F/\pi^2$  を単位長さあたりにしたもの）。 真下の水平面照度は、長さ方向に積分して次のとおり。 $E_h = \dfrac{\pi I'_{\perp}}{2h} = \dfrac{F'}{2\pi h}\;[\mathrm{lx}]$

距離  $h$  の1乗に反比例し、2乗ではない。点光源の逆二乗をそのまま当てはめない。導出を開く長さ方向の積分

光源の微小部分  $dx$  から真下の点へ向かう向きが、軸に直角な面から角  $\varphi$  だけ傾くとする。 その向きから見た投影面積は  $\cos\varphi$  倍になるので、光度は  $I'_{\perp}\cos\varphi\,dx$ 。 距離は  $r = h/\cos\varphi$ 、床への入射角も  $\varphi$  で、 $x = h\tan\varphi$  から  $dx = h\,d\varphi/\cos^2\varphi$ 。 $dE_h = \dfrac{I'_{\perp}\cos\varphi\,dx}{r^2}\cos\varphi = \dfrac{I'_{\perp}}{h}\cos^2\varphi\,d\varphi \;\Longrightarrow\; E_h = \dfrac{I'_{\perp}}{h}\int_{-\pi/2}^{\pi/2}\cos^2\varphi\,d\varphi = \dfrac{\pi I'_{\perp}}{2h}$ 本試験 R7下 問17（無限長直線光源の光束発散度と直下照度）
