ミクロ（なぜ）：電動機運転（0＜s＜1）で、同期速度 Nₛ で移動する回転磁界に対し回転子導体は N（＜Nₛ）で遅れて動く。この相対速度が磁束を切って e＝Blv の起電力と誘導電流 I₂（短絡二次回路に流れる・図の●印＝紙面手前向き）を生み、F＝BI₂L の力が磁界を追う向きに働いてトルクになる。追いつくと相対速度がゼロになり I₂ もトルクも消える。
🔬 ミクロの因果（なぜすべりが必要か）
1. **固定子の三相電流が回転磁界**を作る（同期速度 $N_s = \dfrac{120f}{p}$ で回転）
2. **回転子導体は Nₛ より遅く回り置き去られる** → 相対速度で磁束を切る（すべり $s = \dfrac{N_s - N}{N_s}$）
3. 電磁誘導 $e = Blv$ で短絡二次回路に**誘導電流 I₂** が流れる（回転子周波数 $f_2 = s f_1$）
4. 結果、$F = B I_2 L$ の力が磁界を追う向きに働き**トルク発生**。同期速度に追いつくと $I_2 = 0$ でトルク消滅 → 必ず $s > 0$ で運転

## 1.動作原理

三相交流を巻線に流すと 固定子内に回転磁界が生じる。この磁界が回転子導体を切り、電磁誘導によって回転子に電流が誘起される。電流と磁束の相互作用（フレミング左手の法則）によりトルクが発生し、回転子は磁界と同方向に回転する。
電動機として運転するとき、回転子の速度は 常に同期速度より小さい（外力で同期速度以上に回すと s < 0 の誘導発電機になる）。同速になると磁束を切らず誘導電流が消えるため、トルクもゼロとなる。この速度差を 滑り といい、誘導機の動作の根幹を成す。
理解を深める — トルク発生を理論（電磁誘導＋電磁力）に還元する
誘導機のトルクは、理論の二つの原理が連鎖して生まれる。まず **電磁誘導**：同期速度で回る回転磁界が、それより遅い回転子の導体を相対的に切る。導体1本が鎖交する磁束 $\Phi$ が変化するため、ファラデーの法則 $e=-N\dfrac{d\Phi}{dt}$ により回転子導体に誘導起電力が生じ、短絡された二次回路に誘導電流 $I_2$ が流れる。
次に **電磁力**：その電流 $I_2$ が磁束密度 $B$ の回転磁界中に置かれるので、フレミング左手の法則に従う力 $F=B\,I_2\,L$ を受ける。この力が回転子を磁界と同方向へ引きずり、半径を掛けた $T=F\,r$ がトルクになる。
**「滑りが無いとトルクが消える」**理由もここに還元できる。回転子が同期速度に達すると相対速度がゼロ、つまり導体が切る磁束が変化しなくなり $\dfrac{d\Phi}{dt}=0$。電磁誘導が止まって $I_2=0$ となり、力 $F=B\,I_2\,L=0$、トルクもゼロになる。だから誘導機は必ず滑り $s>0$ で運転する。回転子周波数 $f_2=s f_1$ が $d\Phi/dt$ の速さそのものを表す点に注目すると、滑りが誘導起電力の源だと一気に腑に落ちる。
→ 理論Wiki「電磁誘導（ファラデー・レンツの法則）」で e=-dΦ/dt の原理と、フレミング左手の電磁力 F=BIL を深掘り

## 2.等価回路と電力の流れ

一相分の T 形等価回路は次の通り。一次側に $r_1, jx_1$、励磁回路に $r_0, jx_0$、二次側に $jx_2'$ と $r_2'/s$ を持つ。**滑り s が分母にある二次抵抗が誘導機の本質** であり、機械的出力は $r_2'(1-s)/s$ で表される負荷抵抗が消費する電力に相当する。
— 図1.2.2 三相誘導電動機 一相分の T形等価回路（一次換算） —
重要な比率（覚えよう）
二次入力 $P_2$・二次銅損 $P_{c2}$・機械的出力 $P_m$ の比は、滑りだけで決まる:
$P_2 : P_{c2} : P_m \;=\; 1 : s : (1-s)$
この関係は B 問題で頻出。1 つでも与えられれば残り 2 つが即座に求まる。
03 / 07
**二次銅損 / 二次入力**
$\dfrac{P_{c2}}{P_2} = s \quad,\quad \dfrac{P_m}{P_2} = 1-s$
効率や出力計算で軸となる関係。
04 / 07
**トルクへの換算（同期ワット）**
$T = \dfrac{P_2}{\omega_s} = \dfrac{P_m}{\omega}$
二次入力 $P_2$ を**同期**角速度 $\omega_s$ で割るとトルクになる。これが $P_2$ を **同期ワット**と呼ぶ理由。機械的出力 $P_m$ を**実際の**回転角速度 $\omega$ で割っても同じ値になる（$P_m=(1-s)P_2$ と $\omega=(1-s)\omega_s$ の $(1-s)$ が相殺するため）。角速度は $\omega_s = 2\pi N_s/60$・$\omega = 2\pi N/60$（$N$ の単位は min⁻¹）。
例題 — トルク換算を2通りで出して一致を確かめる
**問:** 4 極・50 Hz の三相誘導電動機で、二次入力 $P_2 = 22.0\;\mathrm{kW}$、滑り $s = 4.0\,\%$（セクション6の例題 1.2.2 と同じ $P_2$・$s$ の機に、極数と周波数を与えたもの）。発生トルク $T$ を求めよ。
**同期側から:** 同期速度は $N_s = \dfrac{120 \times 50}{4} = 1500\;\mathrm{min^{-1}}$、同期角速度は
$\omega_s = \dfrac{2\pi \times 1500}{60} = 50\pi \approx 157.1\;[\mathrm{rad/s}]$
$T = \dfrac{P_2}{\omega_s} = \dfrac{22000}{50\pi} \approx 140\;[\mathrm{N\cdot m}]$
**機械側から検算:** 回転速度 $N = (1-s)N_s = 0.96 \times 1500 = 1440\;\mathrm{min^{-1}}$、$\omega = \dfrac{2\pi \times 1440}{60} = 48\pi \approx 150.8\;\mathrm{rad/s}$、機械的出力 $P_m = (1-s)P_2 = 0.96 \times 22000 = 21120\;\mathrm{W}$。
$T = \dfrac{P_m}{\omega} = \dfrac{21120}{48\pi} \approx 140\;[\mathrm{N\cdot m}]$
両者は**厳密に一致**する（丸めの都合で近い値になっているのではない）。$P_m$ と $\omega$ の両方に同じ $(1-s)$ が掛かって約分されるためで、トルクは滑りが変わっても「二次入力 ÷ 同期角速度」で求まる。だから $P_2$ をワット単位のまま「トルクの代用量」として扱える＝同期ワット。
⚠️ 分母に入れるのは **rad/s** であって min⁻¹ ではない。$2\pi/60$ の換算を忘れて $N_s$ でそのまま割ると、答えが $60/2\pi \approx 9.55$ 分の 1 になる（この例なら 14.7 という値が出る）。⚠️ $P_2$ と組むのは $\omega_s$、$P_m$ と組むのは $\omega$。**たすき掛けにしない**。

## 3.トルク特性

滑り s に対するトルク T の関係は、典型的な「山形」の曲線となる。停動トルク Tmax を境に、左側（高滑り域）が始動領域、右側（低滑り域）が安定運転領域である。
— 図1.2.3 トルク特性（横軸:滑り s、縦軸:トルク T）。かご形の代表値 sm ≈ 0.2 で作図した一例で、sm は二次抵抗で動く（下の比例推移を参照） —
05 / 07
**トルク式（簡易形）**
$T \;\propto\; \dfrac{V_1^{2} \cdot (r_2'/s)}{(r_1 + r_2'/s)^2 + (x_1 + x_2')^2}$
電圧の二乗に比例することに注意。電源電圧が 0.9 倍に低下すると、トルクは 0.81 倍となる。

### 比例推移（巻線形のみ）

巻線形誘導機において 二次抵抗を k 倍にすると、同一トルクを生じる滑りも k 倍 になる。これを比例推移という。停動滑り $s_m$ も k 倍になるため、二次抵抗を増やせば 始動トルクを大きく できる一方、運転時の効率は低下する。
比例推移で「必ず」正しくなる3点と、正しくない2点
**① 最大トルクの大きさは二次抵抗によらず一定。**動くのは「最大トルクを生じる滑り $s_m$」だけで、山の高さ $T_{max}$ は変わらない。トルク式で $r_2'/s$ を1つの変数と見ると、$r_2'$ と $s$ が同じ倍率で動く限り式の値が変わらないためで、上の図でいえば**山が横にスライドするだけで高さは同じ**。$T_{max} \propto \dfrac{V_1^{2}}{2(x_1 + x_2')}$ と、$r_2'$ を含まない形で書けることからも読める。「二次抵抗を増やすと最大トルクが増える」は誤り。
**② 始動トルクが増えるのは $s_m$ が 1 に達するまで。**$s_m = 1$（始動の瞬間に山の頂点が来る）で始動トルク＝最大トルクとなり、そこからさらに二次抵抗を増やすと山は s > 1 側へ抜けてしまい、始動トルクは逆に減少する。「抵抗を増やせば増やすほど始動トルクが大きくなる」は誤り。
**③ 比例推移が成り立つ量は限られる。**トルクと電流（一次電流・二次電流）・力率には成り立つが、出力・効率・二次銅損には成り立たない。同じトルクを高い滑りで出す分だけ二次銅損 $P_{c2}=sP_2$ が増え、効率は下がる（だから運転中は抵抗を短絡する）。
比例推移の使い道
「始動時のみ二次抵抗を挿入し、加速後に短絡」という二次抵抗始動法はこの性質を利用したもの。かご形では原理的に二次抵抗を変化できないため、二重かご形・深溝形が用いられる。

図1.2.4 Y-Δ 始動で 1/3 になる理由。相電圧・相電流は 1/√3 だが、Δ では線電流が相電流の √3 倍あるため線電流の比は 1/3。トルクは相電圧の2乗に比例するので同じく 1/3。「1/√3」と答える誤りは、相電流と線電流を取り違えたときに起きる。
頻出の誤答
**Y-Δ 始動の電流とトルク** はともに $1/3$ になると覚える。「電流は $1/\sqrt{3}$ 」と書いて間違えるパターンが多い。これは **線電流** と **相電流** の混同が原因。 Y 結線では相電流＝線電流、Δ 結線では相電流の $\sqrt{3}$ 倍が線電流。Y では相電圧が $1/\sqrt{3}$ となり、トルクは電圧の二乗 ⇒ $1/3$。電流も $1/3$。

## 5.速度制御

- **周波数制御（VVVF）** — 最も広く使われる方式。$V/f = \mathrm{const}$ で磁束を一定に保つ。低速で電圧降下を補正する **トルクブースト** も併用。
- **極数切替** — 巻線結線を切り替えて極数を変え、段階的に速度を変える。
- **二次抵抗制御** — 巻線形で外部抵抗を調整。効率は悪いが大容量機で実績あり。
- **二次励磁制御（クレーマ・セルビウス）** — 二次に電力を入出力。エネルギー回生が可能。

06 / 07
**V/f 一定制御**
$\dfrac{V}{f} = \mathrm{const} \;\Rightarrow\; \phi \;\approx\; \mathrm{const}$
磁束を定格値に保ち、最大トルクを維持しながら可変速運転を行う。基底周波数以上では弱め界磁制御に移行。

## 6.例題

例題 1.2.1（同期速度・滑り）
**問:** 4 極・50 Hz の三相誘導電動機が 1455 min⁻¹ で運転している。滑り s [%]、回転子周波数 f₂ [Hz] を求めよ。
**解:**
$N_s = \dfrac{120 \times 50}{4} = 1500 \;[\mathrm{min^{-1}}]$
$s = \dfrac{1500 - 1455}{1500} = 0.030 \;=\; 3.0\;\%$
$f_2 = s \cdot f_1 = 0.030 \times 50 = 1.5 \;[\mathrm{Hz}]$
例題 1.2.2（電力比）
**問:** ある三相誘導電動機の二次入力が 22.0 kW、滑りが 4.0% であるとき、二次銅損 P_c2 と機械的出力 P_m を求めよ。
**解:** 比 $P_2 : P_{c2} : P_m = 1 : s : (1-s)$ を用いる。
$P_{c2} = s \cdot P_2 = 0.040 \times 22.0 = 0.88 \;[\mathrm{kW}]$
$P_m = (1-s) \cdot P_2 = 0.96 \times 22.0 = 21.12 \;[\mathrm{kW}]$
07 / 07
**効率（簡易）**
$\eta \;\approx\; (1-s) \times \dfrac{P_2}{P_1} \;\le\; (1-s)$
鉄損・一次銅損・機械損を無視した上限値。実機では (1-s) からさらに数%低下する。
