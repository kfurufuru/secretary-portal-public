# 単相誘導電動機

単相電源では回転磁界が生じないため、始動時のみ補助巻線で擬似的に二相を作って起動する。家電・小型機器に多用。
**優先度 C**出題は少ない。選択肢を切れる程度まで
**出題頻度（編集部集計）:** 低

▼ ミクロを図で掘り下げる：なぜ単相は自力で始動できず、コンデンサで始動できるか
ミクロ（なぜ）：単相の交番磁界は互いに逆回転する2つの回転磁界の合成。静止時（s＝1）は両者のトルクが打ち消し合って始動トルクゼロ。補助巻線に直列コンデンサで進み電流を流し、空間的にずれた主巻線との位相差で回転磁界を作って始動する。
🔬 ミクロの因果（なぜ単相は自力で始動できないか）
1. **単相交流を1つの巻線に流すと交番磁界**（同じ軸上で大きさだけ脈動）——これは互いに逆回転する**正転・逆転2つの回転磁界の合成**と等価
2. **静止時（s＝1）**は正転・逆転成分のトルクが同じ大きさ・逆向き → 打ち消し合って**始動トルクゼロ**
3. **補助巻線に直列コンデンサ**を入れると電流が進み（$X_C=\dfrac{1}{\omega C}$）、遅れ気味の主巻線電流との間に位相差 Δφ が生まれる
4. 空間的にずれた2巻線 × 時間位相差の擬似二相で**回転磁界が復活し始動トルク発生**。位相差が90°に近いほど大きく、分相よりコンデンサ始動の始動トルクが大きいのはこのため。暗記用の序列は くま取り＜分相＜コンデンサ始動＜反発始動

## 1.始動方式

- **分相始動形** — 主巻線と抵抗の大きい補助巻線で位相差を作る
- **コンデンサ始動形** — 補助巻線に直列コンデンサ。始動トルク大
- **コンデンサ始動・運転形** — 大容量の始動用と小容量の運転用を使い分け、始動後に始動用を切り離して運転用を残す。力率・運転特性（振動・騒音）を改善
- **くま取りコイル形** — 銅環で磁束に位相差を与える。小容量向け

理解を深める — コンデンサ始動は補助巻線の電流を進ませて回転磁界を作る
単相交流を1つの巻線に流しても、磁束は同じ軸上で大きさが脈動する**交番磁界**にしかならず、向きが回り続ける**回転磁界**はできない（だから単相機は自力で始動トルクを生まない）。回転磁界を作るには、空間的にずれた2つの巻線に**時間的に位相のずれた電流**を流して擬似的な二相を作る必要がある。**コンデンサ始動形**は、補助巻線に直列にコンデンサを入れてこの位相差を作る。
鍵になるのは、理論で学ぶ**コンデンサでは電流が電圧より位相が進む**性質。容量性リアクタンス $X_C=\dfrac{1}{\omega C}$ だけの理想回路では、電流は電圧より $90^\circ$ 進む（コイルは逆に $90^\circ$ 遅れる）。主巻線（誘導性で電流が遅れ気味）に対し、コンデンサを直列にした補助巻線は電流が進む側へ寄るので、両巻線電流の間に大きな位相差 $\Delta\varphi$ が生まれる。これが空間的にずれた2巻線と組み合わさって回転磁界となり、**始動トルク**を生む。位相差が $90^\circ$ に近いほど二相が対称に近づき始動トルクが大きくなる——分相始動（抵抗差でわずかな位相差）よりコンデンサ始動の始動トルクが大きいのはこのため。
→ 理論Wiki「1.2 コンデンサ」で容量性リアクタンスと電流の位相進み（ICE）を深掘り
覚え方
始動トルクの大小（一般的傾向）: **くま取り < 分相 < コンデンサ始動 < 反発始動**。家電は静音・小型のくま取り、井戸ポンプは始動トルク大のコンデンサ始動が多い。
