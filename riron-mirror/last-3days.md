## 1先に潰す6点 — 直近の×記録（2026年7〜8月）から⚠ここは「知らなかった」ではなく「取り違えた」で落としている

学習記録で直近に ×（間違えた） が付いたテーマだけを抜き出した。Day 3 以降の一般確認より先にこの6つを潰す。書いてあるのは公式そのものではなく、分かれ目（どこで取り違えるか）。

### ① 相互インダクタンス — 和動・差動と、L が負にならない理由📍符号は端子の極性ではなく「和動か差動か」で決まる
- 和動接続（磁束が助け合う）:  $L = L_1 + L_2 + 2M$
- 差動接続（磁束が打ち消し合う）:  $L = L_1 + L_2 - 2M$
-  $M = k\sqrt{L_1 L_2}$ 、結合係数は  $0 \le k \le 1$ （ $k=1$  は完全結合＝漏れ磁束ゼロ。理想変圧器はさらに損失も無視した別概念）

差動でも合成 L は負にならない。 $k \le 1$  より  $M \le \sqrt{L_1 L_2}$  なので  $L_1 + L_2 - 2M \ge L_1 + L_2 - 2\sqrt{L_1 L_2} = (\sqrt{L_1} - \sqrt{L_2})^2 \ge 0$ 。負の L はエネルギーを取り出し続けられる永久機関になるので、その選択肢は物理で切れる。

回路図の ●印は端子の＋−ではなく「同極性端子」（＝両コイルの巻き方向の相対関係）を示す。●どうしから電流が入る（または両方から出る）なら和動で +2M、片方だけ●へ入るなら差動で −2M。📖詳しく学ぶ：3.1 インダクタンス・電磁誘導→

### ② 磁界 — 1/r が使えるのは「無限長直線」だけ📍形状ごとに H の式が違う。思い出した式が今の形状のものか先に確認する
- 無限長直線電流から距離 r:  $H = \dfrac{I}{2\pi r}$ （ $1/r$ ）
- 十分長いソレノイドの内部（端から十分離れた領域）:  $H = nI$ （n は単位長あたり巻数・位置に依らず一様、外部はほぼ0。端の付近だけは弱まる）
- 円形コイル（半径 a・N 巻）の中心:  $H = \dfrac{NI}{2a}$ （1巻なら  $I/(2a)$ ）

点電荷の電界が  $1/r^2$  で直線電流の磁界が  $1/r$  なのは、広がる先が球面  $4\pi r^2$  か円周  $2\pi r$  かの違い。分母に何が来るかで冪を復元できる。

 $B = \mu H$ （ $\mu = \mu_0 \mu_r$ ）。μ がどちらに効くかは「何が固定されているか」で変わる：起磁力  $NI$  側が固定なら  $H$  が決まって  $B$  が μ 倍、磁束  $\phi$  側が固定なら  $B$  が決まって  $H$  が  $1/\mu$ 。

名前で引っかける正誤問題に注意：磁力線の密度が表すのは磁界の強さ  $H$ 、磁束線の密度が表すのが磁束密度  $B$ 。「磁力線の密度＝磁束密度」は誤り（R02問4 の正答肢がこれ）。名前が似ているだけで別物、つなぐのは  $B = \mu H$  の1本だけ、と切り分ける。📖詳しく学ぶ：1.4 磁気回路→

### ③ 静電エネルギーは 1/r、力は 1/r²（冪が1つ下がる）📍「動き出すか」は力、「どこまで行くか・速さ」はエネルギー
- 力:  $F = k\dfrac{Q_1 Q_2}{r^2}$
- 位置エネルギー（無限遠を基準）:  $W = k\dfrac{Q_1 Q_2}{r}$
- 両者の関係は  $F = -\dfrac{dW}{dr}$ 。距離依存だけ見れば「力を r で積分すると冪が1つ下がる」と覚えれば、 $1/r^2$  ↔  $1/r$  を取り違えない
- 電位  $V = k\dfrac{Q}{r}$  と電界  $E = k\dfrac{Q}{r^2}$  も同じ関係

設問が「静止した電荷は動き出すか／どちら向きに動くか」なら力（1/r²）の比較、「速さはいくらになるか／仕事はいくらか」ならエネルギー（1/r）の差。どちらを聞かれているかを1行書いてから式を選ぶ。📖詳しく学ぶ：1.1 静電気・クーロンの法則→

### ④ 左手・右手と「磁界は動いている電荷しか押さない」📍押されるなら左手・生み出すなら右手
- 左手（電動機）: 親指=力 F・人差し指=磁束密度 B・中指=電流 I
- 右手（発電機）: 親指=速度 v・人差し指=磁束密度 B・中指=誘導起電力 e（＝誘導電流の向き）

電界は静止していても押す（ $F = qE$ ）。磁界は動いている電荷しか押さない（ $F = qvB\sin\theta$  なので  $v = 0$  や v が B と平行なら力はゼロ）。電子は電流と逆向きに動く点も毎回確認する。

平行導体は「同じ向きの電流どうしが引き合い、逆向きは反発する」（同符号の電荷が反発するのと逆なので取り違えやすい）。空気中では単位長あたり  $F = \dfrac{\mu_0 I_1 I_2}{2\pi r}$ （大きさ。引力か斥力かは電流の向きで判定）。📖詳しく学ぶ：1.3 電磁力→

### ⑤ トランジスタ α・β — 分母が何かを先に置く📍I_E = I_C + I_B を書けば α と β は復元できる
- ベース接地の電流増幅率:  $\alpha = \dfrac{I_C}{I_E}$ （エミッタが全体・コレクタはその大部分なので 1 未満）
- エミッタ接地の電流増幅率:  $\beta = \dfrac{I_C}{I_B}$ （ベース電流はごく小さいので 1 よりずっと大きい）
- 相互変換:  $\alpha = \dfrac{\beta}{\beta + 1}$ 、 $\beta = \dfrac{\alpha}{1 - \alpha}$

迷ったら  $I_E = I_C + I_B$  を1行書いて代入すれば、暗記なしで相互変換が出る。答えが 1 未満か 1 より大きいかで、分母に置いたのが  $I_E$  か  $I_B$  かを検算できる。📖詳しく学ぶ：5.2 トランジスタ→

### ⑥ 磁気回路 — 電気回路と同型に置き、逆答しやすい2点だけ潰す📍μ は σ の対応物。ヒステリシス面積と飽和は「逆に答える」記録があるので向きを固定する
- 三要素: 起磁力  $F = NI$ （単位は A）／磁束  $\phi$ ／磁気抵抗  $R_m = \dfrac{l}{\mu S}$ 。 $\phi = \dfrac{NI}{R_m}$
- 透磁率 μ は導電率 σ の対応物（抵抗率ではない）:  $R_m = \dfrac{l}{\mu S}$  ⇔  $R = \dfrac{l}{\sigma S}$  で完全同型。「磁気抵抗は？」に μ そのものと答えるのが典型の誤り（電気回路で「抵抗は？」に σ と答えるのと同じ）
- 空隙は桁で効く:  $\mu_r = 5000$  の鉄心に 1 mm の空気ギャップ ＝ 鉄心 5 m 相当（ $0.001 \times 5000$ ）。ギャップがあれば  $R_m$  はほぼギャップだけで決まる

逆に答えた記録がある2点（向きをここで固定する）
- ヒステリシス面積 ＝ 1サイクルで捨てるエネルギー。だから変圧器鉄心は面積の狭い材料（ケイ素鋼板）が良い。広いのは永久磁石（保磁力が要る）。「変圧器は広い方がよい」は逆
- 飽和すると μ が激減 →  $R_m = l/(\mu S)$  が急増 → 同じ  $NI$  では  $\phi$  が伸びない。必要な  $\phi$  を得ようとして励磁電流が急増する。「電流が流れなくなる」は逆

 $\phi = NI/R_m$  の線形計算が使えるのは飽和していない領域だけ。この一文を先に書けば、上の2点は向きを間違えない。

この3点（磁気抵抗と透磁率の取り違え・ヒステリシス面積・飽和時の励磁電流）は 7.1 引っかけパターン集 に選択肢つきの練習問題がある。向きを固定したら1問ずつ当てて確認する。📖詳しく学ぶ：1.4 磁気回路→

## 2Day 3（試験3日前）— 電磁気・直流回路の公式確認

### 静電気・コンデンサ📍クーロンの法則 F = kQ₁Q₂/r² の係数kの根拠

 $k = 1/(4\pi\varepsilon_0)$ 。 $\varepsilon_0 \approx 8.85 \times 10^{-12}$  [F/m] は真空の誘電率。「kを丸暗記する」のではなく、 $\varepsilon_0$  から導出できると点が取れる。

比誘電率  $\varepsilon_r$  がある媒質では  $k = 1/(4\pi\varepsilon_0\varepsilon_r)$  と分母が増える（斥力・引力が弱まる）。📖詳しく学ぶ：1.1 静電気・クーロンの法則→

確認事項：
- クーロンの法則の距離依存（ $r^2$  に反比例）を説明できるか
- 電界  $E = F/Q$  と電位  $V = kQ/r$  の違いを即答できるか
- コンデンサの直列合成（逆数の和）と並列合成（足し算）を抵抗と混同しないか → パターン2📍コンデンサのエネルギー W = CV²/2 の2分の1の根拠

「電荷 Q と電圧 V をかけて Q×V では？」と考えると、答えは2倍ずれる。理由は、充電のあいだ電圧が 0 から V へ少しずつ上がること。からっぽのコンデンサは電圧が0なので最初の電荷はスッと入り、電荷がたまるほど電圧が上がって、次の電荷を押し込むのがだんだん大変になる。

電荷1個を押し込むコストはそのときの電圧で決まり、0 から V へ直線で増える。ならせば平均  $V/2$ 。全電荷 Q ぶんを合計すると  $W = Q \times (V/2)$ 。これを図にすると下のグラフになる。

> 図：たて＝電圧、よこ＝電荷。色をぬった三角形がたくわえたエネルギー W で、点線の長方形 QV のちょうど半分。

たて＝電圧・よこ＝電荷の直線の下は三角形。その面積は「底辺 × 高さ ÷ 2」で、この÷2こそが  $1/2$  の正体。長方形  $QV$ （電圧がずっと V だったと仮定した値）のちょうど半分が、 $W = \tfrac{1}{2}QV = \tfrac{1}{2}CV^2 = \tfrac{Q^2}{2C}$  となる。📖詳しく学ぶ：1.2 コンデンサ→

確認事項：
-  $W = Q^2/(2C) = CV^2/2 = QV/2$  の3形式を切り替えられるか → パターン3
- 直列接続で各コンデンサの電荷が等しい理由を説明できるか

### 磁気・電磁力📍フレミング左手（モーター）と右手（発電機）の選び方

「何が欲しいか」で手を選ぶ。力Fが欲しい→左手（モーター）、起電力eが欲しい→右手（発電機）。

左手：中指=電流 I、人差し指=磁束密度 B、親指=力 F（IBF の順）。
右手：中指=誘起起電力 e、人差し指=磁束密度 B、親指=速度 v（eBv の順）。📖詳しく学ぶ：1.3 電磁力→

-  $F = BIL\sin\theta$  の  $\theta$  が「電流と磁界の角」であることを確認できるか → パターン4
- 誘導起電力  $e = BLv\sin\theta$  の  $\theta$  が「速度と磁界の角」であることを確認できるか

電気抵抗  $R = \rho l/A$  と対応。 $\mu = \mu_0\mu_r$ （鉄心では  $\mu_r$  は数百〜数千）。空隙では  $\mu_r = 1$  なので磁気抵抗が急増する。鉄心区間と空隙区間で材料を必ず確認する。📖詳しく学ぶ：1.4 磁気回路→
